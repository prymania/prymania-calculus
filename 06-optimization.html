โจทย์ปัญหาค่าเหมาะที่สุด

ใช้อนุพันธ์แก้ปัญหาจริง: พื้นที่มากที่สุด รายได้สูงสุด กำไรสูงสุด ปริมาตรกล่อง และการเคลื่อนที่

🎬 คำถามเปิดบท
  • ร้านค้าออนไลน์ส่งของวันละหลายหมื่นกล่อง ถ้าออกแบบกล่องให้ใส่ของได้เท่าเดิมแต่ ใช้กระดาษน้อยลง กล่องละนิดเดียว ทั้งปีจะประหยัดได้มหาศาล
    — กล่องแบบไหนประหยัดที่สุด?
  • AI อย่าง ChatGPT ถูกฝึกด้วยการหาค่า “ผิดพลาดน้อยที่สุด” ของฟังก์ชันที่มีตัวแปรเป็นพันล้านตัว
    — ตั้ง $f'(x) = 0$ แล้วแก้สมการแบบในบทนี้คงไม่ไหว แล้วคอมพิวเตอร์ทำอย่างไร?

  2. ใช้อนุพันธ์หาค่าที่เหมาะที่สุด และตรวจสอบด้วย $f''$ หรือค่าปลายช่วง
  3. ตอบคำถามให้ครบทุกส่วนพร้อมหน่วย

6.1 สูตรสำเร็จ 5 ขั้น

โจทย์ “มากที่สุด / น้อยที่สุด / คุ้มที่สุด” ในชีวิตจริงเต็มไปหมด

  • ตั้งราคาเท่าไรให้ได้เงินมากสุด
  • ใช้วัสดุน้อยสุด
  • ใช้เวลาสั้นสุด

ทั้งหมดใช้เครื่องมือเดียวกันคือ หาจุดที่อนุพันธ์เป็นศูนย์

1. อ่าน + วาดรูปอะไรคือสิ่งที่อยากให้ max/min
➜
2. ตั้งตัวแปรให้ x คืออะไร
➜
3. เขียนฟังก์ชันให้เหลือตัวแปรเดียว
➜
4. ดิฟ = 0หาจุดวิกฤต
➜
5. ตรวจ + ตอบf″ / ปลายช่วง / หน่วย
⚠️ ข้อผิดพลาดที่เจอบ่อย
  • ฟังก์ชันยังมี 2 ตัวแปร
    → ต้องใช้ “เงื่อนไข” ในโจทย์ แทนตัวแปรหนึ่งด้วยอีกตัวก่อนดิฟ
  • ตอบแค่ค่า x แต่โจทย์ถามขนาด พื้นที่ หรือเงิน

  • ลืมเช็คช่วงของ x

⭐ โบนัส 6.1

กระป๋องน้ำอัดลมเป็น ทรงกระบอก จุ 330 มล. (= 330 ลบ.ซม.) ถ้าต้องการใช้แผ่นอะลูมิเนียม (พื้นที่ผิว) น้อยที่สุด

ปริมาตร$V = \pi r^2 h = 330$ พื้นที่ผิว$S = 2\pi r^2 + 2\pi r h$ (ฝา + ก้น + ผนัง)
  1. แสดงว่ากระป๋องที่ประหยัดที่สุดต้องมี ความสูง = 2 เท่าของรัศมี (สูงเท่าความกว้าง)
  2. กระป๋องจริงสูงกว่าความกว้างเกือบ 2 เท่า คิดว่าบริษัทผลิตกระป๋องแบบนั้นเพราะอะไร

6.6 Gradient descent: ให้คอมพิวเตอร์เดินหาจุดต่ำสุดเอง เสริม

  • ทุกข้อในบทนี้เราแก้สมการ $f'(x) = 0$ ได้
  • แต่ฟังก์ชันในงานจริง (เช่น ความผิดพลาดของโมเดล AI) ซับซ้อนจนแก้สมการตรง ๆ ไม่ได้

คอมพิวเตอร์จึงใช้วิธี “เดินลงเขาทีละก้าว”

⛷️ Gradient descent
$$x_{\text{ใหม่}} = x - (\text{ขนาดก้าว})\times f'(x)$$
  • ถ้า $f'(x) \lt 0$ (กราฟลงไปทางขวา) → $x$ เพิ่มขึ้น เดินไปทางขวา
  • ถ้า $f'(x) \gt 0$ (กราฟขึ้นไปทางขวา) → $x$ ลดลง เดินไปทางซ้าย
  • ยิ่งชันยิ่งก้าวยาว และเมื่อถึงก้นหุบ $f'(x) \approx 0$ ก็หยุดเดินเอง

ลองปรับ “ขนาดก้าว” (ในวงการ AI เรียกว่า learning rate) แล้วกดก้าวหลาย ๆ ครั้ง:

  • เล็กมาก (0.02) — ไปถูกทางแต่ช้ามาก ต้องเดินหลายร้อยก้าว
  • พอดี (0.1–0.5) — เข้าใกล้ $x = 3$ อย่างรวดเร็ว
  • ใหญ่เกิน (1.0 ขึ้นไป) — ก้าวข้ามหุบไปมา ไม่ลงสักที หรือกระเด็นหลุดออกไปเลย
ตัวอย่าง 6.12เดินด้วยมือ 2 ก้าว⭐ ง่าย

$f(x) = (x-3)^2 + 1$ เริ่มที่ $x = 0$ ใช้ขนาดก้าว 0.1 จงหาตำแหน่งหลังเดิน 2 ก้าว

Gradient descent กับขนาดก้าวต่าง ๆ
def df(x):                    # f(x) = (x - 3)**2 + 1  ->  f'(x) = 2(x - 3)
    return 2 * (x - 3)

for lr in [0.02, 0.1, 0.4, 1.0, 1.1]:
    x = 0.0
    for step in range(20):
        x = x - lr * df(x)
    print(f"ขนาดก้าว {lr:<4}  เดิน 20 ก้าว ได้ x = {x:.4f}")

ขนาดก้าว 0.02  เดิน 20 ก้าว ได้ x = 1.6740
ขนาดก้าว 0.1   เดิน 20 ก้าว ได้ x = 2.9654
ขนาดก้าว 0.4   เดิน 20 ก้าว ได้ x = 3.0000
ขนาดก้าว 1.0   เดิน 20 ก้าว ได้ x = 0.0000
ขนาดก้าว 1.1   เดิน 20 ก้าว ได้ x = -112.0128

นี่คือวิธีเดียวกับที่ใช้ฝึกโมเดล AI แทบทุกตัว ต่างกันแค่

  • “x” ไม่ใช่ตัวเลขตัวเดียว แต่เป็น ปุ่มปรับนับล้านนับพันล้านปุ่ม
  • “ความชัน” ของแต่ละปุ่มคำนวณด้วยกฎลูกโซ่ (backpropagation) จากบทที่ 4

การเลือก learning rate ให้พอดี เป็นงานสำคัญของวิศวกร AI เลยทีเดียว

⭐ โบนัส 6.3

ลองจินตนาการว่าคุณเป็นลูกบอลอยู่บนภูเขาที่มี หมอกหนามาก มองไม่เห็นภาพรวม รู้แค่ความชันใต้เท้าตัวเอง แล้วเดินลงเขาด้วย gradient descent

ฟังก์ชัน $f(x) = x^4 - 4x^2 + x$ มีหุบ 2 หุบ คือที่ $x \approx -1.47$ ($f \approx -5.44$) และ $x \approx 1.35$ ($f \approx -2.62$)

  1. หุบไหนคือ “จุดต่ำสุดจริง” (ต่ำสุดสัมบูรณ์)
  2. ถ้าเริ่มเดินที่ $x = 2$ ลูกบอลจะไปจบที่หุบไหน และนี่เป็นปัญหาอย่างไร
  3. เสนอวิธีแก้ปัญหานี้ อย่างน้อย 1 วิธี
🎬 กลับมาตอบคำถามเปิดบท
กล่องที่ประหยัดที่สุดกล่องลูกบาศก์ (เมื่อฐานเป็นสี่เหลี่ยมจัตุรัสและมีฝา)
หาได้ด้วยการเขียนพื้นที่ผิวเป็นฟังก์ชันตัวแปรเดียว แล้วดิฟ = 0 ตามสูตร 5 ขั้น AI หาค่าต่ำสุดใช้ gradient descent: ไม่แก้สมการ แต่ใช้ความชันบอกทิศ แล้วเดินลงทีละก้าวจนถึงก้นหุบ

แนวคิดเดียวกันทั้งบท คือ จุดต่ำสุดอยู่ตรงที่ความชันเป็นศูนย์

ตรวจโจทย์กล่องไม่มีฝาด้วย SymPy
from sympy import symbols, diff, solve
x = symbols('x', positive=True)
V = x*(12 - 2*x)**2
for c in solve(diff(V, x), x):
    print("x =", c, " V =", V.subs(x, c), " V'' =", diff(V, x, 2).subs(x, c))
ผลลัพธ์เมื่อรัน
x = 2  V = 128  V'' = -48
x = 6  V = 0  V'' = 48
