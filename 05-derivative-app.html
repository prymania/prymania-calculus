CHAPTER 05 · อนุพันธ์

ความชัน เส้นสัมผัส และค่าสูงสุด–ต่ำสุด

ความชันเส้นโค้ง สมการเส้นสัมผัส ฟังก์ชันเพิ่ม–ลด จุดวิกฤต ค่าสูงสุด–ต่ำสุดสัมพัทธ์และสัมบูรณ์

🎬 คำถามเปิดบท
  • ไม่ใช้เครื่องคิดเลข ลองตอบให้ได้ใน 10 วินาที: $\sqrt{4.1}$ มีค่าประมาณเท่าไร (ละเอียดถึงทศนิยม 2 ตำแหน่ง)?
  • ทีมดูแลเซิร์ฟเวอร์ของแอปอยากรู้ว่า ช่วงไหนของวันมีคนใช้งานมากที่สุด จะได้เตรียมเครื่องให้พอ
    ถ้ามีสูตรจำนวนผู้ใช้ตามเวลา จะหาจุดพีคได้อย่างไร โดยไม่ต้องลองแทนค่าทุกชั่วโมง?
🎯 เมื่อเรียนจบบทนี้ นิสิตจะสามารถ
  1. หาความชันของเส้นโค้ง ณ จุดใด ๆ และสมการเส้นสัมผัสได้
  2. หาจุดวิกฤต และช่วงที่ฟังก์ชันเพิ่ม/ลด ด้วยตารางเครื่องหมาย $f'(x)$
  3. ตัดสินว่าจุดวิกฤตเป็นค่าสูงสุดสัมพัทธ์ ต่ำสุดสัมพัทธ์ หรือจุดนิ่ง ด้วย $f'$ หรือ $f''$
  4. หาค่าสูงสุดและต่ำสุดสัมบูรณ์บนช่วงปิด $[a,b]$ ได้
  5. ใช้เส้นสัมผัสประมาณค่าฟังก์ชันใกล้จุดที่รู้ค่า (linear approximation) ได้

5.1 ความชันของเส้นโค้ง

เส้นตรงความชันเท่ากันทุกจุด เส้นโค้งความชันเปลี่ยนไปตามตำแหน่ง

ที่จุดใด ๆ ความชันของเส้นโค้งก็คือ ความชันของเส้นสัมผัสที่จุดนั้น ซึ่งหาได้จากการดิฟ 1 ครั้ง

📐 ความชันของ $y = f(x)$ ที่ $x = a$
$$m = f'(a)$$
  • ดิฟก่อน แล้วค่อยแทนค่า
  • ถ้าแทนค่าก่อนดิฟ จะได้ค่าคงที่ ซึ่งดิฟได้ 0 เสมอ!
ตัวอย่าง 5.1ความชันของ y = x² หลายจุด⭐ ง่าย

หาความชันเส้นโค้งของ $y = x^2$ ที่จุด $x = -4,\ x = 2$ และ $x = 5$

ตัวอย่าง 5.2ความชัน ณ จุดต่าง ๆ⭐ ง่าย
  1. $y = 5x^3 + 3x^2 - 1$ ที่ $x = 0$ และ $x = 5$
  2. $y = -10x^3 - 2x^2 - 3x$ ที่ $x = -5,\ 0,\ 1$
  3. $y = -(x^2) - x^3$ ที่ $x = -4,\ 0,\ 4$
⭐ โบนัส 5.1

ป้ายจราจรบนทางขึ้นเขาเขียนว่า “ทางชัน 8%”

  1. 8% หมายถึงอะไร เมื่อมองเป็น “ความชัน”
  2. ทางขึ้นเขาเส้นหนึ่งมีรูปตามสมการ $y = 0.0005x^2$ (x = ระยะทางแนวราบ, y = ความสูง หน่วยเมตร) ที่ $x = 50$ ทางชันกี่ %
  3. ต้องติดป้ายเตือนรถบรรทุกเมื่อทางชันเกิน 10% ควรติดป้ายที่ $x$ เท่าใด

5.2 สมการเส้นสัมผัส (Tangent line)

เส้นสัมผัส คือเส้นตรงที่ “แตะ” กราฟที่จุดหนึ่ง

  • มีความชันเท่ากับความชันของกราฟที่จุดนั้นพอดี
  • ใช้สมการ จุด–ความชัน
📏 สมการเส้นสัมผัสที่ $x = x_1$
$$y - y_1 = m(x - x_1) \qquad\text{โดย}\quad y_1 = f(x_1),\ \ m = f'(x_1)$$
  1. $x_1$ = จุดที่โจทย์กำหนด
  2. $y_1$ = แทน $x_1$ ใน ฟังก์ชันเดิม $f(x)$
  3. $m$ = ดิฟ $f$ แล้วแทน $x_1$ ใน $f'(x)$
  4. แทนลงสมการ แล้วจัดให้อยู่ในรูป $y = mx + c$
ตัวอย่าง 5.3เส้นสัมผัสของ y = x³⭐⭐ ปานกลาง

หาสมการเส้นสัมผัสเส้นโค้ง $y = x^3$ ที่จุด $x = -3$ และ $x = 2$

ตัวอย่าง 5.4เส้นสัมผัส (ฝึกต่อ)⭐⭐ ปานกลาง
  1. $y = x^3 - x^2 + 5$ ที่ $x = 0$ และ $x = 3$
  2. $y = 5x^3 - 2x^2 - x$ ที่ $x = 0$ และ $x = 5$
  3. $y = \tfrac14x^4 - \tfrac23x^3 + 5x^2 - 10$ ที่ $x = 0$ และ $x = 2$

ใช้เส้นสัมผัสประมาณค่า (Linear approximation)

ลองลากจุดในกราฟด้านบนแล้วสังเกต

  • ใกล้ ๆ จุดสัมผัส เส้นสัมผัสแทบทับกราฟ
  • เราจึงใช้เส้นตรง (ซึ่งคำนวณง่าย) แทนเส้นโค้งได้ เมื่อ $x$ อยู่ใกล้จุดที่รู้ค่า
📏 ค่าประมาณจากเส้นสัมผัสที่ $x = a$
$$f(x) \approx f(a) + f'(a)(x - a) \qquad\text{เมื่อ } x \text{ ใกล้ } a$$

หา $\sqrt{4.1}$

ฟังก์ชัน$f(x) = \sqrt x$ ที่ $a = 4$ (รู้ว่า $\sqrt4 = 2$) ความชัน$f'(x) = \dfrac{1}{2\sqrt x}$ ได้ $f'(4) = \dfrac14$
$$\sqrt{4.1} \approx 2 + \tfrac14(4.1 - 4) = 2 + 0.025 = 2.025$$
เทียบค่าประมาณจากเส้นสัมผัสกับค่าจริง
import math

def approx(x):              # เส้นสัมผัสของ sqrt(x) ที่ x = 4
    return 2 + (x - 4) / 4

for x in [4.1, 4.5, 5, 9]:
    real = math.sqrt(x)
    print(f"x = {x:<4}  ประมาณ = {approx(x):.4f}  จริง = {real:.4f}  คลาดเคลื่อน = {abs(approx(x) - real):.4f}")
ผลลัพธ์เมื่อรัน
x = 4.1   ประมาณ = 2.0250  จริง = 2.0248  คลาดเคลื่อน = 0.0002
x = 4.5   ประมาณ = 2.1250  จริง = 2.1213  คลาดเคลื่อน = 0.0037
x = 5     ประมาณ = 2.2500  จริง = 2.2361  คลาดเคลื่อน = 0.0139
x = 9     ประมาณ = 3.2500  จริง = 3.0000  คลาดเคลื่อน = 0.2500
ตัวอย่าง 5.5ประมาณค่ารากด้วยเส้นสัมผัส⭐ ง่าย

ใช้เส้นสัมผัสของ $f(x) = \sqrt x$ ที่ $x = 9$ ประมาณค่า $\sqrt{9.2}$

💻 ในโลกคอมพิวเตอร์
  • คอมพิวเตอร์ “วาดเส้นโค้ง” ไม่เป็น — มันวาดได้แต่ เส้นตรงสั้น ๆ หลายร้อยเส้นต่อกัน (กราฟทุกรูปในเว็บนี้ก็วาดแบบนั้น)
  • เมื่อต้องคำนวณฟังก์ชันยาก ๆ อย่างรวดเร็ว เช่น ฟิสิกส์ในเกมที่ต้องคำนวณ 60 ครั้งต่อวินาที ก็มัก ใช้เส้นตรงประมาณเส้นโค้ง ในช่วงสั้น ๆ แบบเดียวกับหัวข้อนี้
⭐ โบนัส 5.2

สติกเกอร์รูปสี่เหลี่ยมจัตุรัสด้านยาว 10 ซม. ถ้าเครื่องตัดตัดเกินไปด้านละ 0.1 ซม. (ด้านยาว 10.1 ซม.)

  1. ใช้อนุพันธ์ ประมาณ ว่าพื้นที่เพิ่มขึ้นกี่ ตร.ซม. (ให้ $A(s) = s^2$)
  2. คำนวณพื้นที่ที่เพิ่มขึ้นจริง แล้วเทียบกับค่าประมาณ
  3. วาดรูปอธิบายว่าส่วนต่างเล็ก ๆ ระหว่างค่าประมาณกับค่าจริงมาจากตรงไหน

5.3 ฟังก์ชันเพิ่ม ฟังก์ชันลด และจุดวิกฤต

↗ ฟังก์ชันเพิ่ม (increasing)

x เพิ่ม แล้ว y เพิ่ม · ความชันเป็นบวก $\;f'(x) > 0$

↘ ฟังก์ชันลด (decreasing)

x เพิ่ม แล้ว y ลด · ความชันเป็นลบ $\;f'(x) \lt 0$

จุดวิกฤต (critical point)จุดที่ $f'(x) = 0$ (หรือ $f'$ หาค่าไม่ได้) ลักษณะกราฟ “แบนราบ” ชั่วขณะ อาจเป็นแบบใดแบบหนึ่งด้านล่าง
🧭 ขั้นตอนหาช่วงเพิ่ม/ลด และจุดวิกฤต
  1. หา $f'(x)$
  2. แก้สมการ $f'(x) = 0$ ได้ค่า x ของจุดวิกฤต แล้วแทนใน $f(x)$ เดิม เพื่อได้พิกัด $(x, y)$
  3. แบ่งเส้นจำนวนตามจุดวิกฤต เลือกเลขง่าย ๆ ในแต่ละช่วงไปแทนใน $f'(x)$ ดูเครื่องหมาย
  4. สรุป: $+$ = เพิ่ม, $-$ = ลด

  2. $y = x^3 - 9x^2 + 24x - 16$
  3. $y = \tfrac13x^3 - x^2 - 15x + 3$
ตัวอย่าง 5.12กำลังสี่ สามจุดวิกฤต⭐⭐⭐ ท้าทาย

$y = \tfrac14x^4 - x^3 + x^2 + 4$

5.4 ทดสอบสูงสุด–ต่ำสุดสัมพัทธ์

วิธีที่ 1: ดูเครื่องหมาย $f'$ (First derivative test)

  • $f'$ เปลี่ยนจาก + เป็น − → สูงสุดสัมพัทธ์ ⛰️
  • $f'$ เปลี่ยนจาก − เป็น + → ต่ำสุดสัมพัทธ์ 🏞️
  • ไม่เปลี่ยนเครื่องหมาย → จุดนิ่ง

วิธีที่ 2: ดู $f''$ (Second derivative test)

  • $f''(c) \lt 0$ (กราฟคว่ำ ∩) → สูงสุด
  • $f''(c) > 0$ (กราฟหงาย ∪) → ต่ำสุด
  • $f''(c) = 0$ → สรุปไม่ได้ ใช้วิธีที่ 1
🙂 จำแบบหน้ายิ้ม–หน้าบึ้ง
$f'' > 0$กราฟหงายเหมือน ปากยิ้ม ∪ → ก้นถ้วยคือจุดต่ำสุด $f'' \lt 0$กราฟคว่ำเหมือน ปากบึ้ง ∩ → ยอดคือจุดสูงสุด
ตัวอย่าง 5.13ใช้ f'' ตัดสิน⭐⭐ ปานกลาง

$f(x) = x^3 - 3x^2 - 9x + 5$ จงหาจุดวิกฤตและใช้อนุพันธ์อันดับสองบอกชนิด

5.5 ค่าสูงสุด–ต่ำสุดสัมบูรณ์บนช่วงปิด

บนช่วงปิด $[a, b]$ ฟังก์ชันต่อเนื่องจะมีค่าสูงสุดและต่ำสุด “ทั้งหมด” (สัมบูรณ์) เสมอ และเกิดได้แค่ 2 ที่

  • จุดวิกฤตในช่วง
  • ปลายช่วง $a$ หรือ $b$
🏁 ขั้นตอน (Closed interval method)
  1. หาจุดวิกฤต ($f'(x) = 0$) เก็บเฉพาะที่อยู่ในช่วง $[a,b]$
  2. แทนค่าจุดวิกฤตเหล่านั้นใน $f(x)$
  3. แทนค่าปลายช่วง $f(a)$ และ $f(b)$
  4. ค่ามากที่สุด = สูงสุดสัมบูรณ์ · ค่าน้อยที่สุด = ต่ำสุดสัมบูรณ์
ตัวอย่าง 5.14ช่วงปิด [−10, 0]⭐⭐ ปานกลาง

หาค่าสูงสุดและต่ำสุดสัมบูรณ์ของ $y = x^3 - 3x^2 - 9x + 5$ บนช่วง $[-10, 0]$

ตัวอย่าง 5.15ช่วงปิด [−2, 10]⭐⭐ ปานกลาง

$y = \tfrac13x^3 - x^2 - 15x + 3$ บนช่วง $[-2, 10]$

ตัวอย่าง 5.16ช่วงปิด [−2, 5]⭐⭐⭐ ท้าทาย

$y = \tfrac14x^4 - x^3 + x^2 + 4$ บนช่วง $[-2, 5]$

💻 ในโลกคอมพิวเตอร์: หาช่วงพีคของระบบ

จุดวิกฤตคือ “ยอดเขา” และ “ก้นหุบ” ของกราฟข้อมูล ใช้หา

  • ช่วงที่มีคนใช้งานมากที่สุด
  • ช่วงที่ราคาหุ้นกลับตัว
  • จุดที่โมเดล AI มีความผิดพลาดน้อยที่สุด (จะเห็นในบทที่ 6)
ตัวอย่าง 5.17ผู้ใช้งานพร้อมกันสูงสุดเมื่อไร⭐ ง่าย

จำนวนผู้ใช้งานพร้อมกัน (พันคน) ของแอปหนึ่ง ในช่วง 8:00–20:00 น. ประมาณได้ด้วย $U(t) = -0.5t^2 + 14t - 60$ เมื่อ $t$ คือเวลา (ชั่วโมง) จงหาเวลาที่มีผู้ใช้มากที่สุด และจำนวนผู้ใช้ตอนนั้น

⭐ โบนัส 5.3

นึกถึง จำนวนคนในโรงอาหารของมหาวิทยาลัย ตั้งแต่ 7:00 ถึง 19:00 น.

  1. วาดกราฟคร่าว ๆ (แกน x = เวลา, แกน y = จำนวนคน)
  2. บนกราฟ ชี้จุดวิกฤตทุกจุด แล้วบอกว่าแต่ละจุดเป็น สูงสุดสัมพัทธ์ หรือ ต่ำสุดสัมพัทธ์
  3. จุดใดเป็น สูงสุดสัมบูรณ์ และ ต่ำสุดสัมบูรณ์ บนช่วง [7:00, 19:00]
  4. ถ้าคุณเป็นผู้จัดการโรงอาหาร จะใช้ข้อมูลจากข้อ 2–3 ทำอะไร
🎬 กลับมาตอบคำถามเปิดบท
$\sqrt{4.1} \approx 2.025$ได้จาก เส้นสัมผัส ของ $\sqrt x$ ที่ $x = 4$ (ค่าจริงคือ 2.0248… ผิดไม่ถึง 0.001) ช่วงพีคของผู้ใช้หาได้จาก จุดวิกฤต ที่ $U'(t) = 0$ แล้วตรวจด้วย $f''$ หรือปลายช่วง — ไม่ต้องลองแทนค่าทีละชั่วโมง
ตรวจคำตอบด้วย Python (SymPy)
from sympy import symbols, diff, solve, Rational
x = symbols('x')
f = Rational(1, 4)*x**4 - x**3 + x**2 + 4
crit = solve(diff(f, x), x)
print("จุดวิกฤต:", crit)
for c in [-2] + crit + [5]:
    print("  f(%s) = %s" % (c, f.subs(x, c)))

  f(0) = 4

  f(5) = 241/4

คำถามท้ายบท แบบฝึก ไม่มีคะแนน

ลองทำเองก่อนทุกข้อ แล้วค่อยกด “ดูเฉลย” (ต้องใช้รหัสผ่านจากอาจารย์)

  1. ความชันและเส้นสัมผัส
  2. จงหาความชันของ $y = 2x^3 - 4x + 1$ ที่ $x = -1$ และ $x = 2$
  3. จงหาสมการเส้นสัมผัส $y = x^2 - 4x + 1$ ที่ $x = 3$
  4. จงหาสมการเส้นสัมผัส $y = \dfrac{4}{x}$ ที่จุด $(2, 2)$ (แยกตัวส่วน)
  5. จงหาจุดบนกราฟ $y = x^2 - 6x + 10$ ที่เส้นสัมผัสขนานกับแกน x (ความชัน = 0)
  6. ใช้เส้นสัมผัสของ $f(x) = \sqrt x$ ที่ $x = 16$ ประมาณค่า $\sqrt{16.4}$ (เส้นสัมผัสประมาณค่า)
  7. ฟังก์ชันเพิ่ม/ลด จุดวิกฤต
  8. จงหาช่วงเพิ่ม ช่วงลด และจุดวิกฤตของ $y = -(x^2) + 8x - 7$
  9. จงหาช่วงเพิ่ม ช่วงลด และจุดวิกฤตของ $y = x^3 - 12x + 2$
  10. จงหาช่วงเพิ่ม ช่วงลดของ $y = 2x^3 + 3x^2 - 36x$ (ตารางเครื่องหมาย)
  11. ฟังก์ชัน $y = x^3 + 3x$ มีจุดวิกฤตหรือไม่ เป็นฟังก์ชันเพิ่มหรือลด
  12. จุดวิกฤตของ $y = (x-1)^3 + 2$ เป็นจุดชนิดใด (รากซ้ำ)
  13. สูงสุด–ต่ำสุด
  14. ใช้อนุพันธ์อันดับสองตัดสินชนิดของจุดวิกฤตของ $f(x) = x^3 - 6x^2 + 5$
  15. หาค่าสูงสุดและต่ำสุดสัมบูรณ์ของ $f(x) = x^3 - 3x$ บนช่วง $[0, 3]$ (อย่าลืมปลายช่วง)
  16. หาค่าสูงสุดและต่ำสุดสัมบูรณ์ของ $f(x) = -(x^2) + 4x + 1$ บนช่วง $[-1, 3]$
