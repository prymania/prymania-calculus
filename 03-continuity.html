CHAPTER 03 · ลิมิต

ความต่อเนื่องของฟังก์ชัน

เงื่อนไข 3 ข้อของความต่อเนื่อง ชนิดของจุดไม่ต่อเนื่อง ฟังก์ชันหลายช่วง และการหาค่า k ให้ฟังก์ชันต่อเนื่อง

🎬 คำถามเปิดบท
  • เคยเล่นเกมที่ตัวละครเดินอยู่ดี ๆ แล้ว “วาร์ป” กระตุกไปอีกที่ไหม? บั๊กแบบนี้เกิดจากอะไร?
  • สมการอย่าง $x^3 + x - 1 = 0$ ไม่มีสูตรง่าย ๆ ให้แก้
    แต่คอมพิวเตอร์ก็ยังหาคำตอบได้ละเอียดถึงทศนิยมหลายตำแหน่ง — มันทำได้อย่างไร?
🎯 เมื่อเรียนจบบทนี้ นิสิตจะสามารถ
  1. บอกเงื่อนไข 3 ข้อของความต่อเนื่องที่จุด $x = a$ ได้
  2. จำแนกจุดไม่ต่อเนื่องแบบ “รู” “กระโดด” และ “พุ่งไปอนันต์” จากกราฟได้
  3. ตรวจสอบความต่อเนื่องของฟังก์ชันหลายช่วง (piecewise) ได้
  4. หาค่าคงที่ $k$ ที่ทำให้ฟังก์ชันต่อเนื่องได้
  5. ใช้ความต่อเนื่องหาคำตอบของสมการด้วยการแบ่งครึ่งช่วง (bisection) ได้ (เสริม)

3.1 ความต่อเนื่องคืออะไร

พูดแบบภาษาคน: ฟังก์ชันต่อเนื่องที่จุดหนึ่ง ถ้า เราวาดกราฟผ่านจุดนั้นได้โดยไม่ต้องยกปากกา ✏️

  • ไม่มีรู
  • ไม่มีรอยขาด
  • ไม่มีการกระโดด
✅ นิยาม: $f$ ต่อเนื่องที่ $x = a$ ก็ต่อเมื่อครบทั้ง 3 ข้อ
  1. $f(a)$ หาค่าได้  (มีจุดอยู่จริง)
  2. $\displaystyle\lim_{x\to a}f(x)$ หาค่าได้  (ลิมิตซ้าย = ลิมิตขวา)
  3. $\displaystyle\lim_{x\to a}f(x) = f(a)$  (ค่าที่ “กำลังมุ่งไป” ตรงกับ “ค่าจริง”)

ข้อใดข้อหนึ่งไม่ผ่าน → ไม่ต่อเนื่อง ที่ $x = a$

3.2 หน้าตาของจุดไม่ต่อเนื่อง

💡 ทำไมต้องสนใจ?
  • ทฤษฎีหลายอย่างในบทต่อ ๆ ไป ใช้ได้ เฉพาะกับฟังก์ชันที่ต่อเนื่อง
    เช่น หาค่าสูงสุด–ต่ำสุดบนช่วงปิด และหาพื้นที่ด้วยอินทิกรัล
  • ในโลกจริง ความต่อเนื่องหมายถึง “ไม่มีการกระตุก”
    เช่น ความเร็วรถไม่กระโดดจาก 40 เป็น 90 กม./ชม. ในพริบตา
⭐ โบนัส 3.1

ยกตัวอย่างสิ่งในชีวิตจริงที่เขียนเป็นกราฟแล้ว ไม่ต่อเนื่อง ให้ได้ 2 แบบจาก 3 แบบ ด้านบน (รู · กระโดด · พุ่งไปอนันต์)

  • บอกว่าแกน x และแกน y คืออะไร
  • บอกว่าไม่ต่อเนื่องที่ไหน และเป็นแบบใด

3.3 ตรวจความต่อเนื่องทีละข้อ

ตัวอย่าง 3.1พหุนาม⭐ ง่าย

กำหนด $f(x) = x^2$ จงตรวจว่า $f$ ต่อเนื่องที่ $x = -1$ หรือไม่

ตัวอย่าง 3.2ตัวส่วนเป็นศูนย์⭐ ง่าย

กำหนด $f(x) = \dfrac{x}{x-7}$ จงตรวจว่า $f$ ต่อเนื่องที่ $x = 7$ หรือไม่

ตัวอย่าง 3.3ฟังก์ชันสองช่วง⭐⭐ ปานกลาง

$$f(x) = \begin{cases} 3x - 2 &;\ x \le 2\\ x^2 &;\ x \gt 2\end{cases}$$ ต่อเนื่องที่ $x = 2$ หรือไม่

ตัวอย่าง 3.4ต้องแยกตัวประกอบก่อนหาลิมิต⭐⭐ ปานกลาง

$$f(x) = \begin{cases} x - 2 &;\ x \le 1\\[4pt] \dfrac{x^2 - 3x + 2}{x-1} &;\ x \gt 1\end{cases}$$ ต่อเนื่องที่ $x = 1$ หรือไม่

ตัวอย่าง 3.5สูตรเดิมแต่ตรวจที่จุดอื่น⭐⭐ ปานกลาง

$$f(x) = \begin{cases} x - 2 &;\ x \lt 0\\[4pt] \dfrac{x^2 - 3x + 2}{x-1} &;\ x \ge 0\end{cases}$$ ต่อเนื่องที่ $x = 0$ หรือไม่

ตัวอย่าง 3.6สามช่วง⭐⭐⭐ ท้าทาย

$$f(x) = \begin{cases} \dfrac{x^2+4x-12}{x^2+8x-20} &;\ x \lt 2\\[6pt] \dfrac{x}{3} &;\ x = 2 \\[6pt] \dfrac{x^2-4}{x^2+2x-8} &;\ x \gt 2\end{cases}$$ ต่อเนื่องที่ $x = 2$ หรือไม่

3.4 หาค่า k ที่ทำให้ฟังก์ชันต่อเนื่อง

โจทย์แนวนี้ออกสอบบ่อยมาก!

หลักคิด: บังคับให้ ลิมิตซ้าย = ลิมิตขวา = f(a) แล้วแก้สมการหา k

  1. หาลิมิตซ้ายและลิมิตขวา (ถ้ามี k อยู่ในสูตรก็ปล่อยไว้เป็นตัวแปร)
  2. ตั้งสมการให้ทุกค่าเท่ากัน
  3. แก้สมการหา k แล้วตรวจคำตอบ — ถ้าตั้งสมการแล้วขัดแย้งกัน แปลว่า ไม่มี k ที่เป็นไปได้
ตัวอย่าง 3.7k คือค่าของจุด⭐ ง่าย

$$f(x) = \begin{cases} \dfrac{x^2-9}{x-3} &;\ x \lt 3\\[4pt] k &;\ x = 3\\ x + 3 &;\ x \gt 3\end{cases}$$ หาค่า $k$ ที่ทำให้ $f$ ต่อเนื่องที่ $x = 3$

ตัวอย่าง 3.8ไม่มีคำตอบก็ได้⭐⭐ ปานกลาง

$$f(x) = \begin{cases} \dfrac{x^2-4}{x-2} &;\ x \lt 2\\[4pt] k &;\ x = 2\\ x + 1 &;\ x \gt 2\end{cases}$$ หาค่า $k$ ที่ทำให้ $f$ ต่อเนื่องที่ $x = 2$

ตัวอย่าง 3.9k อยู่ในสูตร⭐⭐ ปานกลาง

$$f(x) = \begin{cases} kx + 1 &;\ x \lt 2\\ x^2 - 1 &;\ x \ge 2\end{cases}$$ หาค่า $k$ ที่ทำให้ $f$ ต่อเนื่องทุกจุด

ตัวอย่าง 3.10สองตัวแปร⭐⭐⭐ ท้าทาย

$$f(x) = \begin{cases} x + a &;\ x \lt 1\\ 5 &;\ x = 1\\ bx^2 - 3 &;\ x \gt 1\end{cases}$$ หาค่า $a$ และ $b$ ที่ทำให้ $f$ ต่อเนื่องที่ $x = 1$

💻 ในโลกคอมพิวเตอร์: บั๊ก “วาร์ป” = ฟังก์ชันไม่ต่อเนื่อง
  • ตำแหน่งตัวละครในเกมคือฟังก์ชันของเวลา $p(t)$
  • ถ้าโปรแกรมเมอร์เขียน if/else เปลี่ยนท่าเดินกลางคัน แล้วสองท่อนไม่ต่อกันที่รอยต่อ ตัวละครจะกระโดดข้ามตำแหน่งทันที

การหาค่า $k$ ให้ฟังก์ชันต่อเนื่อง คือการแก้บั๊กนี้นั่นเอง

ตัวอย่าง 3.11แก้บั๊กตัวละครวาร์ป⭐ ง่าย

ตัวละครเดิน 2 หน่วย/วินาที ใน 3 วินาทีแรก จากนั้นออกวิ่ง 5 หน่วย/วินาที โปรแกรมเขียนตำแหน่งไว้ว่า

$$p(t) = \begin{cases} 2t &;\ 0 \le t \le 3\\ 5t + k &;\ t \gt 3\end{cases}$$
  1. ถ้าลืมใส่ $k$ (คือ $k = 0$) จะเกิดอะไรขึ้นที่ $t = 3$
  2. ต้องใช้ $k$ เท่าใดตัวละครจึงไม่วาร์ป
⭐ โบนัส 3.2

บริษัทขนส่งคิดค่าส่งพัสดุแบบนี้

$$C(w) = \begin{cases} 40 &;\ 0 \lt w \le 2\\ 10w + k &;\ w \gt 2\end{cases} \qquad (w = \text{น้ำหนักเป็น กก.})$$
  1. หาค่า $k$ ที่ทำให้ค่าส่งต่อเนื่องที่ $w = 2$ (ไม่มีราคากระโดด)
  2. ถ้าใช้ $k = 0$ ลูกค้าที่ส่งพัสดุ 2.1 กก. จะรู้สึกอย่างไร เทียบกับคนส่ง 2 กก.
  3. ในความเป็นจริง บริษัทขนส่งหลายเจ้าเลือกคิดราคาแบบ “ขั้นบันได” (กระโดด) โดยตั้งใจ คิดว่าเพราะอะไร

3.5 ฟังก์ชันไหนต่อเนื่องบ้าง (ภาพรวม)

พหุนาม

ต่อเนื่อง ทุกจุด บน $\mathbb{R}$ เช่น $x^3 - 2x + 7$

ฟังก์ชันตรรกยะ $\frac{P(x)}{Q(x)}$

ต่อเนื่องทุกจุด ยกเว้นที่ $Q(x) = 0$

รากที่สอง $\sqrt{g(x)}$

ต่อเนื่องเมื่อ $g(x) \ge 0$

ฟังก์ชันหลายช่วง

ต้อง ตรวจที่รอยต่อ ทุกจุด

ตัวอย่าง 3.12หาจุดไม่ต่อเนื่อง⭐ ง่าย

ฟังก์ชัน $f(x) = \dfrac{x+1}{x^2 - 5x + 6}$ ไม่ต่อเนื่องที่จุดใดบ้าง

3.6 ความต่อเนื่องช่วยหาคำตอบของสมการ เสริม

🌉 ทฤษฎีบทค่าระหว่างกลาง (Intermediate Value Theorem) แบบภาษาคน
ถ้า$f$ ต่อเนื่อง บนช่วง $[a, b]$ และ$f(a)$ กับ $f(b)$ มี เครื่องหมายต่างกัน (ตัวหนึ่งติดลบ อีกตัวเป็นบวก) แล้วต้องมีอย่างน้อยหนึ่งจุดระหว่าง $a$ กับ $b$ ที่ $f(x) = 0$

เหตุผล: เดินจากใต้แกน x ไปเหนือแกน x โดยไม่ยกปากกา ต้องข้ามแกน x สักที่แน่นอน

จากทฤษฎีบทนี้ได้วิธีหาคำตอบที่ง่ายมาก เรียกว่า การแบ่งครึ่งช่วง (bisection):

  1. เริ่มจากช่วง $[a, b]$ ที่ $f(a)$ กับ $f(b)$ เครื่องหมายต่างกัน
  2. หาจุดกึ่งกลาง $m = \frac{a+b}{2}$ แล้วดูเครื่องหมายของ $f(m)$
  3. เก็บครึ่งที่ปลายสองข้างยังเครื่องหมายต่างกัน (คำตอบอยู่ในครึ่งนั้นแน่นอน) ทิ้งอีกครึ่ง
  4. ทำซ้ำ — ช่วงแคบลงครึ่งหนึ่งทุกรอบ
ตัวอย่าง 3.13แบ่งครึ่งด้วยมือ⭐⭐ ปานกลาง

กำหนด $f(x) = x^2 - 2$ (คำตอบของ $f(x) = 0$ คือ $\sqrt2$)

  1. แสดงว่ามีคำตอบอยู่ในช่วง $[1, 2]$
  2. แบ่งครึ่ง 2 ครั้ง แล้วบอกช่วงใหม่
⚠️ ต้องต่อเนื่องเท่านั้น!

$f(x) = \dfrac1x$ มี $f(-1) = -1$ และ $f(1) = 1$ เครื่องหมายต่างกัน

  • แต่ ไม่มี $x$ ไหนที่ $\frac1x = 0$
  • เพราะกราฟ ขาด ที่ $x = 0$ (กระโดดข้ามแกน x ไปเลย) ทฤษฎีบทจึงใช้ไม่ได้
Bisection ในโค้ด: เหมือน binary search
def f(x):
    return x**3 + x - 1

lo, hi = 0, 1                 # f(0) = -1 < 0, f(1) = 1 > 0
for rnd in range(1, 21):
    mid = (lo + hi) / 2
    if f(lo) * f(mid) <= 0:   # เครื่องหมายต่างกัน -> คำตอบอยู่ครึ่งซ้าย
        hi = mid
    else:
        lo = mid
    if rnd in (1, 2, 3, 5, 10, 20):
        print(f"รอบ {rnd:2}: คำตอบอยู่ใน [{lo:.7f}, {hi:.7f}]")

  • การแบ่งครึ่งช่วงคือ binary search แบบเดียวกับที่ใช้ค้นหาข้อมูลในอาเรย์ที่เรียงแล้ว
  • ทุกรอบตัดทิ้งครึ่งหนึ่ง 20 รอบช่วงจึงแคบลงเหลือ $\frac{1}{2^{20}} \approx$ หนึ่งในล้าน
  • โปรแกรมคำนวณจริง (เช่นฟังก์ชันหารากในไลบรารีวิทยาศาสตร์) ใช้แนวคิดนี้เป็นพื้นฐาน

เกม ทายเลข 1–100: เพื่อนคิดเลขไว้หนึ่งตัว ทุกครั้งที่ทาย เพื่อนจะบอกแค่ “มากไป” “น้อยไป” หรือ “ถูก”

  1. ถ้าใช้กลยุทธ์ แบ่งครึ่ง (ทายตรงกลางช่วงที่เหลือทุกครั้ง) ต้องทาย อย่างมากกี่ครั้ง จึงรับประกันว่าทายถูก
  2. ถ้าเปลี่ยนเป็นเลข 1–1,000,000 ต้องทายอย่างมากกี่ครั้ง
  3. กลยุทธ์นี้เหมือนการแบ่งครึ่งช่วงหารากในหัวข้อนี้อย่างไร

from sympy import symbols, limit, Piecewise, solve
x, k = symbols('x k')
left  = limit((x**2 - 9)/(x - 3), x, 3, '-')
right = limit(x + 3, x, 3, '+')
print("ลิมิตซ้าย =", left, " ลิมิตขวา =", right)

  1. นิยามและกราฟ
  2. จงเขียนเงื่อนไข 3 ข้อของการที่ $f$ ต่อเนื่องที่ $x = a$
  3. ฟังก์ชัน $f$ มี $f(4) = 2$, $\displaystyle\lim_{x\to4^-}f(x) = 5$, $\displaystyle\lim_{x\to4^+}f(x) = 5$ ฟังก์ชันต่อเนื่องที่ $x=4$ หรือไม่ ถ้าไม่ จะแก้ $f(4)$ เป็นเท่าใดจึงจะต่อเนื่อง (ดูว่าข้อไหนไม่ผ่าน)
  4. ฟังก์ชัน $f(x) = \dfrac{x-4}{x^2-16}$ ไม่ต่อเนื่องที่จุดใด จุดไหนเป็นแบบ “รู” จุดไหนเป็นแบบ “พุ่งไปอนันต์”
  5. ตรวจความต่อเนื่อง
  6. $f(x) = \begin{cases} x^2 + 1 &;\ x \lt 1\\ 3x - 1 &;\ x \ge 1\end{cases}$ ต่อเนื่องที่ $x = 1$ หรือไม่
  7. $f(x) = \begin{cases} 2x &;\ x \lt 3\\ 5 &;\ x = 3\\ x + 3 &;\ x \gt 3\end{cases}$ ต่อเนื่องที่ $x = 3$ หรือไม่
  8. $f(x) = \begin{cases} \dfrac{x^2-1}{x+1} &;\ x \ne -1\\ -2 &;\ x = -1\end{cases}$ ต่อเนื่องที่ $x = -1$ หรือไม่
  9. หาค่าคงที่
  10. $f(x) = \begin{cases} \dfrac{x^2-4}{x-2} &;\ x \lt 2\\ k &;\ x = 2\\ x + 2 &;\ x \gt 2\end{cases}$ หาค่า $k$ ที่ทำให้ต่อเนื่องที่ $x = 2$ (ลิมิตซ้าย = ขวา = k)
  11. $f(x) = \begin{cases} kx^2 &;\ x \le 3\\ 2x + 12 &;\ x \gt 3\end{cases}$ หาค่า $k$
  12. $f(x) = \begin{cases} \dfrac{x^2 + x - 6}{x - 2} &;\ x \ne 2\\ k &;\ x = 2\end{cases}$ หาค่า $k$
  13. $f(x) = \begin{cases} ax + 1 &;\ x \lt 1\\ 4 &;\ x = 1\\ x^2 + b &;\ x \gt 1\end{cases}$ หาค่า $a$ และ $b$ ที่ทำให้ต่อเนื่องที่ $x = 1$ (2 สมการ 2 ตัวแปร)
  14. $f(x) = \begin{cases} \dfrac{\sqrt{x} - 2}{x - 4} &;\ x \ne 4\\ k &;\ x = 4\end{cases}$ หาค่า $k$
  15. แบ่งครึ่งช่วง (เสริม)
  16. กำหนด $f(x) = x^2 - 3$ จงแสดงว่ามีคำตอบของ $f(x) = 0$ ในช่วง $[1, 2]$ แล้วแบ่งครึ่ง 2 ครั้ง (แบ่งครึ่งช่วง (เสริม))
