เส้นสัมผัสคือเส้นตรงที่ “แตะ” กราฟที่จุดหนึ่ง โดยมีความชันเท่ากับความชันของกราฟที่จุดนั้นพอดี ใช้สมการ จุด–ความชัน:

📏 สมการเส้นสัมผัสที่ $x = x_1$
$$y - y_1 = m(x - x_1) \qquad\text{โดย}\quad y_1 = f(x_1),\ \ m = f'(x_1)$$
  1. $x_1$ = จุดที่โจทย์กำหนด
  2. $y_1$ = แทน $x_1$ ใน ฟังก์ชันเดิม $f(x)$
  3. $m$ = ดิฟ $f$ แล้วแทน $x_1$ ใน $f'(x)$
  4. แทนลงสมการ แล้วจัดให้อยู่ในรูป $y = mx + c$

ทดสอบสูงสุด–ต่ำสุดสัมพัทธ์

วิธีที่ 1: ดูเครื่องหมาย $f'$ (First derivative test)

  • $f'$ เปลี่ยนจาก + เป็น − → สูงสุดสัมพัทธ์ ⛰️
  • $f'$ เปลี่ยนจาก − เป็น + → ต่ำสุดสัมพัทธ์ 🏞️
  • ไม่เปลี่ยนเครื่องหมาย → จุดนิ่ง

วิธีที่ 2: ดู $f''$ (Second derivative test)

  • $f''(c) \lt 0$ (กราฟคว่ำ ∩) → สูงสุด
  • $f''(c) > 0$ (กราฟหงาย ∪) → ต่ำสุด
  • $f''(c) = 0$ → สรุปไม่ได้ ใช้วิธีที่ 1
🙂 จำแบบหน้ายิ้ม–หน้าบึ้ง

$f'' > 0$ กราฟหงายเหมือน ปากยิ้ม ∪ ก้นถ้วยคือจุดต่ำสุด · $f'' \lt 0$ กราฟคว่ำเหมือน ปากบึ้ง ∩ ยอดคือจุดสูงสุด

$f(x) = x^3 - 3x^2 - 9x + 5$ จงหาจุดวิกฤตและใช้อนุพันธ์อันดับสองบอกชนิด

$f'(x) = 3x^2 - 6x - 9 = 3(x-3)(x+1)$ → $x = -1,\ 3$ · $f''(x) = 6x - 6$

$f''(-1) = -12 \lt 0$ → สูงสุดสัมพัทธ์ที่ $(-1, f(-1)) = (-1, 10)$

$f''(3) = 12 > 0$ → ต่ำสุดสัมพัทธ์ที่ $(3, f(3)) = (3, -22)$

  1. หาจุดวิกฤต ($f'(x) = 0$) เก็บเฉพาะที่อยู่ในช่วง $[a,b]$

 ฟังก์ชัน $y = x^3 + 3x$ มีจุดวิกฤตหรือไม่ เป็นฟังก์ชันเพิ่มหรือลด

$y' = 3x^2 + 3 > 0$ ทุก x จึง ไม่มีจุดวิกฤต และเป็นฟังก์ชันเพิ่มตลอด

 จุดวิกฤตของ $y = (x-1)^3 + 2$ เป็นจุดชนิดใด

$y' = 3(x-1)^2 = 0 \Rightarrow x = 1$ · $y'$ เป็นบวกทั้งสองข้าง → จุดนิ่ง (1, 2) ไม่ใช่สูงสุด/ต่ำสุด

 สูงสุด–ต่ำสุด ใช้อนุพันธ์อันดับสองตัดสินชนิดของจุดวิกฤตของ $f(x) = x^3 - 6x^2 + 5$

$f' = 3x^2 - 12x = 3x(x-4)$ · $f'' = 6x - 12$ · $f''(0) = -12$ → สูงสุดสัมพัทธ์ (0, 5) · $f''(4) = 12$ → ต่ำสุดสัมพัทธ์ (4, −27)

 หาค่าสูงสุดและต่ำสุดสัมบูรณ์ของ $f(x) = x^3 - 3x$ บนช่วง $[0, 3]$

$f' = 3(x-1)(x+1)$ เก็บ x = 1 · $f(0) = 0,\ f(1) = -2,\ f(3) = 18$ → สูงสุด 18 ที่ x = 3 · ต่ำสุด −2 ที่ x = 1

 หาค่าสูงสุดและต่ำสุดสัมบูรณ์ของ $f(x) = -x^2 + 4x + 1$ บนช่วง $[-1, 3]$

$f' = -2x + 4 = 0 \Rightarrow x = 2$ · $f(-1) = -4,\ f(2) = 5,\ f(3) = 4$ → สูงสุด 5 ที่ x = 2 · ต่ำสุด −4 ที่ x = −1
