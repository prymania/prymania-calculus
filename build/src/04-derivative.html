อัตราการเปลี่ยนแปลงเฉลี่ย

ขับรถมหาสารคาม → ขอนแก่น 75 กม. ใช้เวลา 1.5 ชม. ความเร็วเฉลี่ย$\dfrac{75}{1.5} = 50$ กม./ชม.

นี่แหละคือ อัตราการเปลี่ยนแปลงเฉลี่ย = ระยะทางเปลี่ยนไปเท่าไร ต่อเวลาที่เปลี่ยนไป

📐 อัตราการเปลี่ยนแปลงเฉลี่ย เมื่อ x เปลี่ยนจาก $x$ เป็น $x + h$
$$\frac{\Delta y}{\Delta x} = \frac{f(x+h) - f(x)}{(x+h) - x} = \frac{f(x+h) - f(x)}{h} \quad\text{หรือ}\quad \frac{f(x_2) - f(x_1)}{x_2 - x_1}$$

ในทางกราฟ คือ ความชันของเส้นตัด (secant line) ที่ลากผ่านสองจุดบนกราฟ

$f(1) = 3,\ f(3) = 7$ → $\dfrac{7 - 3}{3 - 1} = $ 2 (เส้นตรง อัตราเฉลี่ยเท่ากับความชันเสมอ)

  2. $f(x) = x^2 - 5x$ เมื่อ x เปลี่ยนจาก −10 เป็น 10
  3. $f(x) = \dfrac{x-2}{x+2}$ เมื่อ x เปลี่ยนจาก −5 เป็น 5
  4. $f(x) = 3x^2 + 2x + 7$ เมื่อ x เปลี่ยนจาก 0 เป็น 10

  3. $f(5) = \tfrac37,\ f(-5) = \tfrac{-7}{-3} = \tfrac73$ → $\dfrac{\frac37 - \frac73}{10} = \dfrac{-\frac{40}{21}}{10} = $ −4/21 ≈ −0.19
  4. $f(10) = 327,\ f(0) = 7$ → $\dfrac{320}{10} = $ 32

อัตราการเปลี่ยนแปลงขณะใด ๆ = อนุพันธ์

  • มาตรวัดความเร็วในรถไม่ได้บอกความเร็วเฉลี่ย แต่บอกความเร็ว ณ วินาทีนั้น
  • ทำได้โดยให้ช่วงเวลา $h$ เล็กลงจนเข้าใกล้ 0 — นั่นคือใช้ลิมิตจากบทที่ 2!
⭐ นิยามอนุพันธ์ (Derivative)
$$f'(x) = \lim_{h\to0}\frac{f(x+h) - f(x)}{h}$$
เขียนแทนได้$f'(x),\ y',\ \dfrac{dy}{dx},\ \dfrac{d}{dx}f(x)$ เรียกว่า“การดิฟ” (differentiate) ในทางกราฟ$f'(a)$ = ความชันของเส้นสัมผัส (tangent line) ที่จุด $x = a$

ลองเลื่อน h ให้เล็กลง

  • จุด Q ไหลเข้าหา P
  • เส้นตัดสีชมพูค่อย ๆ ทับเส้นสัมผัสสีเขียว

ความชันของเส้นตัดวิ่งเข้าหาความชันของเส้นสัมผัส — นี่คือความหมายของอนุพันธ์

ข้อมูลในมือถือหรือชีวิตประจำวันหลายอย่างคือ “อัตราการเปลี่ยนแปลงขณะใด ๆ” (อนุพันธ์) เช่น หน้าปัดความเร็วรถ = อนุพันธ์ของระยะทางเทียบกับเวลา

  • ยกตัวอย่างอื่นอีก 2 อย่าง
  • บอกให้ชัดว่าเป็นอนุพันธ์ ของอะไร เทียบกับ อะไร และมีหน่วยเป็นอะไร

ตัวอย่างที่ถูก

ความเร็วดาวน์โหลดอนุพันธ์ของปริมาณข้อมูลเทียบกับเวลา (MB/วินาที) อัตราแบตลดอนุพันธ์ของเปอร์เซ็นต์แบตเทียบกับเวลา (%/ชั่วโมง) อัตราการเต้นหัวใจอนุพันธ์ของจำนวนครั้งที่หัวใจเต้นเทียบกับเวลา (ครั้ง/นาที) อัตราสิ้นเปลืองน้ำมันอนุพันธ์ของน้ำมันที่ใช้เทียบกับระยะทาง (ลิตร/กม.) ยอดผู้ติดตามโตต่อวันอนุพันธ์ของจำนวนผู้ติดตามเทียบกับเวลา (คน/วัน)

เกณฑ์: ต้องบอก “ของอะไร เทียบกับอะไร” ได้ถูก หน่วยต้องเป็น “ปริมาณ ÷ ตัวแปร” · ค่าที่เป็นปริมาณสะสม (เช่น ระยะทางรวม) ไม่นับ

หาอัตราการเปลี่ยนแปลงขณะใด ๆ ของ $f(x) = x^2 + 5$ แล้วหาค่าเมื่อ $x = 1$

$$\begin{aligned}f'(x) &= \lim_{h\to0}\frac{[(x+h)^2+5] - [x^2+5]}{h} = \lim_{h\to0}\frac{x^2+2xh+h^2+5-x^2-5}{h}\\ &= \lim_{h\to0}\frac{2xh+h^2}{h} = \lim_{h\to0}\frac{h(2x+h)}{h} = \lim_{h\to0}(2x+h) = 2x\end{aligned}$$

เมื่อ $x = 1$: $f'(1) = $ 2
  1. $f(x) = 3x^2 - 5$ ขณะ $x = 10$
  2. $f(x) = x^3 - x^2$ ขณะ $x = 5$

a) $f(x+h) - f(x) = 3(x^2+2xh+h^2) - 5 - 3x^2 + 5 = 6xh + 3h^2$

$$f'(x) = \lim_{h\to0}\frac{6xh+3h^2}{h} = \lim_{h\to0}(6x+3h) = 6x \quad\Rightarrow\quad f'(10) = 60$$

b) ใช้ $(x+h)^3 = x^3 + 3x^2h + 3xh^2 + h^3$

$$\begin{aligned}f(x+h)-f(x) &= (3x^2h + 3xh^2 + h^3) - (2xh + h^2)\\ f'(x) &= \lim_{h\to0}(3x^2 + 3xh + h^2 - 2x - h) = 3x^2 - 2x\end{aligned}$$

$f'(5) = 75 - 10 = $ 65

ลองในโค้ด: ให้คอมพิวเตอร์ “ดิฟ” ด้วยการลด h

คอมพิวเตอร์ไม่รู้จักลิมิต แต่เราเลียนแบบได้ด้วยลูปธรรมดา

  • คำนวณความชันของเส้นตัดโดยใช้ $h$ เล็กลงเรื่อย ๆ แล้วดูว่าคำตอบวิ่งเข้าหาเลขอะไร
  • ใช้ $f(x) = x^2 + 5$ จากตัวอย่างด้านบน ซึ่งรู้แล้วว่า $f'(1) = 2$
def f(x): return x**2 + 5 x = 1 for h in [1, 0.1, 0.01, 0.001, 0.000001, 1e-15]: slope = (f(x + h) - f(x)) / h print(f"h = {h:<8} ความชันเส้นตัด = {slope}")
💻 ในโลกคอมพิวเตอร์
  • ยิ่ง $h$ เล็ก ความชันยิ่งเข้าใกล้ 2
  • แต่ พอ $h$ เล็กเกินไป (เช่น $10^{-15}$) คำตอบกลับเพี้ยน เพราะตัวเลขทศนิยมในคอมพิวเตอร์ (floating point) มีความละเอียดจำกัด

โปรแกรมคำนวณจริงจึงไม่ลด $h$ ไปเรื่อย ๆ แต่ใช้ สูตรดิฟ ที่จะเรียนในหัวข้อถัดไปแทน

❌ ข้อผิดพลาดยอดฮิต

$\dfrac{d}{dx}[f\cdot g] \ne f'\cdot g'$ — ดิฟผลคูณ ไม่ใช่ เอาดิฟมาคูณกัน!

ที่ถูก$x\cdot x = x^2$ ดิฟได้ $2x$ ถ้าเอาดิฟมาคูณ$1 \cdot 1 = 1$ ✗

ดิฟผลคูณ

$$\frac{d}{dx}(\text{หน้า}\cdot\text{หลัง}) = \text{หน้า}\cdot\text{หลัง}' + \text{หลัง}\cdot\text{หน้า}'$$

ดิฟผลหาร

💻 กฎลูกโซ่ = วิธีที่ AI เรียนรู้

ลองสร้าง “AI” ที่เล็กที่สุดในโลก

ปุ่มปรับได้มีปุ่มเดียวคือ $w$ วิธีทาย$\hat y = w\cdot x$ เป้าหมายทายให้ใกล้คำตอบจริง $y$ จึงวัด ความผิดพลาด (loss) ด้วย
$$L = (\,wx - y\,)^2$$

คำถามที่ AI ต้องตอบทุกครั้งคือ “ถ้าขยับ $w$ นิดหนึ่ง ความผิดพลาดจะเพิ่มหรือลด?”

  • คำถามนี้ก็คือ $\dfrac{dL}{dw}$
  • $L$ เป็นฟังก์ชันซ้อน (ก้อนกำลังสอง ไส้ในคือ $wx - y$) จึงใช้กฎลูกโซ่
$$\frac{dL}{dw} = \underbrace{2(wx - y)}_{\text{ดิฟก้อนนอก}}\cdot\underbrace{x}_{\text{ดิฟไส้ในเทียบ } w}$$
  • ถ้า $\dfrac{dL}{dw} \lt 0$ แปลว่าเพิ่ม $w$ แล้วผิดน้อยลง → เพิ่ม $w$
  • ถ้า $\dfrac{dL}{dw} \gt 0$ → ลด $w$

สรุปเป็นกฎข้อเดียว ทำซ้ำไปเรื่อย ๆ เรียกว่า gradient descent (จะได้เจออีกครั้งในบทที่ 6)

$$w_{\text{ใหม่}} = w - (\text{ก้าวเล็ก ๆ})\cdot\dfrac{dL}{dw}$$

ข้อมูลหนึ่งชุดคือ $x = 2,\ y = 6$ (คำตอบที่ถูกคือ $w = 3$) ตอนนี้โมเดลมี $w = 1$ จงหา $L$ และ $\dfrac{dL}{dw}$ แล้วบอกว่าควรเพิ่มหรือลด $w$

ทาย $\hat y = 1\cdot 2 = 2$ → $L = (2 - 6)^2 = 16$

$\dfrac{dL}{dw} = 2(wx - y)\cdot x = 2(2 - 6)\cdot 2 = -16$ → ติดลบ จึง เพิ่ม w

ถ้าใช้ก้าว 0.05: $w_{\text{ใหม่}} = 1 - 0.05(-16) = 1.8$ → ทายได้ $3.6$ ใกล้ 6 ขึ้น และ $L = (3.6-6)^2 = 5.76$ ลดลงจาก 16

 x, y = 2, 6 # ข้อมูล: ป้อน 2 ต้องได้ 6 w = 1 # เริ่มจากค่าที่ผิด step = 0.05 # ขนาดก้าว (learning rate) for rnd in range(1, 9): L = (w*x - y)**2 dL_dw = 2*(w*x - y) * x # กฎลูกโซ่ w = w - step * dL_dw print(f"รอบ {rnd}: loss = {L:7.4f} -> w ใหม่ = {w:.4f}")
💻 ในโลกคอมพิวเตอร์

โครงข่ายประสาทเทียม (neural network) ที่อยู่เบื้องหลัง ChatGPT หรือระบบจดจำใบหน้า

  • คือฟังก์ชันซ้อนกันหลายร้อยชั้น $f(g(h(\cdots)))$
  • มีปุ่ม $w$ เป็นพันล้านปุ่ม

แต่หลักการเหมือนตัวอย่างนี้ทุกประการ: ใช้ กฎลูกโซ่ ไล่ดิฟย้อนจากชั้นนอกสุดเข้าไปทีละชั้น (เรียกว่า backpropagation) แล้วขยับทุกปุ่มไปทางที่ทำให้ผิดน้อยลง

ทดลองกับ AI ตัวจิ๋วด้านบน (ข้อมูล $x = 2,\ y = 6$ เริ่มที่ $w = 1$) แต่เปลี่ยน ขนาดก้าว จาก 0.05

  1. ใช้ขนาดก้าว 0.25 คำนวณ $w$ หลังก้าวที่ 1, 2, 3
  2. ใช้ขนาดก้าว 0.3 คำนวณ $w$ หลังก้าวที่ 1, 2
  3. สรุปว่าขนาดก้าวที่ใหญ่เกินไปทำให้เกิดอะไรขึ้น

ใช้ $\dfrac{dL}{dw} = 2(wx - y)\cdot x = 8w - 24$

ข้อ 1 (ก้าว 0.25)$w$: 1 → 5 → 1 → 5 … เด้งไปมา ไม่ลงที่ 3 สักที ข้อ 2 (ก้าว 0.3)$w$: 1 → 5.8 → −0.92 … กระเด็นออกห่างคำตอบ 3 มากขึ้นเรื่อย ๆ

วิธีคิด: $w_{\text{ใหม่}} = w - \eta(8w - 24)$ เช่น ก้าว 0.25: $1 - 0.25(8 - 24) = 1 + 4 = 5$

ข้อ 3: ก้าวใหญ่เกินจะ “ก้าวข้าม” จุดต่ำสุด ทำให้เด้งไปมา (0.25) หรือหลุดออกไปเรื่อย ๆ (0.3) — ต้องเลือกขนาดก้าวให้พอดี เป็นงานสำคัญของวิศวกร AI

เกณฑ์: ตัวเลขข้อ 1–2 ต้องถูก และข้อ 3 ต้องบอกว่าก้าวใหญ่เกินทำให้ไม่ลู่เข้าหาคำตอบ

ดิฟฟังก์ชันประกอบ $(f\circ g)'$

🔗 สูตร (คือกฎลูกโซ่ในอีกรูปแบบ)
$$(f\circ g)'(x) = f'(g(x))\cdot g'(x)$$

ขั้นตอน

  1. หา $f'$ และ $g'$ ก่อน
  2. เอา $g(x)$ ไปแทนใน $f'$
  3. คูณด้วย $g'(x)$

กำหนด $f(x) = 2x^2 + 3$ และ $g(x) = 3x + 5$ จงหา $(f\circ g)'(x)$ และ $(g\circ f)'(x)$

$f'(x) = 4x$, $g'(x) = 3$

$(f\circ g)'(x) = f'(g(x))\cdot g'(x) = 4(3x+5)\cdot 3 = $ $12(3x+5)$

$(g\circ f)'(x) = g'(f(x))\cdot f'(x) = 3\cdot 4x = $ $12x$  (เพราะ $g'$ เป็นค่าคงที่ 3 แทนอะไรก็ได้ 3)
