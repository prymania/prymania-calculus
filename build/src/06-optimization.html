เงื่อนไขกว้าง x ยาว y: $2x + 2y = 40 \Rightarrow y = 20 - x$ ฟังก์ชัน$A = x(20 - x) = 20x - x^2$ ดิฟ = 0$A' = 20 - 2x = 0 \Rightarrow x = 10,\ y = 10$ ตรวจ$A'' = -2 \lt 0$ → สูงสุด ✓ ตอบสี่เหลี่ยมจัตุรัส 10×10 พื้นที่ 100 ตร.ซม.

นำกระดาษแข็งรูปสี่เหลี่ยมจัตุรัสขนาด 12×12 ซม. มาตัดมุมทั้งสี่ออกเป็นสี่เหลี่ยมจัตุรัสด้านละ x ซม. แล้วพับขึ้นเป็นกล่องไม่มีฝา จงหา x ที่ทำให้กล่องมีปริมาตรมากที่สุด

ฟังก์ชันฐานกว้าง $12 - 2x$ สูง $x$ → $V(x) = x(12 - 2x)^2$ โดย $0 \lt x \lt 6$ ดิฟผลคูณ + ลูกโซ่
$$\begin{aligned} V'(x) &= (12-2x)^2 + x\cdot 2(12-2x)(-2)\\ &= (12-2x)(12 - 2x - 4x) = (12-2x)(12-6x) \end{aligned}$$
ดิฟ = 0$x = 6$ (ตัดทิ้ง กล่องแบน ปริมาตร 0) หรือ $x = 2$ ตอบ$V(2) = 2\cdot 8^2 = 128$ → ตัดมุมด้านละ 2 ซม. ได้ปริมาตรมากสุด 128 ลบ.ซม.

ต้องการกล่องมีฝา ฐานเป็นสี่เหลี่ยมจัตุรัส จุของได้ 1,000 ลบ.ซม. จงหาขนาดกล่องที่ใช้กระดาษ (พื้นที่ผิว) น้อยที่สุด

เงื่อนไขฐานกว้าง $x$ สูง $h$: ปริมาตร $x^2h = 1000 \Rightarrow h = \dfrac{1000}{x^2}$ ฟังก์ชันพื้นที่ผิว (ฐาน + ฝา + ข้าง 4 ด้าน): $S = 2x^2 + 4xh = 2x^2 + \dfrac{4000}{x}$ ดิฟ = 0$S'(x) = 4x - \dfrac{4000}{x^2} = 0 \Rightarrow x^3 = 1000 \Rightarrow x = 10$ ตรวจ$S''(x) = 4 + \dfrac{8000}{x^3} \gt 0$ → ต่ำสุด ✓ ตอบ$h = \dfrac{1000}{100} = 10$ → กล่องลูกบาศก์ 10×10×10 ซม. ใช้กระดาษ 600 ตร.ซม.

เทียบ: กล่องฐาน 20×20 สูง 2.5 ซม. จุเท่ากัน แต่ใช้กระดาษ $800 + 200 = 1{,}000$ ตร.ซม. — มากกว่าถึง 67%

กระป๋องน้ำอัดลมเป็น ทรงกระบอก จุ 330 มล. (= 330 ลบ.ซม.) ถ้าต้องการใช้แผ่นอะลูมิเนียม (พื้นที่ผิว) น้อยที่สุด

ปริมาตร$V = \pi r^2 h = 330$ พื้นที่ผิว$S = 2\pi r^2 + 2\pi r h$ (ฝา + ก้น + ผนัง)
  1. แสดงว่ากระป๋องที่ประหยัดที่สุดต้องมี ความสูง = 2 เท่าของรัศมี (สูงเท่าความกว้าง)
  2. กระป๋องจริงสูงกว่าความกว้างเกือบ 2 เท่า คิดว่าบริษัทผลิตกระป๋องแบบนั้นเพราะอะไร

ข้อ 1

$$\begin{aligned} h &= \frac{330}{\pi r^2} \;\Rightarrow\; S(r) = 2\pi r^2 + \frac{660}{r}\\ S'(r) &= 4\pi r - \frac{660}{r^2} = 0 \;\Rightarrow\; \pi r^3 = 165\\ h &= \frac{330}{\pi r^2} = \frac{2\cdot 165}{\pi r^2} = \frac{2\pi r^3}{\pi r^2} = 2r \end{aligned}$$

(ได้ $r \approx 3.74$ ซม. และ $h \approx 7.49$ ซม.)

ข้อ 2 (ตอบได้หลายแบบ):

  • ถือถนัดมือ ใส่ตู้กดน้ำและเครื่องบรรจุมาตรฐานได้
  • ดูมีปริมาณมากกว่า และพิมพ์ฉลากได้พื้นที่มากกว่า

ปัญหาธุรกิจ: รายได้และกำไร

💰 ศัพท์ที่ต้องรู้
รายได้ $R$ราคา × จำนวนที่ขาย ต้นทุน $C$เงินที่จ่ายเพื่อผลิต กำไร $P$$R - C$

ลดราคาลง → ขายได้มากขึ้น แต่ได้เงินต่อชิ้นน้อยลง จึงต้องหา “จุดพอดี”

เราทำ PryFlix เก็บค่าสมาชิกเดือนละ 200 บาท มีสมาชิก 1,000 คน สังเกตว่าทุก ๆ การลดราคา 10 บาท จะมีสมาชิกเพิ่ม 100 คน ควรตั้งราคาเท่าใดจึงได้รายได้มากที่สุด และได้รายได้เท่าใด

ตั้งตัวแปร$x$ = จำนวนครั้งที่ลดราคาครั้งละ 10 บาท ราคา $200 - 10x$  ·  สมาชิก $1000 + 100x$
$$R(x) = (1000 + 100x)(200 - 10x) = 200{,}000 + 10{,}000x - 1{,}000x^2$$
ดิฟ = 0$R'(x) = 10{,}000 - 2{,}000x = 0 \Rightarrow x = 5$ ตรวจ$R'' = -2{,}000 \lt 0$ สูงสุด ✓ ตอบราคา $200 - 50 = $ 150 บาท สมาชิก 1,500 คน → รายได้สูงสุด 225,000 บาท/เดือน

ร้านเค้กตั้งราคาชิ้นละ 50 บาท ขายได้เดือนละ 100 ชิ้น ถ้าลดราคาลงทุก 1 บาท จะขายได้เพิ่ม 5 ชิ้น ควรตั้งราคาเท่าใด และได้ยอดขายกี่บาท

ตั้งตัวแปรคราวนี้ให้ $x$ = ราคาเค้กโดยตรง → ลดไป $50 - x$ บาท ขายได้ $100 + 5(50 - x) = 350 - 5x$ ชิ้น ฟังก์ชัน$R(x) = x(350 - 5x) = 350x - 5x^2$ ดิฟ = 0$R'(x) = 350 - 10x = 0 \Rightarrow x = 35$  และ $R'' = -10 \lt 0$ ✓

ตั้งราคา 35 บาท ขาย 175 ชิ้น ได้ 6,125 บาท/เดือน

บริษัทผลิตสินค้า $x$ ชิ้น มีต้นทุน $C(x) = x^2 - 4x + 5$ บาท และรายได้ $R(x) = 20x - x^2$ บาท จงหาจำนวนที่ควรผลิตเพื่อให้กำไรสูงสุด และกำไรสูงสุดเท่าใด

ปัญหาการเคลื่อนที่

ลูกบอลถูกโยนขึ้นจากความสูง 1 เมตร ความสูงหลังผ่านไป $t$ วินาทีคือ $h(t) = -5t^2 + 20t + 1$ เมตร ลูกบอลขึ้นไปได้สูงสุดเท่าใด เมื่อใด

หลักคิดจุดสูงสุดคือจุดที่ความเร็วเป็นศูนย์ ดิฟ = 0$h'(t) = -10t + 20 = 0 \Rightarrow t = 2$ วินาที ตอบ$h(2) = -20 + 40 + 1 = 21$ → สูงสุด 21 เมตร ที่ t = 2 วินาที

ต้นทุนรวมของการผลิต $x$ ชิ้นคือ $C(x) = 2x^2 + 50x + 800$ บาท ควรผลิตกี่ชิ้นเพื่อให้ ต้นทุนเฉลี่ยต่อชิ้น ต่ำที่สุด

ฟังก์ชันต้นทุนเฉลี่ย $\bar C(x) = \dfrac{C(x)}{x} = 2x + 50 + \dfrac{800}{x}$ ดิฟ = 0$\bar C'(x) = 2 - \dfrac{800}{x^2} = 0 \Rightarrow x^2 = 400 \Rightarrow x = 20$ ตรวจ$\bar C''(x) = \dfrac{1600}{x^3} > 0$ ต่ำสุด ✓ ตอบ$\bar C(20) = 40 + 50 + 40 = 130$ → ผลิต 20 ชิ้น ต้นทุนเฉลี่ยต่ำสุด 130 บาท/ชิ้น

Gradient descent: ให้คอมพิวเตอร์เดินหาจุดต่ำสุดเอง เสริม

  • ทุกข้อในบทนี้เราแก้สมการ $f'(x) = 0$ ได้
  • แต่ฟังก์ชันในงานจริง (เช่น ความผิดพลาดของโมเดล AI) ซับซ้อนจนแก้สมการตรง ๆ ไม่ได้

คอมพิวเตอร์จึงใช้วิธี “เดินลงเขาทีละก้าว”

⛷️ Gradient descent
$$x_{\text{ใหม่}} = x - (\text{ขนาดก้าว})\times f'(x)$$
  • ถ้า $f'(x) \lt 0$ (กราฟลงไปทางขวา) → $x$ เพิ่มขึ้น เดินไปทางขวา
  • ถ้า $f'(x) \gt 0$ (กราฟขึ้นไปทางขวา) → $x$ ลดลง เดินไปทางซ้าย
  • ยิ่งชันยิ่งก้าวยาว และเมื่อถึงก้นหุบ $f'(x) \approx 0$ ก็หยุดเดินเอง

ลองปรับ “ขนาดก้าว” (ในวงการ AI เรียกว่า learning rate) แล้วกดก้าวหลาย ๆ ครั้ง:

  • เล็กมาก (0.02) — ไปถูกทางแต่ช้ามาก ต้องเดินหลายร้อยก้าว
  • พอดี (0.1–0.5) — เข้าใกล้ $x = 3$ อย่างรวดเร็ว
  • ใหญ่เกิน (1.0 ขึ้นไป) — ก้าวข้ามหุบไปมา ไม่ลงสักที หรือกระเด็นหลุดออกไปเลย

$f(x) = (x-3)^2 + 1$ เริ่มที่ $x = 0$ ใช้ขนาดก้าว 0.1 จงหาตำแหน่งหลังเดิน 2 ก้าว

ความชัน$f'(x) = 2(x - 3)$ ก้าวที่ 1$f'(0) = -6$ → $x = 0 - 0.1(-6) = 0.6$ ก้าวที่ 2$f'(0.6) = -4.8$ → $x = 0.6 - 0.1(-4.8) = $ 1.08

กำลังเดินเข้าหาจุดต่ำสุด $x = 3$

 def df(x): # f(x) = (x - 3)**2 + 1 -> f'(x) = 2(x - 3) return 2 * (x - 3) for lr in [0.02, 0.1, 0.4, 1.0, 1.1]: x = 0.0 for step in range(20): x = x - lr * df(x) print(f"ขนาดก้าว {lr:<4} เดิน 20 ก้าว ได้ x = {x:.4f}")

  • “x” ไม่ใช่ตัวเลขตัวเดียว แต่เป็น ปุ่มปรับนับล้านนับพันล้านปุ่ม
  • “ความชัน” ของแต่ละปุ่มคำนวณด้วยกฎลูกโซ่ (backpropagation) จากบทที่ 4

การเลือก learning rate ให้พอดี เป็นงานสำคัญของวิศวกร AI เลยทีเดียว

ลองจินตนาการว่าคุณเป็นลูกบอลอยู่บนภูเขาที่มี หมอกหนามาก มองไม่เห็นภาพรวม รู้แค่ความชันใต้เท้าตัวเอง แล้วเดินลงเขาด้วย gradient descent

ฟังก์ชัน $f(x) = x^4 - 4x^2 + x$ มีหุบ 2 หุบ คือที่ $x \approx -1.47$ ($f \approx -5.44$) และ $x \approx 1.35$ ($f \approx -2.62$)

  1. หุบไหนคือ “จุดต่ำสุดจริง” (ต่ำสุดสัมบูรณ์)
  2. ถ้าเริ่มเดินที่ $x = 2$ ลูกบอลจะไปจบที่หุบไหน และนี่เป็นปัญหาอย่างไร
  3. เสนอวิธีแก้ปัญหานี้ อย่างน้อย 1 วิธี

ข้อ 1: หุบที่ $x \approx -1.47$ เพราะค่าต่ำกว่า (−5.44 < −2.62)

ข้อ 2: เริ่มที่ $x = 2$ ความชันเป็นบวก ลูกบอลเดินไปทางซ้ายแล้ว ติดอยู่ในหุบ $x \approx 1.35$ (ต่ำสุดสัมพัทธ์) เพราะที่นั่นความชันเป็น 0 แล้ว — มันไม่รู้ว่ามีหุบที่ลึกกว่าอยู่อีกฝั่ง AI จึงอาจได้คำตอบ “ดีพอใช้” แต่ไม่ใช่ “ดีที่สุด”

ข้อ 3 (ตอบได้หลายแบบ):

  • เริ่มเดินหลาย ๆ จุดแล้วเลือกคำตอบที่ดีที่สุด
  • เพิ่ม “แรงเฉื่อย” ให้ลูกบอลกลิ้งข้ามเนินเตี้ย ๆ ได้ (momentum)
  • ใช้ก้าวใหญ่ช่วงแรกแล้วค่อย ๆ ลดขนาดก้าว

เกณฑ์: ข้อ 1–2 ต้องแยก “ต่ำสุดสัมพัทธ์” กับ “ต่ำสุดสัมบูรณ์” ได้ · ข้อ 3 ให้คะแนนวิธีที่สมเหตุสมผล
