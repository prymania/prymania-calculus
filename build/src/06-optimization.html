และ: AI อย่าง ChatGPT ถูกฝึกด้วยการหาค่า “ผิดพลาดน้อยที่สุด” ของฟังก์ชันที่มีตัวแปรเป็นพันล้านตัว — ตั้ง $f'(x) = 0$ แล้วแก้สมการแบบในบทนี้คงไม่ไหว แล้วคอมพิวเตอร์ทำอย่างไร?

ปัญหาพื้นที่และปริมาตร

มีรั้วยาว 1,000 เมตร ต้องการกั้นที่ดินรูปสี่เหลี่ยมมุมฉากริมแม่น้ำ โดยด้านที่ติดแม่น้ำไม่ต้องกั้นรั้ว จงหาขนาดที่ทำให้ได้พื้นที่มากที่สุด และพื้นที่นั้นเป็นเท่าใด

เงื่อนไข (รั้ว)$2x + y = 1000 \Rightarrow y = 1000 - 2x$ ฟังก์ชัน (พื้นที่)$A = xy = x(1000 - 2x) = 1000x - 2x^2$ ดิฟ = 0$A'(x) = 1000 - 4x = 0 \Rightarrow x = 250$ ตรวจ$A''(x) = -4 \lt 0$ → สูงสุด ✓

ด้านกว้าง (ตั้งฉากแม่น้ำ) 250 ม. ด้านยาว $y = 500$ ม. → พื้นที่มากที่สุด 125,000 ตร.ม.

สี่เหลี่ยมผืนผ้ามีความยาวรอบรูป 40 ซม. จะมีพื้นที่มากที่สุดเท่าใด

ให้กว้าง x ยาว y: $2x + 2y = 40 \Rightarrow y = 20 - x$ · $A = x(20 - x) = 20x - x^2$

$A' = 20 - 2x = 0 \Rightarrow x = 10,\ y = 10$ · $A'' = -2 \lt 0$ → สี่เหลี่ยมจัตุรัส 10×10 พื้นที่ 100 ตร.ซม.

นำกระดาษแข็งรูปสี่เหลี่ยมจัตุรัสขนาด 12×12 ซม. มาตัดมุมทั้งสี่ออกเป็นสี่เหลี่ยมจัตุรัสด้านละ x ซม. แล้วพับขึ้นเป็นกล่องไม่มีฝา จงหา x ที่ทำให้กล่องมีปริมาตรมากที่สุด

ฐานกว้าง $12 - 2x$ สูง $x$ → $V(x) = x(12 - 2x)^2$ โดย $0 \lt x \lt 6$

ใช้ผลคูณ+ลูกโซ่: $V'(x) = (12-2x)^2 + x\cdot 2(12-2x)(-2) = (12-2x)(12 - 2x - 4x) = (12-2x)(12-6x)$

$V' = 0 \Rightarrow x = 6$ (ตัดทิ้ง กล่องแบน ปริมาตร 0) หรือ $x = 2$

$V(2) = 2\cdot 8^2 = 128$ → ตัดมุมด้านละ 2 ซม. ได้ปริมาตรมากสุด 128 ลบ.ซม.

ต้องการกล่องมีฝา ฐานเป็นสี่เหลี่ยมจัตุรัส จุของได้ 1,000 ลบ.ซม. จงหาขนาดกล่องที่ใช้กระดาษ (พื้นที่ผิว) น้อยที่สุด

ให้ฐานกว้าง $x$ สูง $h$: ปริมาตร $x^2h = 1000 \Rightarrow h = \dfrac{1000}{x^2}$

พื้นที่ผิว (ฐาน + ฝา + ข้าง 4 ด้าน): $S = 2x^2 + 4xh = 2x^2 + \dfrac{4000}{x}$

$S'(x) = 4x - \dfrac{4000}{x^2} = 0 \Rightarrow x^3 = 1000 \Rightarrow x = 10$ · $S''(x) = 4 + \dfrac{8000}{x^3} \gt 0$ → ต่ำสุด ✓

$h = \dfrac{1000}{100} = 10$ → กล่องลูกบาศก์ 10×10×10 ซม. ใช้กระดาษ 600 ตร.ซม.

เทียบ: กล่องฐาน 20×20 สูง 2.5 ซม. จุเท่ากันแต่ใช้กระดาษ $800 + 200 = 1{,}000$ ตร.ซม. — มากกว่าถึง 67%

ปัญหาตัวเลข

จงหาจำนวนเต็มบวกสองจำนวนที่บวกกันได้ 120 และทำให้ ผลคูณของจำนวนหนึ่งกับกำลังสองของอีกจำนวนหนึ่ง มีค่ามากที่สุด

ให้จำนวนแรก $x$ จำนวนที่สอง $120 - x$ · $f(x) = (120 - x)x^2 = 120x^2 - x^3$

$f'(x) = 240x - 3x^2 = 3x(80 - x) = 0 \Rightarrow x = 0$ หรือ $x = 80$ · $f''(x) = 240 - 6x$

$f''(0) = 240 > 0$ (ต่ำสุด) · $f''(80) = -240 \lt 0$ (สูงสุด ✓)

สองจำนวนคือ 80 และ 40 ได้ผลคูณ $40 \times 80^2 = 256{,}000$

จำนวนบวกสองจำนวนคูณกันได้ 64 ผลบวกของสองจำนวนนี้น้อยที่สุดเป็นเท่าใด

ให้ $x$ และ $\dfrac{64}{x}$ → $S(x) = x + 64x^{-1}$ · $S'(x) = 1 - \dfrac{64}{x^2} = 0 \Rightarrow x = 8$ (บวก)

$S''(x) = \dfrac{128}{x^3} > 0$ → ต่ำสุด ✓ → 8 กับ 8 ผลบวกน้อยสุด 16

ปัญหาธุรกิจ: รายได้และกำไร

💰 ศัพท์ที่ต้องรู้

รายได้ $R$ = ราคา × จำนวนที่ขาย · ต้นทุน $C$ · กำไร $P = R - C$ · ลดราคาลง → ขายได้มากขึ้น แต่ได้เงินต่อชิ้นน้อยลง จึงต้องหา “จุดพอดี”

เราทำ PryFlix เก็บค่าสมาชิกเดือนละ 200 บาท มีสมาชิก 1,000 คน สังเกตว่าทุก ๆ การลดราคา 10 บาท จะมีสมาชิกเพิ่ม 100 คน ควรตั้งราคาเท่าใดจึงได้รายได้มากที่สุด และได้รายได้เท่าใด

ให้ $x$ = จำนวนครั้งที่ลดราคาครั้งละ 10 บาท → ราคา $200 - 10x$ · สมาชิก $1000 + 100x$

$$R(x) = (1000 + 100x)(200 - 10x) = 200{,}000 + 10{,}000x - 1{,}000x^2$$

$R'(x) = 10{,}000 - 2{,}000x = 0 \Rightarrow x = 5$ · $R'' = -2{,}000 \lt 0$ สูงสุด ✓

ราคา $200 - 50 = $ 150 บาท · สมาชิก 1,500 คน → รายได้สูงสุด 225,000 บาท/เดือน

ร้านเค้กตั้งราคาชิ้นละ 50 บาท ขายได้เดือนละ 100 ชิ้น ถ้าลดราคาลงทุก 1 บาท จะขายได้เพิ่ม 5 ชิ้น ควรตั้งราคาเท่าใด และได้ยอดขายกี่บาท

คราวนี้ให้ $x$ = ราคาเค้กโดยตรง → ลดไป $50 - x$ บาท ขายได้ $100 + 5(50 - x) = 350 - 5x$ ชิ้น

$R(x) = x(350 - 5x) = 350x - 5x^2$ · $R'(x) = 350 - 10x = 0 \Rightarrow x = 35$ · $R'' = -10 \lt 0$ ✓

ตั้งราคา 35 บาท ขาย 175 ชิ้น ได้ 6,125 บาท/เดือน

💡 สังเกต: ตั้งตัวแปรต่างกัน (PryFlix ให้ x = จำนวนครั้งที่ลด / เค้กให้ x = ราคา) ได้ทั้งคู่ ขอแค่ใช้ให้สม่ำเสมอ

บริษัทผลิตสินค้า $x$ ชิ้น มีต้นทุน $C(x) = x^2 - 4x + 5$ บาท และรายได้ $R(x) = 20x - x^2$ บาท จงหาจำนวนที่ควรผลิตเพื่อให้กำไรสูงสุด และกำไรสูงสุดเท่าใด

$P(x) = R - C = (20x - x^2) - (x^2 - 4x + 5) = -2x^2 + 24x - 5$

$P'(x) = -4x + 24 = 0 \Rightarrow x = 6$ · $P''(x) = -4 \lt 0$ ✓

$P(6) = -72 + 144 - 5 = 67$ → ผลิต 6 ชิ้น กำไรสูงสุด 67 บาท

ลูกบอลถูกโยนขึ้นจากความสูง 1 เมตร ความสูงหลังผ่านไป $t$ วินาทีคือ $h(t) = -5t^2 + 20t + 1$ เมตร ลูกบอลขึ้นไปได้สูงสุดเท่าใด เมื่อใด

จุดสูงสุดคือจุดที่ความเร็วเป็นศูนย์: $h'(t) = -10t + 20 = 0 \Rightarrow t = 2$ วินาที

$h(2) = -20 + 40 + 1 = 21$ → สูงสุด 21 เมตร ที่ t = 2 วินาที

ต้นทุนรวมของการผลิต $x$ ชิ้นคือ $C(x) = 2x^2 + 50x + 800$ บาท ควรผลิตกี่ชิ้นเพื่อให้ ต้นทุนเฉลี่ยต่อชิ้น ต่ำที่สุด

ต้นทุนเฉลี่ย $\bar C(x) = \dfrac{C(x)}{x} = 2x + 50 + \dfrac{800}{x}$

$\bar C'(x) = 2 - \dfrac{800}{x^2} = 0 \Rightarrow x^2 = 400 \Rightarrow x = 20$ · $\bar C''(x) = \dfrac{1600}{x^3} > 0$ ต่ำสุด ✓

$\bar C(20) = 40 + 50 + 40 = 130$ → ผลิต 20 ชิ้น ต้นทุนเฉลี่ยต่ำสุด 130 บาท/ชิ้น

Gradient descent: ให้คอมพิวเตอร์เดินหาจุดต่ำสุดเอง เสริม

ทุกข้อในบทนี้เราแก้สมการ $f'(x) = 0$ ได้ แต่ฟังก์ชันในงานจริง (เช่น ความผิดพลาดของโมเดล AI) ซับซ้อนจนแก้สมการตรง ๆ ไม่ได้ คอมพิวเตอร์จึงใช้วิธี “เดินลงเขาทีละก้าว”:

⛷️ Gradient descent
$$x_{\text{ใหม่}} = x - (\text{ขนาดก้าว})\times f'(x)$$
  • ถ้า $f'(x) \lt 0$ (กราฟลงไปทางขวา) → $x$ เพิ่มขึ้น เดินไปทางขวา
  • ถ้า $f'(x) \gt 0$ (กราฟขึ้นไปทางขวา) → $x$ ลดลง เดินไปทางซ้าย
  • ยิ่งชันยิ่งก้าวยาว และเมื่อถึงก้นหุบ $f'(x) \approx 0$ ก็หยุดเดินเอง

ลองปรับ “ขนาดก้าว” (ในวงการ AI เรียกว่า learning rate) แล้วกดก้าวหลาย ๆ ครั้ง:

  • เล็กมาก (0.02) — ไปถูกทางแต่ช้ามาก ต้องเดินหลายร้อยก้าว
  • พอดี (0.1–0.5) — เข้าใกล้ $x = 3$ อย่างรวดเร็ว
  • ใหญ่เกิน (1.0 ขึ้นไป) — ก้าวข้ามหุบไปมา ไม่ลงสักที หรือกระเด็นหลุดออกไปเลย

$f(x) = (x-3)^2 + 1$ เริ่มที่ $x = 0$ ใช้ขนาดก้าว 0.1 จงหาตำแหน่งหลังเดิน 2 ก้าว

$f'(x) = 2(x - 3)$

ก้าวที่ 1: $f'(0) = -6$ → $x = 0 - 0.1(-6) = 0.6$

ก้าวที่ 2: $f'(0.6) = -4.8$ → $x = 0.6 - 0.1(-4.8) = $ 1.08 (กำลังเดินเข้าหาจุดต่ำสุด $x = 3$)

 def df(x): # f(x) = (x - 3)**2 + 1 -> f'(x) = 2(x - 3) return 2 * (x - 3) for lr in [0.02, 0.1, 0.4, 1.0, 1.1]: x = 0.0 for step in range(20): x = x - lr * df(x) print(f"ขนาดก้าว {lr:<4} เดิน 20 ก้าว ได้ x = {x:.4f}")

 กระดาษ 30×30 ซม. ตัดมุมด้านละ x แล้วพับเป็นกล่องไม่มีฝา x เท่าใดได้ปริมาตรมากสุด
ฟังก์ชัน$V = x(30 - 2x)^2$,  $0 \lt x \lt 15$ ดิฟ = 0$V' = (30-2x)(30-6x) = 0 \Rightarrow x = 5$  (x = 15 ตัดทิ้ง กล่องแบน) ตอบตัดมุมด้านละ 5 ซม. ได้ $V(5) = 5\cdot 20^2 = 2{,}000$ ลบ.ซม.

 ฟังก์ชันกำไร $P(x) = -x^3 + 6x^2 + 15x - 40$ (พันบาท) เมื่อผลิต $x$ พันชิ้น ($x \ge 0$) ควรผลิตเท่าใด
ดิฟ = 0$P' = -3x^2 + 12x + 15 = -3(x-5)(x+1) = 0 \Rightarrow x = 5$  (x = −1 ตัดทิ้ง) ตรวจ$P''(5) = -6(5) + 12 = -18 \lt 0$ สูงสุด ✓ ตอบ$P(5) = -125 + 150 + 75 - 40 = 60$ → ผลิต 5 พันชิ้น กำไร 60 พันบาท

 Gradient descent (เสริม) ใช้ gradient descent กับ $f(x) = x^2 - 4x$ เริ่มที่ $x = 0$ ขนาดก้าว 0.25 จงหาตำแหน่งหลังเดิน 2 ก้าว และบอกว่ากำลังเดินเข้าหาจุดใด
ความชัน$f'(x) = 2x - 4$ ก้าวที่ 1$x = 0 - 0.25(-4) = 1$ ก้าวที่ 2$x = 1 - 0.25(-2) = 1.5$
