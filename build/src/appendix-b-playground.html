🧪 วิธีใช้

พิมพ์ฟังก์ชันในช่อง f(x) แล้วกด Enter (หรือคลิกนอกช่อง) — ใช้ ^ แทนยกกำลัง คูณไม่ต้องใส่ * ก็ได้ เช่น 2x^3 - 3x^2 - 12x + 5 รองรับ sqrt( ) |x| abs( ) sin cos tan exp ln pi e

  • เส้นประเหลือง = กราฟอนุพันธ์ $f'(x)$ — สังเกตว่าตรงไหนที่ $f'$ ตัดแกน x ตรงนั้น $f$ มีจุดวิกฤต
  • เส้นสัมผัสสีชมพู เลื่อนได้ด้วยแถบ x₀
  • ติ๊ก พื้นที่ใต้กราฟ แล้วใส่ a, b เพื่อดูทั้งค่าอินทิกรัล (มีเครื่องหมาย) และพื้นที่จริง

ภารกิจชวนลอง

  1. พิมพ์ x^3 - 3x เลื่อนเส้นสัมผัสหาตำแหน่งที่เส้นสัมผัสนอนราบ แล้วดูว่ากราฟ $f'$ (เส้นประ) อยู่ตรงไหน
  2. พิมพ์ (x^2-1)/(x-1) ดูว่ากราฟเป็นเส้นตรงที่มีรู — ตรวจคำตอบลิมิตในบทที่ 2
  3. พิมพ์ x^2 - 4x ติ๊กพื้นที่ a = 0, b = 6 แล้วเทียบ “∫” กับ “พื้นที่จริง” — ทำไมไม่เท่ากัน?
  4. พิมพ์ x^3 แล้วดูที่ x = 0 — ความชันเป็น 0 แต่ไม่ใช่สูงสุดหรือต่ำสุด (จุดนิ่ง)
  5. พิมพ์ |x| แล้วเลื่อนเส้นสัมผัสผ่าน x = 0 — ความชันกระโดดจาก −1 เป็น 1 (ดิฟไม่ได้ที่มุมแหลม)
