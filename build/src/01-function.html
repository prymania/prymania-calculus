💡 ทำไมแคลคูลัสต้องเริ่มที่ฟังก์ชัน?

แคลคูลัสคือคณิตศาสตร์ของ “การเปลี่ยนแปลง” — ความเร็วรถเปลี่ยนไปอย่างไร ยอดขายโตเร็วแค่ไหน พื้นที่ใต้กราฟมีเท่าไร ทุกอย่างที่เราจะวัดการเปลี่ยนแปลง ต้องเขียนออกมาเป็น ฟังก์ชัน ก่อนเสมอ และเครื่องมือแรกที่ใช้วัดการเปลี่ยนแปลงก็คือ ความชัน ของเส้นตรง — สองเรื่องนี้จึงเป็นฐานของทั้งวิชา

ฟังก์ชันคืออะไร

ฟังก์ชัน (Function) คือความสัมพันธ์ระหว่างเซตของ input กับเซตของ output โดยที่ input แต่ละค่า ต้องให้ output ได้เพียง 1 ค่าเท่านั้น

ลองนึกภาพ ตู้กดน้ำ 🥤 — กดปุ่ม A ต้องได้โค้กเสมอ ถ้ากดปุ่ม A แล้วบางทีได้โค้ก บางทีได้น้ำเปล่า ตู้นั้นก็ “ไม่ใช่ฟังก์ชัน” (และน่าจะเสีย 😅)

x = 3input
➜
f(x) = 2x + 1เครื่องจักรฟังก์ชัน
➜
f(3) = 7output (ได้ค่าเดียว)

เราเขียนฟังก์ชันได้หลายแบบ เช่น $y = x^2 + 5x - 3$ หรือ $f(x) = 3x + 8$ โดย $f(x)$ อ่านว่า “เอฟของเอ็กซ์” หมายถึง ค่า output เมื่อใส่ input เป็น x

หลายตัวไปตัวเดียวได้ แต่ตัวเดียวไปหลายตัวไม่ได้

✅ เป็นฟังก์ชัน

$R = \{(1,2),(2,2),(3,3),(4,3)\}$ — ทุก input มีลูกศรออก เส้นเดียว (ไปซ้ำกันได้)

❌ ไม่เป็นฟังก์ชัน

input 1 ให้ output ได้ทั้ง 1 และ −1 → ไม่ใช่ฟังก์ชัน

ดูจากกราฟ: Vertical Line Test (ลากเส้นตั้ง)

ลากเส้นแนวตั้งผ่านกราฟที่ตำแหน่งใดก็ได้ — ถ้ามีตำแหน่งที่เส้นตั้งตัดกราฟมากกว่า 1 จุด แสดงว่าไม่เป็นฟังก์ชัน (เพราะ x ค่าเดียวได้ y หลายค่า)

โดเมนและเรนจ์

📥 โดเมน (Domain)

เซตของ x ทั้งหมดที่ใส่เข้าไปได้ (ค่า input ที่ทำให้ฟังก์ชันหาค่าได้)

📤 เรนจ์ (Range)

เซตของ y ทั้งหมดที่ออกมาได้ (ค่า output ที่เป็นไปได้)

เช่น $R=\{(1,2),(2,2),(3,3),(4,3)\}$ มีโดเมน $=\{1,2,3,4\}$ และเรนจ์ $=\{2,3\}$

⚠️ สองกับดักที่ทำให้ x ใส่ไม่ได้ (สำหรับจำนวนจริง)
  1. ตัวส่วนเป็น 0 ไม่ได้ — เช่น $f(x)=\dfrac{1}{x-3}$ ใส่ x = 3 ไม่ได้
  2. ในรูทต้องไม่ติดลบ — เช่น $f(x)=\sqrt{x-2}$ ต้องมี $x-2 \ge 0$ คือ $x \ge 2$
ถ้าไม่เจอสองอย่างนี้ (เช่น พหุนาม) โดเมนคือ จำนวนจริงทั้งหมด $\mathbb{R}$ หรือ $(-\infty,\infty)$

การหาค่าฟังก์ชันและฟังก์ชันประกอบ

หาค่าฟังก์ชัน = เอาค่าที่กำหนด “ไปแทน x ทุกตัว” เช่น $f(x)=2x-5$ จะได้ $f(4)=2(4)-5=3$ และ $f(a+1) = 2(a+1)-5 = 2a-3$

ฟังก์ชันประกอบ (Composite function) $(f\circ g)(x) = f(g(x))$ คือการส่ง output ของ $g$ เข้าเครื่อง $f$ ต่อ — ทำตัวขวาก่อน

x
➜
gทำก่อน
➜
g(x)
➜
fทำทีหลัง
➜
f(g(x))

กำหนดให้ $f(x) = 2x - 5$ และ $g(x) = x + 10$ จงหาค่าต่อไปนี้

  1. $f(2) + g(2)$
  2. $f(5) - g(-3)$
  3. $(f\circ g)(3)$
  4. $(g\circ f)(-5)$
  5. ถ้า $f(x) = -21$ จงหา $x$
  6. ถ้า $f(x) = -1$ จงหา $g(x)$
  1. $f(2) = -1,\ g(2) = 12$ → $-1 + 12 = $ 11
  2. $f(5) = 5,\ g(-3) = 7$ → $5 - 7 = $ −2
  3. $g(3) = 13$ ก่อน แล้ว $f(13) = 2(13)-5 = $ 21
  4. $f(-5) = -15$ ก่อน แล้ว $g(-15) = -15+10 = $ −5
  5. $2x - 5 = -21 \Rightarrow 2x = -16 \Rightarrow$ x = −8
  6. $2x - 5 = -1 \Rightarrow x = 2$ แล้ว $g(2) = 12$ → g(x) = 12

กำหนด $f(x) = x^2 - 3$ และ $g(x) = 2x + 1$ จงหา $(f\circ g)(x)$ และ $(g\circ f)(x)$ แล้วตรวจว่าเท่ากันหรือไม่

$$\begin{aligned}(f\circ g)(x) &= f(2x+1) = (2x+1)^2 - 3 = 4x^2 + 4x - 2\\ (g\circ f)(x) &= g(x^2-3) = 2(x^2-3) + 1 = 2x^2 - 5\end{aligned}$$

สองอันนี้ ไม่เท่ากัน → โดยทั่วไป $f\circ g \ne g\circ f$ ลำดับสำคัญมาก!

ความชันและสมการเส้นตรง

ความชัน (slope) ใช้ตัวอักษร $m$ บอกว่า ถ้า x ขยับไป 1 หน่วย y จะขยับไปเท่าไร

📐 สูตรความชันจากสองจุด $(x_1,y_1)$ และ $(x_2,y_2)$
$$m = \frac{y_2 - y_1}{x_2 - x_1} = \frac{\Delta y}{\Delta x} = \frac{\text{ระยะขึ้น–ลง}}{\text{ระยะเดินไปข้างหน้า}}$$

ความชันบอกอะไรเรา

m > 0 ↗

กราฟขึ้นจากซ้ายไปขวา (x เพิ่ม y เพิ่ม)

m < 0 ↘

กราฟลงจากซ้ายไปขวา (x เพิ่ม y ลด)

m = 0 →

เส้นนอน y ไม่เปลี่ยนเลย

|m| ยิ่งมาก

ยิ่งชัน เปลี่ยนแปลงเร็ว

📏 สมการเส้นตรง 2 แบบที่ใช้บ่อยที่สุด

แบบความชัน–จุดตัดแกน y: $y = mx + c$  (c คือค่า y ตอน x = 0)

แบบจุด–ความชัน: $y - y_1 = m(x - x_1)$  (รู้จุด 1 จุดกับความชันก็พอ — ใช้มากในบทที่ 5)

🧠 ทริคพาราโบลา $y = ax^2 + bx + c$

$a > 0$ หงาย (มีจุดต่ำสุด), $a \lt 0$ คว่ำ (มีจุดสูงสุด) และจุดยอดอยู่ที่ $x = -\dfrac{b}{2a}$ — ในบทที่ 5 เราจะได้สูตรนี้ “ฟรี ๆ” จากการดิฟ!

(ก) $\mathbb{R} - \{7\}$ (ข) $x + 5 \ge 0$ → $[-5, \infty)$ (ค) $x(x-4) \ne 0$ → $\mathbb{R} - \{0, 4\}$

 จงหาเรนจ์ของ $f(x) = 5 - x^2$

$x^2 \ge 0$ ดังนั้น $-x^2 \le 0$ และ $5 - x^2 \le 5$ → เรนจ์ $(-\infty, 5]$ (พาราโบลาคว่ำ จุดสูงสุด (0, 5))

(ก) $-4 + 8 = 4$ (ข) $g(2)=3,\ f(3)=11$ (ค) $f(2)=8,\ g(8)=63$ (ง) $3(x^2-1)+2 = 3x^2 - 1$

 กำหนด $f(x) = 4x - 9$ ถ้า $f(a) = 15$ จงหา $a$ และ $f(2a)$

$4a - 9 = 15 \Rightarrow a = 6$ แล้ว $f(12) = 48 - 9 = 39$

 กำหนด $f(x) = x^2 + 2x$ จงหา $f(x+h)$ และ $f(x+h) - f(x)$ (เตรียมใช้ในบทที่ 4)$$\begin{aligned}f(x+h) &= (x+h)^2 + 2(x+h) = x^2 + 2xh + h^2 + 2x + 2h\\ f(x+h)-f(x) &= 2xh + h^2 + 2h\end{aligned}$$ ความชันและสมการเส้นตรง จงหาความชันของเส้นตรงที่ผ่านจุด $(3,-1)$ และ $(7, 11)$ แล้วเขียนสมการในรูป $y = mx + c$

$m = \dfrac{11-(-1)}{7-3} = 3$ → $y + 1 = 3(x - 3)$ → $y = 3x - 10$

 เส้นตรงมีความชัน $-\tfrac{1}{2}$ และผ่านจุด $(4, 6)$ จงหาสมการและจุดตัดแกน x

$y - 6 = -\tfrac12(x-4) \Rightarrow y = -\tfrac12 x + 8$ · ตัดแกน x เมื่อ y = 0: $\tfrac12 x = 8 \Rightarrow x = 16$ → จุด (16, 0)

 ร้านถ่ายเอกสารคิดค่าเข้าเล่ม 25 บาท บวกหน้าละ 0.5 บาท จงเขียนฟังก์ชันราคา $P(n)$ ของเอกสาร $n$ หน้า บอกความหมายของความชัน และหาราคาเมื่อพิมพ์ 120 หน้า
