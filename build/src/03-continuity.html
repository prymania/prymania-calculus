🎬 คำถามเปิดบท

เคยเล่นเกมที่ตัวละครเดินอยู่ดี ๆ แล้ว “วาร์ป” กระตุกไปอีกที่ไหม? บั๊กแบบนี้เกิดจากอะไร?

และอีกข้อ: สมการอย่าง $x^3 + x - 1 = 0$ ไม่มีสูตรง่าย ๆ ให้แก้ แต่คอมพิวเตอร์ก็ยังหาคำตอบได้ละเอียดถึงทศนิยมหลายตำแหน่ง — มันทำได้อย่างไร?

🎯 เมื่อเรียนจบบทนี้ นิสิตจะสามารถ
  1. บอกเงื่อนไข 3 ข้อของความต่อเนื่องที่จุด $x = a$ ได้
  2. จำแนกจุดไม่ต่อเนื่องแบบ “รู” “กระโดด” และ “พุ่งไปอนันต์” จากกราฟได้
  3. ตรวจสอบความต่อเนื่องของฟังก์ชันหลายช่วง (piecewise) ได้
  4. หาค่าคงที่ $k$ ที่ทำให้ฟังก์ชันต่อเนื่องได้
  5. ใช้ความต่อเนื่องหาคำตอบของสมการด้วยการแบ่งครึ่งช่วง (bisection) ได้ (เสริม)

ความต่อเนื่องคืออะไร

พูดแบบภาษาคน: ฟังก์ชันต่อเนื่องที่จุดหนึ่ง ถ้า เราวาดกราฟผ่านจุดนั้นได้โดยไม่ต้องยกปากกา ✏️ — ไม่มีรู ไม่มีรอยขาด ไม่มีการกระโดด

✅ นิยาม: $f$ ต่อเนื่องที่ $x = a$ ก็ต่อเมื่อครบทั้ง 3 ข้อ
  1. $f(a)$ หาค่าได้  (มีจุดอยู่จริง)
  2. $\displaystyle\lim_{x\to a}f(x)$ หาค่าได้  (ลิมิตซ้าย = ลิมิตขวา)
  3. $\displaystyle\lim_{x\to a}f(x) = f(a)$  (ค่าที่ “กำลังมุ่งไป” ตรงกับ “ค่าจริง”)

ข้อใดข้อหนึ่งไม่ผ่าน → ไม่ต่อเนื่อง ที่ $x = a$

💡 ทำไมต้องสนใจ?

ทฤษฎีหลายอย่างในบทต่อ ๆ ไป (เช่น หาค่าสูงสุด–ต่ำสุดบนช่วงปิด, หาพื้นที่ด้วยอินทิกรัล) ใช้ได้ เฉพาะกับฟังก์ชันที่ต่อเนื่อง และในโลกจริง ความต่อเนื่องหมายถึง “ไม่มีการกระตุก” เช่น ความเร็วรถไม่กระโดดจาก 40 เป็น 90 กม./ชม. ในพริบตา

ตรวจความต่อเนื่องทีละข้อ

กำหนด $f(x) = x^2$ จงตรวจว่า $f$ ต่อเนื่องที่ $x = -1$ หรือไม่

  1. $f(-1) = (-1)^2 = 1$ ✓
  2. $\displaystyle\lim_{x\to-1}x^2 = 1$ ✓
  3. $\displaystyle\lim_{x\to-1}x^2 = f(-1) = 1$ ✓

ครบ 3 ข้อ → ต่อเนื่องที่ x = −1 (อันที่จริง พหุนามต่อเนื่องทุกจุดเสมอ)

กำหนด $f(x) = \dfrac{x}{x-7}$ จงตรวจว่า $f$ ต่อเนื่องที่ $x = 7$ หรือไม่

ข้อ 1: $f(7) = \dfrac{7}{0}$ หาค่าไม่ได้ ✗ → ไม่ต้องตรวจข้ออื่นต่อ ไม่ต่อเนื่องที่ x = 7

$$f(x) = \begin{cases} 3x - 2 &;\ x \le 2\\ x^2 &;\ x \gt 2\end{cases}$$ ต่อเนื่องที่ $x = 2$ หรือไม่

  1. $x = 2$ อยู่ในช่วง $x \le 2$ → $f(2) = 3(2) - 2 = 4$
  2. ลิมิตซ้าย $\displaystyle\lim_{x\to2^-}(3x-2) = 4$
    ลิมิตขวา $\displaystyle\lim_{x\to2^+}x^2 = 4$
    ซ้าย = ขวา → $\displaystyle\lim_{x\to2}f(x) = 4$
  3. $\displaystyle\lim_{x\to2}f(x) = 4 = f(2)$ ✓

ต่อเนื่องที่ x = 2 — สองท่อนกราฟมาบรรจบกันพอดีที่ (2, 4)

$$f(x) = \begin{cases} x - 2 &;\ x \le 1\\[4pt] \dfrac{x^2 - 3x + 2}{x-1} &;\ x \gt 1\end{cases}$$ ต่อเนื่องที่ $x = 1$ หรือไม่

  1. $f(1) = 1 - 2 = -1$
  2. ลิมิตซ้าย $\displaystyle\lim_{x\to1^-}(x-2) = -1$
    ลิมิตขวา $\dfrac{(x-1)(x-2)}{x-1} = x - 2 \to -1$

  3. $-1 = f(1)$ ✓

$$f(x) = \begin{cases} x - 2 &;\ x \lt 0\\[4pt] \dfrac{x^2 - 3x + 2}{x-1} &;\ x \ge 0\end{cases}$$ ต่อเนื่องที่ $x = 0$ หรือไม่

$f(0)$$\dfrac{0 - 0 + 2}{0 - 1} = -2$ ลิมิตซ้าย$0 - 2 = -2$ ลิมิตขวา$\dfrac{2}{-1} = -2$  (แทนค่าได้เลย ตัวส่วนไม่เป็น 0)

ทุกค่าเท่ากับ −2 → ต่อเนื่องที่ x = 0 (แต่ระวัง! ฟังก์ชันนี้ไม่นิยามที่ x = 1 เพราะช่วง x ≥ 0 ครอบคลุม x = 1 ซึ่งทำให้ตัวส่วนเป็น 0)

$$f(x) = \begin{cases} \dfrac{x^2+4x-12}{x^2+8x-20} &;\ x \lt 2\\[6pt] \dfrac{x}{3} &;\ x = 2 \\[6pt] \dfrac{x^2-4}{x^2+2x-8} &;\ x \gt 2\end{cases}$$ ต่อเนื่องที่ $x = 2$ หรือไม่

  1. $f(2) = \dfrac{2}{3}$
  2. ลิมิตซ้าย $\dfrac{(x+6)(x-2)}{(x+10)(x-2)} = \dfrac{x+6}{x+10} \to \dfrac{8}{12} = \dfrac23$
    ลิมิตขวา $\dfrac{(x-2)(x+2)}{(x-2)(x+4)} = \dfrac{x+2}{x+4} \to \dfrac46 = \dfrac23$
  3. ทั้งสามค่าเท่ากับ $\tfrac23$ ✓

ต่อเนื่องที่ x = 2

หาค่า k ที่ทำให้ฟังก์ชันต่อเนื่อง

โจทย์แนวนี้ออกสอบบ่อยมาก! หลักคิด: บังคับให้ ลิมิตซ้าย = ลิมิตขวา = f(a) แล้วแก้สมการหา k

  1. หาลิมิตซ้ายและลิมิตขวา (ถ้ามี k อยู่ในสูตรก็ปล่อยไว้เป็นตัวแปร)
  2. ตั้งสมการให้ทุกค่าเท่ากัน
  3. แก้สมการหา k แล้วตรวจคำตอบ — ถ้าตั้งสมการแล้วขัดแย้งกัน แปลว่า ไม่มี k ที่เป็นไปได้

$$f(x) = \begin{cases} \dfrac{x^2-9}{x-3} &;\ x \lt 3\\[4pt] k &;\ x = 3\\ x + 3 &;\ x \gt 3\end{cases}$$ หาค่า $k$ ที่ทำให้ $f$ ต่อเนื่องที่ $x = 3$

ลิมิตซ้าย$\dfrac{(x-3)(x+3)}{x-3} = x + 3 \to 6$ ลิมิตขวา$3 + 3 = 6$

ต้องการ $f(3) = k = 6$ → k = 6 (เป็นการ “อุดรู” ที่จุด (3, 6) พอดี)

$$f(x) = \begin{cases} \dfrac{x^2-4}{x-2} &;\ x \lt 2\\[4pt] k &;\ x = 2\\ x + 1 &;\ x \gt 2\end{cases}$$ หาค่า $k$ ที่ทำให้ $f$ ต่อเนื่องที่ $x = 2$

ลิมิตซ้าย$\dfrac{(x-2)(x+2)}{x-2} = x + 2 \to 4$ ลิมิตขวา$2 + 1 = 3$

ลิมิตซ้าย ≠ ลิมิตขวา → ลิมิตหาค่าไม่ได้ ไม่ว่า k จะเป็นอะไร เงื่อนไขข้อ 2 ก็ไม่ผ่าน → ไม่มีค่า k ที่ทำให้ต่อเนื่อง

$$f(x) = \begin{cases} kx + 1 &;\ x \lt 2\\ x^2 - 1 &;\ x \ge 2\end{cases}$$ หาค่า $k$ ที่ทำให้ $f$ ต่อเนื่องทุกจุด

แต่ละท่อนเป็นพหุนาม จึงต่อเนื่องอยู่แล้ว ต้องตรวจแค่ที่รอยต่อ x = 2

ลิมิตซ้าย$2k + 1$ ลิมิตขวา และ $f(2)$$2^2 - 1 = 3$ ตั้งสมการ$2k + 1 = 3$ → k = 1

$$f(x) = \begin{cases} x + a &;\ x \lt 1\\ 5 &;\ x = 1\\ bx^2 - 3 &;\ x \gt 1\end{cases}$$ หาค่า $a$ และ $b$ ที่ทำให้ $f$ ต่อเนื่องที่ $x = 1$

ต้องได้ ลิมิตซ้าย = ลิมิตขวา = $f(1) = 5$

ลิมิตซ้าย = 5$1 + a = 5 \Rightarrow a = 4$ ลิมิตขวา = 5$b(1)^2 - 3 = 5 \Rightarrow b = 8$

a = 4, b = 8

ตำแหน่งตัวละครในเกมคือฟังก์ชันของเวลา $p(t)$ ถ้าโปรแกรมเมอร์เขียน if/else เปลี่ยนท่าเดินกลางคัน แล้วสองท่อนไม่ต่อกันที่รอยต่อ ตัวละครจะกระโดดข้ามตำแหน่งทันที — การหาค่า $k$ ให้ฟังก์ชันต่อเนื่องคือการแก้บั๊กนี้นั่นเอง

ตัวละครเดิน 2 หน่วย/วินาที ใน 3 วินาทีแรก จากนั้นออกวิ่ง 5 หน่วย/วินาที โปรแกรมเขียนตำแหน่งไว้ว่า

$$p(t) = \begin{cases} 2t &;\ 0 \le t \le 3\ 5t + k &;\ t \gt 3\end{cases}$$

(ก) ถ้าลืมใส่ $k$ (คือ $k = 0$) จะเกิดอะไรขึ้นที่ $t = 3$  (ข) ต้องใช้ $k$ เท่าใดตัวละครจึงไม่วาร์ป

(ก) $p(3) = 6$ แต่ลิมิตขวา $= 5(3) = 15$ → ตัวละครวาร์ปจากตำแหน่ง 6 ไป 15 ทันที (ไม่ต่อเนื่องแบบกระโดด)

(ข) ให้ลิมิตขวา = $p(3)$: $15 + k = 6$ → k = −9 จะได้ $p(t) = 5t - 9$ ซึ่งเริ่มวิ่งจากตำแหน่ง 6 พอดี

ฟังก์ชันไหนต่อเนื่องบ้าง (ภาพรวม)

พหุนาม

ต่อเนื่อง ทุกจุด บน $\mathbb{R}$ เช่น $x^3 - 2x + 7$

ฟังก์ชันตรรกยะ $\frac{P(x)}{Q(x)}$

ต่อเนื่องทุกจุด ยกเว้นที่ $Q(x) = 0$

รากที่สอง $\sqrt{g(x)}$

ต่อเนื่องเมื่อ $g(x) \ge 0$

ฟังก์ชันหลายช่วง

ต้อง ตรวจที่รอยต่อ ทุกจุด

ฟังก์ชัน $f(x) = \dfrac{x+1}{x^2 - 5x + 6}$ ไม่ต่อเนื่องที่จุดใดบ้าง

ตัวส่วน $x^2 - 5x + 6 = (x-2)(x-3) = 0$ เมื่อ x = 2, 3

ไม่ต่อเนื่องที่ x = 2 และ x = 3 ต่อเนื่องทุกจุดอื่น

ความต่อเนื่องช่วยหาคำตอบของสมการ เสริม

🌉 ทฤษฎีบทค่าระหว่างกลาง (Intermediate Value Theorem) แบบภาษาคน

ถ้า $f$ ต่อเนื่อง บนช่วง $[a, b]$ และ $f(a)$ กับ $f(b)$ มี เครื่องหมายต่างกัน (ตัวหนึ่งติดลบ อีกตัวเป็นบวก) แล้วต้องมีอย่างน้อยหนึ่งจุดระหว่าง $a$ กับ $b$ ที่ $f(x) = 0$

เหตุผล: เดินจากใต้แกน x ไปเหนือแกน x โดยไม่ยกปากกา ต้องข้ามแกน x สักที่แน่นอน

จากทฤษฎีบทนี้ได้วิธีหาคำตอบที่ง่ายมาก เรียกว่า การแบ่งครึ่งช่วง (bisection):

  1. เริ่มจากช่วง $[a, b]$ ที่ $f(a)$ กับ $f(b)$ เครื่องหมายต่างกัน
  2. หาจุดกึ่งกลาง $m = \frac{a+b}{2}$ แล้วดูเครื่องหมายของ $f(m)$
  3. เก็บครึ่งที่ปลายสองข้างยังเครื่องหมายต่างกัน (คำตอบอยู่ในครึ่งนั้นแน่นอน) ทิ้งอีกครึ่ง
  4. ทำซ้ำ — ช่วงแคบลงครึ่งหนึ่งทุกรอบ

กำหนด $f(x) = x^2 - 2$ (คำตอบของ $f(x) = 0$ คือ $\sqrt2$)  (ก) แสดงว่ามีคำตอบอยู่ในช่วง $[1, 2]$  (ข) แบ่งครึ่ง 2 ครั้ง แล้วบอกช่วงใหม่

(ก) $f(1) = -1 \lt 0$ และ $f(2) = 2 \gt 0$ เครื่องหมายต่างกัน และ $f$ เป็นพหุนามจึงต่อเนื่อง → มีคำตอบใน $[1, 2]$

(ข) ครั้งที่ 1: $m = 1.5$, $f(1.5) = 0.25 \gt 0$ → คำตอบอยู่ระหว่างจุดที่ติดลบกับบวก คือ $[1, 1.5]$

ครั้งที่ 2: $m = 1.25$, $f(1.25) = -0.4375 \lt 0$ → [1.25, 1.5] (และ $\sqrt2 \approx 1.414$ อยู่ในช่วงนี้จริง)
⚠️ ต้องต่อเนื่องเท่านั้น!

$f(x) = \dfrac1x$ มี $f(-1) = -1$ และ $f(1) = 1$ เครื่องหมายต่างกัน แต่ ไม่มี $x$ ไหนที่ $\frac1x = 0$ — เพราะกราฟ ขาด ที่ $x = 0$ (กระโดดข้ามแกน x ไปเลย) ทฤษฎีบทจึงใช้ไม่ได้

def f(x): return x**3 + x - 1 lo, hi = 0, 1 # f(0) = -1 < 0, f(1) = 1 > 0 for rnd in range(1, 21): mid = (lo + hi) / 2 if f(lo) * f(mid) <= 0: # เครื่องหมายต่างกัน -> คำตอบอยู่ครึ่งซ้าย hi = mid else: lo = mid if rnd in (1, 2, 3, 5, 10, 20): print(f"รอบ {rnd:2}: คำตอบอยู่ใน [{lo:.7f}, {hi:.7f}]")

🎬 กลับมาตอบคำถามเปิดบท

บั๊กวาร์ป เกิดจากฟังก์ชันตำแหน่ง ไม่ต่อเนื่อง ที่รอยต่อระหว่างสองท่อนของ if/else — แก้ได้ด้วยการหาค่าคงที่ให้ลิมิตซ้าย = ลิมิตขวา = ค่าจริง แบบที่ฝึกในหัวข้อ 3.4
