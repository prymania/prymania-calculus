บทที่ 1 · ฟังก์ชัน กราฟ และความชัน

⭐ โบนัส 1.1

เครื่องคิดเลขขึ้น Error เมื่อกด $\sqrt{-4}$ หรือ $1 \div 0$ และโปรแกรมภาษา Python ก็ขึ้น error เหมือนกัน

  1. เรื่องนี้เกี่ยวกับ โดเมน ของฟังก์ชันอย่างไร
  2. ยกตัวอย่างโปรแกรมหรือแอปในชีวิตจริง 1 ตัวอย่าง ที่ต้อง “เช็กโดเมน” ก่อนคำนวณ ไม่อย่างนั้นโปรแกรมจะพัง
แนวคำตอบ

ข้อ 1: −4 อยู่นอกโดเมนของ $\sqrt{x}$ และ 0 อยู่นอกโดเมนของ $\dfrac{1}{x}$ ฟังก์ชันจึงหาค่าไม่ได้ เครื่องหรือโปรแกรมจึงแจ้ง error
(Python: math.sqrt(-4) → ValueError: math domain error · 1/0 → ZeroDivisionError)

ข้อ 2 — ตัวอย่างที่ถูก

  • ระบบหาคะแนนเฉลี่ย = ผลรวม ÷ จำนวนนิสิต ถ้ายังไม่มีใครส่งงาน (จำนวน = 0) จะหารด้วยศูนย์
  • แอปคำนวณ BMI = น้ำหนัก ÷ ส่วนสูง² ถ้าผู้ใช้กรอกส่วนสูง 0
  • คำนวณส่วนเบี่ยงเบนมาตรฐาน = √(ความแปรปรวน) ถ้าการปัดเศษทำให้ความแปรปรวนติดลบเล็กน้อย
  • ฟอร์มกรอกอายุหรือจำนวนสินค้า ต้องกันค่าติดลบก่อนนำไปคำนวณ

เกณฑ์: ตัวอย่างต้องบอกได้ว่าค่าไหนอยู่นอกโดเมน และจะเกิดอะไรขึ้นถ้าไม่เช็ก

⭐ โบนัส 1.2

ยกตัวอย่างเหตุการณ์ในชีวิตจริง อย่างน้อย 2 ตัวอย่าง ที่ $f\circ g \ne g\circ f$ คือทำสองขั้นตอนสลับลำดับกันแล้วได้ผลต่างกัน

  • บอกให้ชัดว่า $f$ คืออะไร และ $g$ คืออะไร
  • บอกว่าผลลัพธ์ของสองลำดับต่างกันอย่างไร
  • ห้ามใช้ตัวอย่างส่วนลดกับ VAT ด้านบน
แนวคำตอบ

ตัวอย่างที่ถูก

  • ใส่ถุงเท้า ($g$) แล้วใส่รองเท้า ($f$) ได้การแต่งตัวปกติ · ถ้าใส่รองเท้าก่อนแล้วใส่ถุงเท้า ถุงเท้าจะอยู่นอกรองเท้า
  • ส่วนลดสองแบบ สินค้า 1,000 บาท: ลด 10% ก่อนแล้วลด 100 บาท ได้ 800 · ลด 100 บาทก่อนแล้วลด 10% ได้ 810
  • ขึ้นเงินเดือน 10% ($f$) กับหักค่าใช้จ่ายคงที่ 500 บาท ($g$) สองลำดับได้เงินต่างกัน 50 บาท
  • ซักผ้า ($g$) แล้วตากผ้า ($f$) ได้ผ้าแห้งสะอาด · ตากก่อนแล้วซัก ได้ผ้าเปียก
  • ในโค้ด: เรียงข้อมูล (sort) แล้วเลือก 3 ตัวแรก ได้ “3 อันดับแรก” · เลือก 3 ตัวแรกแล้วค่อยเรียง ได้แค่ 3 ตัวแรกของข้อมูลเดิมที่เรียงแล้ว

เกณฑ์: ต้องระบุ $f$ และ $g$ และผลของสองลำดับต้องต่างกันจริง ตัวอย่างที่สลับแล้วได้ผลเท่าเดิม (เช่น บวก 100 แล้วบวก 50) ไม่นับ เพราะกรณีนั้น $f\circ g = g\circ f$

⭐ โบนัส 1.3

กราฟรูปแบบใดอธิบาย จำนวนประชากรมนุษย์บนโลก ตั้งแต่ 10,000 ปีก่อนจนถึงปัจจุบัน ได้ถูกต้องที่สุด (แกน x = เวลา, แกน y = จำนวนประชากร)

  1. เลือกกราฟ แล้วอธิบายเหตุผลโดยใช้คำว่า ความชัน
  2. ในอนาคต คิดว่ากราฟจะยังเป็นรูปแบบเดิมต่อไปหรือไม่ เพราะอะไร
แนวคำตอบ

ข้อ 1: กราฟ C (แบนราบอยู่นาน แล้วพุ่งขึ้นชันมากในช่วงหลัง)

  • หลายพันปีที่ผ่านมาประชากรเพิ่มช้ามาก → ความชันเกือบเป็น 0
  • หลังการปฏิวัติอุตสาหกรรมและการแพทย์สมัยใหม่ ประชากรเพิ่มเร็วขึ้นเรื่อย ๆ → ความชันเพิ่มขึ้นตลอด
    (ประมาณ 1 พันล้านคนราว ค.ศ. 1800 → 2 พันล้านคน ค.ศ. 1927 → 8 พันล้านคน ค.ศ. 2022)
  • A ผิดเพราะความชันคงที่ · B ผิดเพราะประชากรยังไม่เคยลดลง · D ผิดเพราะลดลงตลอด

ข้อ 2: อัตราการเพิ่มของประชากรต่อปีสูงสุดราวทศวรรษ 1960 และตอนนี้ลดลงเหลือไม่ถึง 1% ต่อปี ความชันจึงน่าจะค่อย ๆ ลดลง กราฟอาจโค้งกลายเป็นรูปตัว S (ค่อย ๆ แบนลงอีกครั้ง)

เกณฑ์: ข้อ 1 ต้องเลือก C และอธิบายด้วยความชันที่ “เพิ่มขึ้น” · ข้อ 2 ตอบได้หลายแบบ ให้คะแนนถ้ามีเหตุผลรองรับ
