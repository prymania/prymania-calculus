ความชัน เส้นสัมผัส และค่าสูงสุด–ต่ำสุด

ความชันเส้นโค้ง สมการเส้นสัมผัส ฟังก์ชันเพิ่ม–ลด จุดวิกฤต ค่าสูงสุด–ต่ำสุดสัมพัทธ์และสัมบูรณ์

🎬 คำถามเปิดบท

ไม่ใช้เครื่องคิดเลข ลองตอบให้ได้ใน 10 วินาที: $\sqrt{4.1}$ มีค่าประมาณเท่าไร (ละเอียดถึงทศนิยม 2 ตำแหน่ง)?

และ: ทีมดูแลเซิร์ฟเวอร์ของแอปอยากรู้ว่า ช่วงไหนของวันมีคนใช้งานมากที่สุด จะได้เตรียมเครื่องให้พอ — ถ้ามีสูตรจำนวนผู้ใช้ตามเวลา จะหาจุดพีคได้อย่างไรโดยไม่ต้องลองแทนค่าทุกชั่วโมง?

🎯 เมื่อเรียนจบบทนี้ นิสิตจะสามารถ
  1. หาความชันของเส้นโค้ง ณ จุดใด ๆ และสมการเส้นสัมผัสได้
  2. หาจุดวิกฤต และช่วงที่ฟังก์ชันเพิ่ม/ลด ด้วยตารางเครื่องหมาย $f'(x)$
  3. ตัดสินว่าจุดวิกฤตเป็นค่าสูงสุดสัมพัทธ์ ต่ำสุดสัมพัทธ์ หรือจุดนิ่ง ด้วย $f'$ หรือ $f''$
  4. หาค่าสูงสุดและต่ำสุดสัมบูรณ์บนช่วงปิด $[a,b]$ ได้
  5. ใช้เส้นสัมผัสประมาณค่าฟังก์ชันใกล้จุดที่รู้ค่า (linear approximation) ได้

5.1 ความชันของเส้นโค้ง

เส้นตรงมีความชันเท่ากันทุกจุด แต่ เส้นโค้งมีความชันเปลี่ยนไปตามตำแหน่ง — ที่จุดใด ๆ ความชันของเส้นโค้งก็คือ ความชันของเส้นสัมผัสที่จุดนั้น ซึ่งหาได้จากการดิฟ 1 ครั้ง

📐 ความชันของ $y = f(x)$ ที่ $x = a$
$$m = f'(a)$$

ดิฟก่อน แล้วค่อยแทนค่า (อย่าแทนค่าก่อนดิฟ ไม่งั้นจะได้ค่าคงที่ซึ่งดิฟได้ 0 เสมอ!)

5.2 สมการเส้นสัมผัส (Tangent line)

เส้นสัมผัสคือเส้นตรงที่ “แตะ” กราฟที่จุดหนึ่ง โดยมีความชันเท่ากับความชันของกราฟที่จุดนั้นพอดี ใช้สมการ จุด–ความชัน:

📏 สมการเส้นสัมผัสที่ $x = x_1$
$$y - y_1 = m(x - x_1) \qquad\text{โดย}\quad y_1 = f(x_1),\ \ m = f'(x_1)$$
  1. $x_1$ = จุดที่โจทย์กำหนด
  2. $y_1$ = แทน $x_1$ ใน ฟังก์ชันเดิม $f(x)$
  3. $m$ = ดิฟ $f$ แล้วแทน $x_1$ ใน $f'(x)$
  4. แทนลงสมการ แล้วจัดให้อยู่ในรูป $y = mx + c$
ตัวอย่าง 5.3เส้นสัมผัสของ y = x³⭐⭐ ปานกลาง

หาสมการเส้นสัมผัสเส้นโค้ง $y = x^3$ ที่จุด $x = -3$ และ $x = 2$

เฉลย

ที่ x = −3: $y_1 = -27$, $y' = 3x^2$ → $m = 27$

$$y + 27 = 27(x + 3) \;\Rightarrow\; y = 27x + 54$$

ที่ x = 2: $y_1 = 8$, $m = 3(4) = 12$

$$y - 8 = 12(x - 2) \;\Rightarrow\; y = 12x - 16$$
ตัวอย่าง 5.4เส้นสัมผัส (ฝึกต่อ)⭐⭐ ปานกลาง
  1. $y = x^3 - x^2 + 5$ ที่ $x = 0$ และ $x = 3$
  2. $y = 5x^3 - 2x^2 - x$ ที่ $x = 0$ และ $x = 5$
  3. $y = \tfrac14x^4 - \tfrac23x^3 + 5x^2 - 10$ ที่ $x = 0$ และ $x = 2$
เฉลย

a) $y' = 3x^2 - 2x$

ที่ x = 0$y_1 = 5,\ m = 0$ → $y = 5$ (เส้นนอน) ที่ x = 3$y_1 = 27 - 9 + 5 = 23,\ m = 27 - 6 = 21$ → $y - 23 = 21(x-3)$ → $y = 21x - 40$

b) $y' = 15x^2 - 4x - 1$

ที่ x = 0$y_1 = 0,\ m = -1$ → $y = -x$ ที่ x = 5$y_1 = 625 - 50 - 5 = 570,\ m = 375 - 20 - 1 = 354$ → $y = 354x - 1770 + 570$ → $y = 354x - 1200$

c) $y' = x^3 - 2x^2 + 10x$

ที่ x = 0$y_1 = -10,\ m = 0$ → $y = -10$ ที่ x = 2$y_1 = 4 - \tfrac{16}{3} + 20 - 10 = \tfrac{26}{3},\ m = 8 - 8 + 20 = 20$ → $y = 20x - 40 + \tfrac{26}{3}$ → $y = 20x - \tfrac{94}{3}$

ใช้เส้นสัมผัสประมาณค่า (Linear approximation)

ลองลากจุดในกราฟด้านบนแล้วสังเกต: ใกล้ ๆ จุดสัมผัส เส้นสัมผัสแทบทับกราฟ เราจึงใช้เส้นตรง (ซึ่งคำนวณง่าย) แทนเส้นโค้งได้ เมื่อ $x$ อยู่ใกล้จุดที่รู้ค่า

📏 ค่าประมาณจากเส้นสัมผัสที่ $x = a$
$$f(x) \approx f(a) + f'(a)(x - a) \qquad\text{เมื่อ } x \text{ ใกล้ } a$$

หา $\sqrt{4.1}$: ใช้ $f(x) = \sqrt x$ ที่ $a = 4$ (รู้ว่า $\sqrt4 = 2$) และ $f'(x) = \dfrac{1}{2\sqrt x}$ ได้ $f'(4) = \dfrac14$

$$\sqrt{4.1} \approx 2 + \tfrac14(4.1 - 4) = 2 + 0.025 = 2.025$$
เทียบค่าประมาณจากเส้นสัมผัสกับค่าจริง
import math

def approx(x):              # เส้นสัมผัสของ sqrt(x) ที่ x = 4
    return 2 + (x - 4) / 4

for x in [4.1, 4.5, 5, 9]:
    real = math.sqrt(x)
    print(f"x = {x:<4}  ประมาณ = {approx(x):.4f}  จริง = {real:.4f}  คลาดเคลื่อน = {abs(approx(x) - real):.4f}")

x = 4.1   ประมาณ = 2.0250  จริง = 2.0248  คลาดเคลื่อน = 0.0002
x = 4.5   ประมาณ = 2.1250  จริง = 2.1213  คลาดเคลื่อน = 0.0037
x = 5     ประมาณ = 2.2500  จริง = 2.2361  คลาดเคลื่อน = 0.0139

💻 ในโลกคอมพิวเตอร์

คอมพิวเตอร์ “วาดเส้นโค้ง” ไม่เป็น — มันวาดได้แต่เส้นตรงสั้น ๆ หลายร้อยเส้นต่อกัน (กราฟทุกรูปในเว็บนี้ก็วาดแบบนั้น) และเมื่อต้องคำนวณฟังก์ชันยาก ๆ อย่างรวดเร็ว เช่น ฟิสิกส์ในเกมที่ต้องคำนวณ 60 ครั้งต่อวินาที ก็มักใช้เส้นตรงประมาณเส้นโค้งในช่วงสั้น ๆ แบบเดียวกับหัวข้อนี้

5.3 ฟังก์ชันเพิ่ม ฟังก์ชันลด และจุดวิกฤต

↗ ฟังก์ชันเพิ่ม (increasing)

x เพิ่ม แล้ว y เพิ่ม · ความชันเป็นบวก $\;f'(x) > 0$

↘ ฟังก์ชันลด (decreasing)

x เพิ่ม แล้ว y ลด · ความชันเป็นลบ $\;f'(x) \lt 0$

จุดวิกฤต (critical point) คือจุดที่ $f'(x) = 0$ (หรือ $f'$ หาค่าไม่ได้) — เป็นจุดที่กราฟ “แบนราบ” ชั่วขณะ อาจเป็น

🧭 ขั้นตอนหาช่วงเพิ่ม/ลด และจุดวิกฤต
  1. หา $f'(x)$
  2. แก้สมการ $f'(x) = 0$ ได้ค่า x ของจุดวิกฤต แล้วแทนใน $f(x)$ เดิม เพื่อได้พิกัด $(x, y)$
  3. แบ่งเส้นจำนวนตามจุดวิกฤต เลือกเลขง่าย ๆ ในแต่ละช่วงไปแทนใน $f'(x)$ ดูเครื่องหมาย
  4. สรุป: $+$ = เพิ่ม, $-$ = ลด

5.4 ทดสอบสูงสุด–ต่ำสุดสัมพัทธ์

วิธีที่ 1: ดูเครื่องหมาย $f'$ (First derivative test)

  • $f'$ เปลี่ยนจาก + เป็น − → สูงสุดสัมพัทธ์ ⛰️
  • $f'$ เปลี่ยนจาก − เป็น + → ต่ำสุดสัมพัทธ์ 🏞️
  • ไม่เปลี่ยนเครื่องหมาย → จุดนิ่ง

วิธีที่ 2: ดู $f''$ (Second derivative test)

  • $f''(c) \lt 0$ (กราฟคว่ำ ∩) → สูงสุด
  • $f''(c) > 0$ (กราฟหงาย ∪) → ต่ำสุด
  • $f''(c) = 0$ → สรุปไม่ได้ ใช้วิธีที่ 1
🙂 จำแบบหน้ายิ้ม–หน้าบึ้ง

$f'' > 0$ กราฟหงายเหมือน ปากยิ้ม ∪ ก้นถ้วยคือจุดต่ำสุด · $f'' \lt 0$ กราฟคว่ำเหมือน ปากบึ้ง ∩ ยอดคือจุดสูงสุด

5.5 ค่าสูงสุด–ต่ำสุดสัมบูรณ์บนช่วงปิด

บนช่วงปิด $[a, b]$ ฟังก์ชันต่อเนื่องจะมีค่าสูงสุดและต่ำสุด “ทั้งหมด” (สัมบูรณ์) เสมอ และมันจะเกิดที่ จุดวิกฤตในช่วง หรือ ที่ปลายช่วง เท่านั้น

🏁 ขั้นตอน (Closed interval method)
  1. หาจุดวิกฤต ($f'(x) = 0$) เก็บเฉพาะที่อยู่ในช่วง $[a,b]$
  2. แทนค่าจุดวิกฤตเหล่านั้นใน $f(x)$
  3. แทนค่าปลายช่วง $f(a)$ และ $f(b)$
  4. ค่ามากที่สุด = สูงสุดสัมบูรณ์ · ค่าน้อยที่สุด = ต่ำสุดสัมบูรณ์

💻 ในโลกคอมพิวเตอร์: หาช่วงพีคของระบบ

จุดวิกฤตคือ “ยอดเขา” และ “ก้นหุบ” ของกราฟข้อมูล — ใช้หาช่วงที่มีคนใช้งานมากที่สุด ช่วงที่ราคาหุ้นกลับตัว หรือจุดที่โมเดล AI มีความผิดพลาดน้อยที่สุด (ซึ่งจะเห็นในบทที่ 6)

ตัวอย่าง 5.17ผู้ใช้งานพร้อมกันสูงสุดเมื่อไร⭐ ง่าย

จำนวนผู้ใช้งานพร้อมกัน (พันคน) ของแอปหนึ่ง ในช่วง 8:00–20:00 น. ประมาณได้ด้วย $U(t) = -0.5t^2 + 14t - 60$ เมื่อ $t$ คือเวลา (ชั่วโมง) จงหาเวลาที่มีผู้ใช้มากที่สุด และจำนวนผู้ใช้ตอนนั้น

เฉลย

$U'(t) = -t + 14 = 0 \Rightarrow t = 14$ (อยู่ในช่วง [8, 20]) · $U''(t) = -1 \lt 0$ → สูงสุด

$U(14) = -98 + 196 - 60 = 38$ → 14:00 น. มีผู้ใช้ประมาณ 38,000 คน (ตรวจปลายช่วง: $U(8) = 20$, $U(20) = 20$ น้อยกว่า)

🎬 กลับมาตอบคำถามเปิดบท

$\sqrt{4.1} \approx 2.025$ — ได้จาก เส้นสัมผัส ของ $\sqrt x$ ที่ $x = 4$ (ค่าจริงคือ 2.0248… ผิดไม่ถึง 0.001)

ช่วงพีคของผู้ใช้ หาได้จาก จุดวิกฤต ที่ $U'(t) = 0$ แล้วตรวจด้วย $f''$ หรือปลายช่วง — ไม่ต้องลองแทนค่าทีละชั่วโมง

ตรวจคำตอบด้วย Python (SymPy)
from sympy import symbols, diff, solve, Rational
x = symbols('x')
f = Rational(1, 4)*x**4 - x**3 + x**2 + 4
crit = solve(diff(f, x), x)
print("จุดวิกฤต:", crit)
for c in [-2] + crit + [5]:
    print("  f(%s) = %s" % (c, f.subs(x, c)))
