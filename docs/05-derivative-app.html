บทที่ 5 · ความชัน เส้นสัมผัส และค่าสูงสุด–ต่ำสุด

ความชันเส้นโค้ง สมการเส้นสัมผัส ฟังก์ชันเพิ่ม–ลด จุดวิกฤต ค่าสูงสุด–ต่ำสุดสัมพัทธ์และสัมบูรณ์

🎯 เมื่อเรียนจบบทนี้ นิสิตจะสามารถ
  1. หาความชันของเส้นโค้ง ณ จุดใด ๆ และสมการเส้นสัมผัสได้
  2. หาจุดวิกฤต และช่วงที่ฟังก์ชันเพิ่ม/ลด ด้วยตารางเครื่องหมาย $f'(x)$
  3. ตัดสินว่าจุดวิกฤตเป็นค่าสูงสุดสัมพัทธ์ ต่ำสุดสัมพัทธ์ หรือจุดนิ่ง ด้วย $f'$ หรือ $f''$
  4. หาค่าสูงสุดและต่ำสุดสัมบูรณ์บนช่วงปิด $[a,b]$ ได้

5.1 ความชันของเส้นโค้ง

เส้นตรงมีความชันเท่ากันทุกจุด แต่ เส้นโค้งมีความชันเปลี่ยนไปตามตำแหน่ง — ที่จุดใด ๆ ความชันของเส้นโค้งก็คือ ความชันของเส้นสัมผัสที่จุดนั้น ซึ่งหาได้จากการดิฟ 1 ครั้ง

📐 ความชันของ $y = f(x)$ ที่ $x = a$
$$m = f'(a)$$

ดิฟก่อน แล้วค่อยแทนค่า (อย่าแทนค่าก่อนดิฟ ไม่งั้นจะได้ค่าคงที่ซึ่งดิฟได้ 0 เสมอ!)

ตัวอย่าง 5.1ความชันของ y = x² หลายจุด⭐ ง่าย

หาความชันเส้นโค้งของ $y = x^2$ ที่จุด $x = -4,\ x = 2$ และ $x = 5$

✅ เฉลย

$y' = 2x$ → ที่ $x = -4$: −8 · ที่ $x = 2$: 4 · ที่ $x = 5$: 10

ซ้ายมือกราฟลง (ความชันลบ) ขวามือกราฟขึ้นชันขึ้นเรื่อย ๆ (ความชันบวกมากขึ้น)

ตัวอย่าง 5.2ความชัน ณ จุดต่าง ๆ⭐ ง่าย
  1. $y = 5x^3 + 3x^2 - 1$ ที่ $x = 0$ และ $x = 5$
  2. $y = -10x^3 - 2x^2 - 3x$ ที่ $x = -5,\ 0,\ 1$
  3. $y = -x^2 - x^3$ ที่ $x = -4,\ 0,\ 4$
✅ เฉลย

a) $y' = 15x^2 + 6x$ → $0$ และ $375 + 30 = 405$

b) $y' = -30x^2 - 4x - 3$ → $-750 + 20 - 3 = -733$, $-3$, $-37$

c) $y' = -2x - 3x^2$ → $8 - 48 = -40$, $0$, $-8 - 48 = -56$

5.2 สมการเส้นสัมผัส (Tangent line)

เส้นสัมผัสคือเส้นตรงที่ “แตะ” กราฟที่จุดหนึ่ง โดยมีความชันเท่ากับความชันของกราฟที่จุดนั้นพอดี ใช้สมการ จุด–ความชัน:

📏 สมการเส้นสัมผัสที่ $x = x_1$
$$y - y_1 = m(x - x_1) \qquad\text{โดย}\quad y_1 = f(x_1),\ \ m = f'(x_1)$$
  1. $x_1$ = จุดที่โจทย์กำหนด
  2. $y_1$ = แทน $x_1$ ใน ฟังก์ชันเดิม $f(x)$
  3. $m$ = ดิฟ $f$ แล้วแทน $x_1$ ใน $f'(x)$
  4. แทนลงสมการ แล้วจัดให้อยู่ในรูป $y = mx + c$
ตัวอย่าง 5.3เส้นสัมผัสของ y = x³⭐⭐ ปานกลาง

หาสมการเส้นสัมผัสเส้นโค้ง $y = x^3$ ที่จุด $x = -3$ และ $x = 2$

✅ เฉลย

ที่ x = −3: $y_1 = -27$, $y' = 3x^2$ → $m = 27$

$$y + 27 = 27(x + 3) \;\Rightarrow\; y = 27x + 54$$

ที่ x = 2: $y_1 = 8$, $m = 3(4) = 12$

$$y - 8 = 12(x - 2) \;\Rightarrow\; y = 12x - 16$$
ตัวอย่าง 5.4เส้นสัมผัส (ฝึกต่อ)⭐⭐ ปานกลาง
  1. $y = x^3 - x^2 + 5$ ที่ $x = 0$ และ $x = 3$
  2. $y = 5x^3 - 2x^2 - x$ ที่ $x = 0$ และ $x = 5$
  3. $y = \tfrac14x^4 - \tfrac23x^3 + 5x^2 - 10$ ที่ $x = 0$ และ $x = 2$
✅ เฉลย

a) $y' = 3x^2 - 2x$ · ที่ 0: $y_1 = 5,\ m = 0$ → $y = 5$ (เส้นนอน) · ที่ 3: $y_1 = 27 - 9 + 5 = 23,\ m = 27 - 6 = 21$ → $y - 23 = 21(x-3)$ → $y = 21x - 40$

b) $y' = 15x^2 - 4x - 1$ · ที่ 0: $y_1 = 0,\ m = -1$ → $y = -x$ · ที่ 5: $y_1 = 625 - 50 - 5 = 570,\ m = 375 - 20 - 1 = 354$ → $y = 354x - 1770 + 570$ → $y = 354x - 1200$

c) $y' = x^3 - 2x^2 + 10x$ · ที่ 0: $y_1 = -10,\ m = 0$ → $y = -10$ · ที่ 2: $y_1 = 4 - \tfrac{16}{3} + 20 - 10 = \tfrac{26}{3},\ m = 8 - 8 + 20 = 20$ → $y = 20x - 40 + \tfrac{26}{3}$ → $y = 20x - \tfrac{94}{3}$

5.3 ฟังก์ชันเพิ่ม ฟังก์ชันลด และจุดวิกฤต

↗ ฟังก์ชันเพิ่ม (increasing)

x เพิ่ม แล้ว y เพิ่ม · ความชันเป็นบวก $\;f'(x) > 0$

↘ ฟังก์ชันลด (decreasing)

x เพิ่ม แล้ว y ลด · ความชันเป็นลบ $\;f'(x) \lt 0$

จุดวิกฤต (critical point) คือจุดที่ $f'(x) = 0$ (หรือ $f'$ หาค่าไม่ได้) — เป็นจุดที่กราฟ “แบนราบ” ชั่วขณะ อาจเป็น

🧭 ขั้นตอนหาช่วงเพิ่ม/ลด และจุดวิกฤต
  1. หา $f'(x)$
  2. แก้สมการ $f'(x) = 0$ ได้ค่า x ของจุดวิกฤต แล้วแทนใน $f(x)$ เดิม เพื่อได้พิกัด $(x, y)$
  3. แบ่งเส้นจำนวนตามจุดวิกฤต เลือกเลขง่าย ๆ ในแต่ละช่วงไปแทนใน $f'(x)$ ดูเครื่องหมาย
  4. สรุป: $+$ = เพิ่ม, $-$ = ลด
ตัวอย่าง 5.5พาราโบลา⭐ ง่าย

หาช่วงเพิ่ม ช่วงลด และจุดวิกฤตของ $y = x^2 - 2x + 3$

✅ เฉลย

$y' = 2x - 2 = 0 \Rightarrow x = 1$ · $y(1) = 1 - 2 + 3 = 2$ → จุดวิกฤต (1, 2)

ทดสอบ: x = 0 → $y' = -2$ (ลบ) · x = 2 → $y' = 2$ (บวก)

ลดเมื่อ $x \lt 1$ · เพิ่มเมื่อ $x > 1$ · (1, 2) เป็นจุดต่ำสุด

ตัวอย่าง 5.6พาราโบลา (สัมประสิทธิ์ไม่สวย)⭐ ง่าย

$y = 3x^2 + 4x + 10$

✅ เฉลย

$y' = 6x + 4 = 0 \Rightarrow x = -\tfrac23$ · $y = 3\cdot\tfrac49 - \tfrac83 + 10 = \tfrac43 - \tfrac83 + 10 = \tfrac{26}{3}$ → จุดวิกฤต $\left(-\tfrac23, \tfrac{26}{3}\right)$

x = −1 → $y' = -2$ ลด · x = 0 → $y' = 4$ เพิ่ม → ลดเมื่อ $x \lt -\tfrac23$ · เพิ่มเมื่อ $x > -\tfrac23$

ตัวอย่าง 5.7กำลังสาม สองจุดวิกฤต⭐⭐ ปานกลาง

$y = 2x^3 - 3x^2 - 12x + 5$

✅ เฉลย

$y' = 6x^2 - 6x - 12 = 6(x^2 - x - 2) = 6(x-2)(x+1) = 0$ → $x = -1,\ 2$

$y(-1) = -2 - 3 + 12 + 5 = 12$ · $y(2) = 16 - 12 - 24 + 5 = -15$ → จุดวิกฤต (−1, 12) และ (2, −15)

ทดสอบใน $y'$: $y'(-2) = 24 + 12 - 12 = 24$ (+) · $y'(0) = -12$ (−) · $y'(10) = 528$ (+)

เพิ่มบน $(-\infty,-1)\cup(2,\infty)$ · ลดบน $(-1, 2)$ · (−1, 12) สูงสุดสัมพัทธ์ · (2, −15) ต่ำสุดสัมพัทธ์

ตัวอย่าง 5.8รากเป็น 0⭐⭐ ปานกลาง

$y = x^3 - x^2 - 10$

✅ เฉลย

$y' = 3x^2 - 2x = x(3x - 2) = 0$ → $x = 0,\ \tfrac23$ · $y(0) = -10$ · $y(\tfrac23) = \tfrac{8}{27} - \tfrac{4}{9} - 10 = -\tfrac{274}{27} \approx -10.15$

เพิ่มบน $(-\infty, 0)\cup(\tfrac23,\infty)$ · ลดบน $(0, \tfrac23)$

ตัวอย่าง 5.9ระวัง! รากซ้ำ⭐⭐⭐ ท้าทาย

$y = 4x^3 - 60x^2 + 300x$

✅ เฉลย

$y' = 12x^2 - 120x + 300 = 12(x^2 - 10x + 25) = 12(x-5)^2 = 0$ → $x = 5$ จุดเดียว · $y(5) = 500 - 1500 + 1500 = 500$

ทดสอบใน $y'$: $y'(0) = 300$ (+) · $y'(10) = 1200 - 1200 + 300 = 300$ (+)

เครื่องหมายไม่เปลี่ยน → (5, 500) เป็น จุดนิ่ง ไม่ใช่สูงสุดหรือต่ำสุด · ฟังก์ชันเพิ่มตลอด (ยกเว้นแบนราบชั่วขณะที่ x = 5)

ตัวอย่าง 5.10ลองทำเอง: กำลังสามอีกสามข้อ⭐⭐ ปานกลาง
  1. $y = x^3 - 6x^2 + 9x + 2$
  2. $y = x^3 - 9x^2 + 24x - 16$
  3. $y = \tfrac13x^3 - x^2 - 15x + 3$
✅ เฉลย

a) $y' = 3(x-1)(x-3)$ · เพิ่ม $(-\infty,1)\cup(3,\infty)$ ลด $(1,3)$ · สูงสุดสัมพัทธ์ (1, 6) ต่ำสุดสัมพัทธ์ (3, 2)

b) $y' = 3(x-2)(x-4)$ · เพิ่ม $(-\infty,2)\cup(4,\infty)$ ลด $(2,4)$ · สูงสุดสัมพัทธ์ (2, 4) ต่ำสุดสัมพัทธ์ (4, 0)

c) $y' = x^2 - 2x - 15 = (x-5)(x+3)$ · เพิ่ม $(-\infty,-3)\cup(5,\infty)$ ลด $(-3,5)$ · สูงสุดสัมพัทธ์ (−3, 30) ต่ำสุดสัมพัทธ์ $(5, -\tfrac{166}{3})$

ตัวอย่าง 5.11กำลังสี่ สามจุดวิกฤต⭐⭐⭐ ท้าทาย

$y = \tfrac14x^4 - x^3 + x^2 + 4$

✅ เฉลย

$y' = x^3 - 3x^2 + 2x = x(x-1)(x-2) = 0$ → $x = 0, 1, 2$ · $y(0) = 4,\ y(1) = \tfrac14 - 1 + 1 + 4 = 4.25,\ y(2) = 4 - 8 + 4 + 4 = 4$

ลดบน $(-\infty,0)\cup(1,2)$ · เพิ่มบน $(0,1)\cup(2,\infty)$ · ต่ำสุดสัมพัทธ์ (0, 4), (2, 4) · สูงสุดสัมพัทธ์ (1, 4.25)

5.4 ทดสอบสูงสุด–ต่ำสุดสัมพัทธ์

วิธีที่ 1: ดูเครื่องหมาย $f'$ (First derivative test)

  • $f'$ เปลี่ยนจาก + เป็น − → สูงสุดสัมพัทธ์ ⛰️
  • $f'$ เปลี่ยนจาก − เป็น + → ต่ำสุดสัมพัทธ์ 🏞️
  • ไม่เปลี่ยนเครื่องหมาย → จุดนิ่ง

วิธีที่ 2: ดู $f''$ (Second derivative test)

  • $f''(c) \lt 0$ (กราฟคว่ำ ∩) → สูงสุด
  • $f''(c) > 0$ (กราฟหงาย ∪) → ต่ำสุด
  • $f''(c) = 0$ → สรุปไม่ได้ ใช้วิธีที่ 1
🙂 จำแบบหน้ายิ้ม–หน้าบึ้ง

$f'' > 0$ กราฟหงายเหมือน ปากยิ้ม ∪ ก้นถ้วยคือจุดต่ำสุด · $f'' \lt 0$ กราฟคว่ำเหมือน ปากบึ้ง ∩ ยอดคือจุดสูงสุด

ตัวอย่าง 5.12ใช้ f'' ตัดสิน⭐⭐ ปานกลาง

$f(x) = x^3 - 3x^2 - 9x + 5$ จงหาจุดวิกฤตและใช้อนุพันธ์อันดับสองบอกชนิด

✅ เฉลย

$f'(x) = 3x^2 - 6x - 9 = 3(x-3)(x+1)$ → $x = -1,\ 3$ · $f''(x) = 6x - 6$

$f''(-1) = -12 \lt 0$ → สูงสุดสัมพัทธ์ที่ $(-1, f(-1)) = (-1, 10)$

$f''(3) = 12 > 0$ → ต่ำสุดสัมพัทธ์ที่ $(3, f(3)) = (3, -22)$

5.5 ค่าสูงสุด–ต่ำสุดสัมบูรณ์บนช่วงปิด

บนช่วงปิด $[a, b]$ ฟังก์ชันต่อเนื่องจะมีค่าสูงสุดและต่ำสุด “ทั้งหมด” (สัมบูรณ์) เสมอ และมันจะเกิดที่ จุดวิกฤตในช่วง หรือ ที่ปลายช่วง เท่านั้น

🏁 ขั้นตอน (Closed interval method)
  1. หาจุดวิกฤต ($f'(x) = 0$) เก็บเฉพาะที่อยู่ในช่วง $[a,b]$
  2. แทนค่าจุดวิกฤตเหล่านั้นใน $f(x)$
  3. แทนค่าปลายช่วง $f(a)$ และ $f(b)$
  4. ค่ามากที่สุด = สูงสุดสัมบูรณ์ · ค่าน้อยที่สุด = ต่ำสุดสัมบูรณ์
ตัวอย่าง 5.13ช่วงปิด [−10, 0]⭐⭐ ปานกลาง

หาค่าสูงสุดและต่ำสุดสัมบูรณ์ของ $y = x^3 - 3x^2 - 9x + 5$ บนช่วง $[-10, 0]$

✅ เฉลย

จุดวิกฤต x = −1, 3 → x = 3 อยู่นอกช่วง ตัดทิ้ง

xf(x)ชนิด

สูงสุดสัมบูรณ์ 10 ที่ x = −1 · ต่ำสุดสัมบูรณ์ −1205 ที่ x = −10

ตัวอย่าง 5.14ช่วงปิด [−2, 10]⭐⭐ ปานกลาง

$y = \tfrac13x^3 - x^2 - 15x + 3$ บนช่วง $[-2, 10]$

✅ เฉลย

$y' = (x-5)(x+3)$ → x = −3 อยู่นอกช่วง เหลือ x = 5

$y(-2) = -\tfrac83 - 4 + 30 + 3 = \tfrac{79}{3} \approx 26.33$ · $y(5) = -\tfrac{166}{3} \approx -55.33$ · $y(10) = \tfrac{1000}{3} - 247 = \tfrac{259}{3} \approx 86.33$

สูงสุดสัมบูรณ์ $\tfrac{259}{3}$ ที่ x = 10 · ต่ำสุดสัมบูรณ์ $-\tfrac{166}{3}$ ที่ x = 5

ตัวอย่าง 5.15ช่วงปิด [−2, 5]⭐⭐⭐ ท้าทาย

$y = \tfrac14x^4 - x^3 + x^2 + 4$ บนช่วง $[-2, 5]$

✅ เฉลย

จุดวิกฤต x = 0, 1, 2 (อยู่ในช่วงทั้งหมด)

สูงสุดสัมบูรณ์ 60.25 ที่ x = 5 · ต่ำสุดสัมบูรณ์ 4 ที่ x = 0 และ x = 2 (x = 1 ให้ 4.25 ซึ่งไม่ใช่ต่ำสุด)

ตรวจคำตอบด้วย Python (SymPy)
from sympy import symbols, diff, solve, Rational
x = symbols('x')
f = Rational(1, 4)*x**4 - x**3 + x**2 + 4
crit = solve(diff(f, x), x)
print("จุดวิกฤต:", crit)
for c in [-2] + crit + [5]:
    print("  f(%s) = %s" % (c, f.subs(x, c)))

  1. ความชันและเส้นสัมผัส
  2. จงหาความชันของ $y = 2x^3 - 4x + 1$ ที่ $x = -1$ และ $x = 2$

    $y' = 6x^2 - 4$ → $y'(-1) = 2$ · $y'(2) = 20$

  3. จงหาสมการเส้นสัมผัส $y = x^2 - 4x + 1$ ที่ $x = 3$

    $y_1 = 9 - 12 + 1 = -2$ · $m = 2(3) - 4 = 2$ → $y + 2 = 2(x - 3)$ → $y = 2x - 8$

  4. จงหาสมการเส้นสัมผัส $y = \dfrac{4}{x}$ ที่จุด $(2, 2)$ (แยกตัวส่วน)

    $y' = -\dfrac{4}{x^2}$ → $m = -1$ → $y - 2 = -(x - 2)$ → $y = -x + 4$

  5. จงหาจุดบนกราฟ $y = x^2 - 6x + 10$ ที่เส้นสัมผัสขนานกับแกน x (ความชัน = 0)

    ขนานแกน x คือความชัน 0: $2x - 6 = 0 \Rightarrow x = 3,\ y = 1$ → จุด (3, 1)

  6. ฟังก์ชันเพิ่ม/ลด จุดวิกฤต
  7. จงหาช่วงเพิ่ม ช่วงลด และจุดวิกฤตของ $y = -x^2 + 8x - 7$

    $y' = -2x + 8 = 0 \Rightarrow x = 4,\ y = 9$ · เพิ่มเมื่อ $x \lt 4$ ลดเมื่อ $x > 4$ · (4, 9) สูงสุดสัมพัทธ์

  8. จงหาช่วงเพิ่ม ช่วงลด และจุดวิกฤตของ $y = x^3 - 12x + 2$

    $y' = 3x^2 - 12 = 3(x-2)(x+2)$ · จุดวิกฤต (−2, 18) สูงสุด, (2, −14) ต่ำสุด · เพิ่ม $(-\infty,-2)\cup(2,\infty)$ ลด $(-2,2)$

  9. จงหาช่วงเพิ่ม ช่วงลดของ $y = 2x^3 + 3x^2 - 36x$ (ตารางเครื่องหมาย)

    $y' = 6x^2 + 6x - 36 = 6(x+3)(x-2)$ · จุดวิกฤต (−3, 81) สูงสุด และ (2, −44) ต่ำสุด · เพิ่ม $(-\infty,-3)\cup(2,\infty)$ ลด $(-3, 2)$

  10. ฟังก์ชัน $y = x^3 + 3x$ มีจุดวิกฤตหรือไม่ เป็นฟังก์ชันเพิ่มหรือลด

    $y' = 3x^2 + 3 > 0$ ทุก x จึง ไม่มีจุดวิกฤต และเป็นฟังก์ชันเพิ่มตลอด

  11. จุดวิกฤตของ $y = (x-1)^3 + 2$ เป็นจุดชนิดใด (รากซ้ำ)

    $y' = 3(x-1)^2 = 0 \Rightarrow x = 1$ · $y'$ เป็นบวกทั้งสองข้าง → จุดนิ่ง (1, 2) ไม่ใช่สูงสุด/ต่ำสุด

  12. สูงสุด–ต่ำสุด
  13. ใช้อนุพันธ์อันดับสองตัดสินชนิดของจุดวิกฤตของ $f(x) = x^3 - 6x^2 + 5$

    $f' = 3x^2 - 12x = 3x(x-4)$ · $f'' = 6x - 12$ · $f''(0) = -12$ → สูงสุดสัมพัทธ์ (0, 5) · $f''(4) = 12$ → ต่ำสุดสัมพัทธ์ (4, −27)

  14. หาค่าสูงสุดและต่ำสุดสัมบูรณ์ของ $f(x) = x^3 - 3x$ บนช่วง $[0, 3]$ (อย่าลืมปลายช่วง)

    $f' = 3(x-1)(x+1)$ เก็บ x = 1 · $f(0) = 0,\ f(1) = -2,\ f(3) = 18$ → สูงสุด 18 ที่ x = 3 · ต่ำสุด −2 ที่ x = 1

  15. หาค่าสูงสุดและต่ำสุดสัมบูรณ์ของ $f(x) = -x^2 + 4x + 1$ บนช่วง $[-1, 3]$

    $f' = -2x + 4 = 0 \Rightarrow x = 2$ · $f(-1) = -4,\ f(2) = 5,\ f(3) = 4$ → สูงสุด 5 ที่ x = 2 · ต่ำสุด −4 ที่ x = −1
