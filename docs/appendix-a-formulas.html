ความชันและเส้นตรง

$$m = \frac{y_2-y_1}{x_2-x_1}$$ $$y = mx + c,\quad y - y_1 = m(x - x_1)$$

ผลต่างกำลังสอง

$$a^2 - b^2 = (a-b)(a+b)$$

ใช้ทำคอนจูเกตด้วย

ผลต่าง / ผลบวกกำลังสาม

$$a^3 - b^3 = (a-b)(a^2+ab+b^2)$$ $$a^3 + b^3 = (a+b)(a^2-ab+b^2)$$

กำลังสองสมบูรณ์

$$(a\pm b)^2 = a^2 \pm 2ab + b^2$$

$x^2+bx+c$: หาเลขที่คูณได้ c บวกได้ b

เลขยกกำลัง

$$\frac1{x^n} = x^{-n},\quad \sqrt[n]{x^m} = x^{m/n}$$

$$(f\circ g)(x) = f(g(x))$$

ทำ g ก่อน

ลิมิตและความต่อเนื่อง

ลิมิตมีค่า

$$\lim_{x\to a^-}f = \lim_{x\to a^+}f$$

แทนค่าได้ $\frac{0}{0}$

แยกตัวประกอบ / คูณคอนจูเกต → ตัด → แทนค่าใหม่

แทนค่าได้ $\frac{k}{0},\ k\ne0$

ลิมิตหาค่าไม่ได้

$x\to\infty$ ของ $\frac{P}{Q}$

กำลังเศษ < ส่วน → 0
กำลังเท่ากัน → อัตราส่วนสัมประสิทธิ์ตัวหน้า
กำลังเศษ > ส่วน → ±∞

ต่อเนื่องที่ x = a

① $f(a)$ มีค่า
② $\lim_{x\to a} f$ มีค่า
③ $\lim_{x\to a} f = f(a)$

อนุพันธ์

นิยาม

$$f'(x) = \lim_{h\to0}\frac{f(x+h)-f(x)}{h}$$

ค่าคงที่ / ยกกำลัง

$$\frac{d}{dx}C = 0,\quad \frac{d}{dx}ax^n = nax^{n-1}$$

ผลคูณ

$$(fg)' = fg' + gf'$$

ผลหาร

$$\left(\frac{f}{g}\right)' = \frac{gf' - fg'}{g^2}$$

กฎลูกโซ่

$$\frac{d}{dx}[u]^n = n[u]^{n-1}\cdot u'$$

ฟังก์ชันประกอบ

$$(f\circ g)' = f'(g(x))\cdot g'(x)$$

รากและเศษส่วน

$$\frac{d}{dx}\sqrt x = \frac1{2\sqrt x},\quad \frac{d}{dx}\frac1x = -\frac1{x^2}$$

ตำแหน่ง → ความเร็ว → ความเร่ง

$$v = s',\quad a = v' = s''$$

การประยุกต์อนุพันธ์

เส้นสัมผัสที่ $x_1$

$$y - f(x_1) = f'(x_1)(x - x_1)$$

เพิ่ม / ลด

$f' > 0$ → เพิ่ม ↗
$f' \lt 0$ → ลด ↘
$f' = 0$ → จุดวิกฤต

ทดสอบด้วย $f'$

$f'$ เปลี่ยน + → − : สูงสุด
$f'$ เปลี่ยน − → + : ต่ำสุด
ไม่เปลี่ยนเครื่องหมาย : จุดนิ่ง

ทดสอบด้วย $f''$

$f'' \lt 0$ → สูงสุด (∩)
$f'' > 0$ → ต่ำสุด (∪)

สูงสุด–ต่ำสุดสัมบูรณ์บน [a, b]

เทียบ f ที่จุดวิกฤตในช่วง + ที่ปลายช่วง a, b

โจทย์ปัญหา

วาดรูป → ตั้งตัวแปร → ฟังก์ชันตัวแปรเดียว → ดิฟ = 0 → ตรวจ + ตอบพร้อมหน่วย
