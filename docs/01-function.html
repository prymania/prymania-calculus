บทที่ 1 · ฟังก์ชัน กราฟ และความชัน

ฟังก์ชันคืออะไร โดเมนและเรนจ์ การหาค่าฟังก์ชัน ฟังก์ชันประกอบ ความชันและสมการเส้นตรง

🎯 เมื่อเรียนจบบทนี้ นิสิตจะสามารถ

💡 ทำไมแคลคูลัสต้องเริ่มที่ฟังก์ชัน?

แคลคูลัสคือคณิตศาสตร์ของ “การเปลี่ยนแปลง” — ความเร็วรถเปลี่ยนไปอย่างไร ยอดขายโตเร็วแค่ไหน พื้นที่ใต้กราฟมีเท่าไร ทุกอย่างที่เราจะวัดการเปลี่ยนแปลง ต้องเขียนออกมาเป็น ฟังก์ชัน ก่อนเสมอ และเครื่องมือแรกที่ใช้วัดการเปลี่ยนแปลงก็คือ ความชัน ของเส้นตรง — สองเรื่องนี้จึงเป็นฐานของทั้งวิชา

1.1 ฟังก์ชันคืออะไร

ฟังก์ชัน (Function) คือความสัมพันธ์ระหว่างเซตของ input กับเซตของ output โดยที่ input แต่ละค่า ต้องให้ output ได้เพียง 1 ค่าเท่านั้น

ลองนึกภาพ ตู้กดน้ำ 🥤 — กดปุ่ม A ต้องได้โค้กเสมอ ถ้ากดปุ่ม A แล้วบางทีได้โค้ก บางทีได้น้ำเปล่า ตู้นั้นก็ “ไม่ใช่ฟังก์ชัน” (และน่าจะเสีย 😅)

x = 3input
➜
f(x) = 2x + 1เครื่องจักรฟังก์ชัน
➜
f(3) = 7output (ได้ค่าเดียว)

เราเขียนฟังก์ชันได้หลายแบบ เช่น $y = x^2 + 5x - 3$ หรือ $f(x) = 3x + 8$ โดย $f(x)$ อ่านว่า “เอฟของเอ็กซ์” หมายถึง ค่า output เมื่อใส่ input เป็น x

หลายตัวไปตัวเดียวได้ แต่ตัวเดียวไปหลายตัวไม่ได้

✅ เป็นฟังก์ชัน

$R = \{(1,2),(2,2),(3,3),(4,3)\}$ — ทุก input มีลูกศรออก เส้นเดียว (ไปซ้ำกันได้)

❌ ไม่เป็นฟังก์ชัน

input 1 ให้ output ได้ทั้ง 1 และ −1 → ไม่ใช่ฟังก์ชัน

ดูจากกราฟ: Vertical Line Test (ลากเส้นตั้ง)

ลากเส้นแนวตั้งผ่านกราฟที่ตำแหน่งใดก็ได้ — ถ้ามีตำแหน่งที่เส้นตั้งตัดกราฟมากกว่า 1 จุด แสดงว่าไม่เป็นฟังก์ชัน (เพราะ x ค่าเดียวได้ y หลายค่า)

ตัวอย่าง 1.1สมการใดเป็นฟังก์ชัน⭐ ง่าย

พิจารณาว่าความสัมพันธ์ต่อไปนี้เป็นฟังก์ชันหรือไม่ เพราะเหตุใด

  1. $y = -x^2 - 5$
  2. $|y| = x$
  3. $y = 2x + 3$
  4. $y = |x|$
  5. $x = 3$
✅ เฉลย
  1. ✅ เป็น — ใส่ x ค่าเดียว คำนวณได้ y ค่าเดียวเสมอ (กราฟพาราโบลาคว่ำ)
  2. ❌ ไม่เป็น — เช่น x = 2 จะได้ $|y| = 2$ คือ y = 2 หรือ y = −2 (สองค่า)
  3. ✅ เป็น — เส้นตรงที่ไม่ใช่เส้นตั้ง ผ่าน Vertical Line Test เสมอ
  4. ✅ เป็น — ระวังสลับกับข้อ 2! ใส่ x ได้ y ค่าเดียว เช่น x = −2 → y = 2 (หลาย x ไปที่ y เดียวกันได้)
  5. ❌ ไม่เป็น — เป็นเส้นตั้ง x = 3 จุด (3, 0), (3, 1), (3, 2), … มี x เดียวกันแต่ y หลายค่า

1.2 โดเมนและเรนจ์

📥 โดเมน (Domain)

เซตของ x ทั้งหมดที่ใส่เข้าไปได้ (ค่า input ที่ทำให้ฟังก์ชันหาค่าได้)

📤 เรนจ์ (Range)

เซตของ y ทั้งหมดที่ออกมาได้ (ค่า output ที่เป็นไปได้)

เช่น $R=\{(1,2),(2,2),(3,3),(4,3)\}$ มีโดเมน $=\{1,2,3,4\}$ และเรนจ์ $=\{2,3\}$

⚠️ สองกับดักที่ทำให้ x ใส่ไม่ได้ (สำหรับจำนวนจริง)
  1. ตัวส่วนเป็น 0 ไม่ได้ — เช่น $f(x)=\dfrac{1}{x-3}$ ใส่ x = 3 ไม่ได้
  2. ในรูทต้องไม่ติดลบ — เช่น $f(x)=\sqrt{x-2}$ ต้องมี $x-2 \ge 0$ คือ $x \ge 2$
ถ้าไม่เจอสองอย่างนี้ (เช่น พหุนาม) โดเมนคือ จำนวนจริงทั้งหมด $\mathbb{R}$ หรือ $(-\infty,\infty)$
ตัวอย่าง 1.2หาโดเมนและเรนจ์⭐⭐ ปานกลาง
  1. $f(x) = 3x - 7$
  2. $f(x) = x^2 + 1$
  3. $f(x) = \dfrac{5}{x+4}$
  4. $f(x) = \sqrt{6 - 2x}$
  5. $f(x) = \dfrac{x}{x^2 - 9}$ (หาเฉพาะโดเมน)
✅ เฉลย
  1. พหุนาม → โดเมน $\mathbb{R}$, เส้นตรงที่ไม่ขนานแกน x → เรนจ์ $\mathbb{R}$
  2. โดเมน $\mathbb{R}$; เนื่องจาก $x^2 \ge 0$ จึงได้ $x^2+1 \ge 1$ → เรนจ์ $[1,\infty)$
  3. ตัวส่วน $x+4 \ne 0$ → โดเมน $\mathbb{R}-\{-4\}$; เศษเป็น 5 เสมอ ผลหารจึงไม่มีทางเป็น 0 → เรนจ์ $\mathbb{R}-\{0\}$
  4. $6-2x \ge 0 \Rightarrow x \le 3$ → โดเมน $(-\infty,3]$; รูทให้ค่าไม่ติดลบ → เรนจ์ $[0,\infty)$
  5. $x^2-9 = (x-3)(x+3) \ne 0$ → โดเมน $\mathbb{R}-\{-3,\,3\}$

1.3 การหาค่าฟังก์ชันและฟังก์ชันประกอบ

หาค่าฟังก์ชัน = เอาค่าที่กำหนด “ไปแทน x ทุกตัว” เช่น $f(x)=2x-5$ จะได้ $f(4)=2(4)-5=3$ และ $f(a+1) = 2(a+1)-5 = 2a-3$

ฟังก์ชันประกอบ (Composite function) $(f\circ g)(x) = f(g(x))$ คือการส่ง output ของ $g$ เข้าเครื่อง $f$ ต่อ — ทำตัวขวาก่อน

x
➜
gทำก่อน
➜
g(x)
➜
fทำทีหลัง
➜
f(g(x))
ตัวอย่าง 1.3หาค่าฟังก์ชัน⭐ ง่าย

กำหนดให้ $f(x) = 2x - 5$ และ $g(x) = x + 10$ จงหาค่าต่อไปนี้

  1. $f(2) + g(2)$
  2. $f(5) - g(-3)$
  3. $(f\circ g)(3)$
  4. $(g\circ f)(-5)$
  5. ถ้า $f(x) = -21$ จงหา $x$
  6. ถ้า $f(x) = -1$ จงหา $g(x)$
✅ เฉลย
  1. $f(2) = -1,\ g(2) = 12$ → $-1 + 12 = $ 11
  2. $f(5) = 5,\ g(-3) = 7$ → $5 - 7 = $ −2
  3. $g(3) = 13$ ก่อน แล้ว $f(13) = 2(13)-5 = $ 21
  4. $f(-5) = -15$ ก่อน แล้ว $g(-15) = -15+10 = $ −5
  5. $2x - 5 = -21 \Rightarrow 2x = -16 \Rightarrow$ x = −8
  6. $2x - 5 = -1 \Rightarrow x = 2$ แล้ว $g(2) = 12$ → g(x) = 12
ตัวอย่าง 1.4หาสูตรของฟังก์ชันประกอบ⭐⭐ ปานกลาง

กำหนด $f(x) = x^2 - 3$ และ $g(x) = 2x + 1$ จงหา $(f\circ g)(x)$ และ $(g\circ f)(x)$ แล้วตรวจว่าเท่ากันหรือไม่

✅ เฉลย
$$\begin{aligned}(f\circ g)(x) &= f(2x+1) = (2x+1)^2 - 3 = 4x^2 + 4x - 2\\ (g\circ f)(x) &= g(x^2-3) = 2(x^2-3) + 1 = 2x^2 - 5\end{aligned}$$

สองอันนี้ ไม่เท่ากัน → โดยทั่วไป $f\circ g \ne g\circ f$ ลำดับสำคัญมาก!

1.4 ความชันและสมการเส้นตรง

ความชัน (slope) ใช้ตัวอักษร $m$ บอกว่า ถ้า x ขยับไป 1 หน่วย y จะขยับไปเท่าไร

📐 สูตรความชันจากสองจุด $(x_1,y_1)$ และ $(x_2,y_2)$
$$m = \frac{y_2 - y_1}{x_2 - x_1} = \frac{\Delta y}{\Delta x} = \frac{\text{ระยะขึ้น–ลง}}{\text{ระยะเดินไปข้างหน้า}}$$

ความชันบอกอะไรเรา

m > 0 ↗

กราฟขึ้นจากซ้ายไปขวา (x เพิ่ม y เพิ่ม)

m < 0 ↘

กราฟลงจากซ้ายไปขวา (x เพิ่ม y ลด)

m = 0 →

เส้นนอน y ไม่เปลี่ยนเลย

|m| ยิ่งมาก

ยิ่งชัน เปลี่ยนแปลงเร็ว

📏 สมการเส้นตรง 2 แบบที่ใช้บ่อยที่สุด

แบบความชัน–จุดตัดแกน y: $y = mx + c$  (c คือค่า y ตอน x = 0)

แบบจุด–ความชัน: $y - y_1 = m(x - x_1)$  (รู้จุด 1 จุดกับความชันก็พอ — ใช้มากในบทที่ 5)

ตัวอย่าง 1.5อ่านความชันจากกราฟ⭐ ง่าย

(ก) หาความชันของเส้นตรงนี้  (ข) เขียนสมการเส้นตรง  (ค) ถ้าแกน x คือ “จำนวนชั่วโมงที่ใช้บริการ” และแกน y คือ “ค่าบริการ (บาท)” ความชันและจุดตัดแกน y หมายถึงอะไร

✅ เฉลย

(ก) $m = \dfrac{250-10}{6-0} = \dfrac{240}{6} = 40$  (ข) จุดตัดแกน y คือ 10 → y = 40x + 10

(ค) ความชัน 40 = ค่าบริการชั่วโมงละ 40 บาท ส่วน 10 = ค่าแรกเข้า 10 บาท (จ่ายแม้ยังไม่ได้ใช้)

ตัวอย่าง 1.6สมการเส้นตรงผ่านสองจุด⭐⭐ ปานกลาง

หาสมการเส้นตรงที่ผ่านจุด $(-2, 7)$ และ $(4, -5)$

✅ เฉลย
$$m = \frac{-5-7}{4-(-2)} = \frac{-12}{6} = -2$$

ใช้แบบจุด–ความชันกับจุด $(-2,7)$: $\;y - 7 = -2(x+2) \Rightarrow y = -2x - 4 + 7$ → y = −2x + 3

ตรวจ: แทน x = 4 ได้ y = −8 + 3 = −5 ✓

ตัวอย่าง 1.7จับคู่เรื่องราวกับกราฟ⭐⭐ ปานกลาง

ให้แกน x คือเวลาหรือปริมาณ และแกน y คือค่าที่เปลี่ยนไป จับคู่เรื่องราว 1–6 กับกราฟ A–F

  1. ส้ม กิโลละ 50 บาท (x = กิโล, y = ราคา)
  2. องุ่น กิโลละ 200 บาท
  3. เดือนนี้ราคาหุ้นธนาคารตกวูบอย่างน่าใจหาย
  4. ราคาน้ำมันเดือนนี้ค่อย ๆ ลดลงอย่างช้า ๆ
  5. ทำดีกับเขามาก ๆ เขาก็รักเพิ่มขึ้นนะ… แต่นิดเดียว T_T
  6. ต่อให้ทำดีแค่ไหน เธอก็ไม่แคร์ T_T
✅ เฉลย

1 → A (ชันบวกปานกลาง) · 2 → B (ชันบวกมาก แพงกว่า 4 เท่า) · 3 → D (ชันลบมาก) · 4 → E (ชันลบน้อย) · 5 → C (ชันบวกนิดเดียว) · 6 → F (ความชัน = 0 ไม่เปลี่ยนเลย)

สรุป: เครื่องหมายของความชันบอกทิศ (เพิ่ม/ลด) และขนาดบอกความเร็วของการเปลี่ยนแปลง — นี่คือหัวใจของ “อนุพันธ์” ในบทที่ 4

1.5 ฟังก์ชันพื้นฐานที่ต้องรู้จักหน้าตา

ในวิชานี้เราจะเจอฟังก์ชันพหุนามเป็นส่วนใหญ่ จำ “หน้าตา” ของกราฟไว้จะช่วยให้คิดเร็วขึ้นมาก

🧠 ทริคพาราโบลา $y = ax^2 + bx + c$

$a > 0$ หงาย (มีจุดต่ำสุด), $a \lt 0$ คว่ำ (มีจุดสูงสุด) และจุดยอดอยู่ที่ $x = -\dfrac{b}{2a}$ — ในบทที่ 5 เราจะได้สูตรนี้ “ฟรี ๆ” จากการดิฟ!

ลองให้ Python คำนวณฟังก์ชันประกอบ
from sympy import symbols, expand
x = symbols('x')
f = lambda t: t**2 - 3
g = lambda t: 2*t + 1
print("f(g(x)) =", expand(f(g(x))))
print("g(f(x)) =", expand(g(f(x))))
print("f(g(3)) =", f(g(3)))
▸ ผลลัพธ์เมื่อรัน
f(g(x)) = 4*x**2 + 4*x - 2
g(f(x)) = 2*x**2 - 5
f(g(3)) = 46

คำถามท้ายบท

ลองทำเองก่อนทุกข้อ แล้วค่อยกด 🔑 ดูเฉลย (ต้องใช้รหัสผ่านจากผู้สอน)

  1. ฟังก์ชัน โดเมน เรนจ์
  2. ความสัมพันธ์ใดต่อไปนี้เป็นฟังก์ชัน: (ก) $y = x^3 - 2x$ (ข) $x^2 + y^2 = 25$ (ค) $y = \sqrt{x}$ (ง) $x = y^2 + 1$ (Vertical Line Test)

    (ก) ✅ เป็น (ข) ❌ ไม่เป็น — วงกลม เช่น x = 0 ได้ y = ±5 (ค) ✅ เป็น — รูทให้ค่าบวกค่าเดียว (ง) ❌ ไม่เป็น — x = 2 ได้ $y^2 = 1$ คือ y = ±1

  3. ความสัมพันธ์ $\{(1,4),(2,5),(3,4),(1,6)\}$ เป็นฟังก์ชันหรือไม่ จงบอกโดเมนและเรนจ์

    ไม่เป็นฟังก์ชัน เพราะ input 1 จับคู่กับทั้ง 4 และ 6 · โดเมน = {1, 2, 3} · เรนจ์ = {4, 5, 6}

  4. จงหาโดเมนของ (ก) $f(x) = \dfrac{2x}{x-7}$ (ข) $f(x) = \sqrt{x+5}$ (ค) $f(x) = \dfrac{1}{x^2 - 4x}$ (ตัวส่วน ≠ 0, ในรูท ≥ 0)

    (ก) $\mathbb{R} - \{7\}$ (ข) $x + 5 \ge 0$ → $[-5, \infty)$ (ค) $x(x-4) \ne 0$ → $\mathbb{R} - \{0, 4\}$

  5. จงหาเรนจ์ของ $f(x) = 5 - x^2$

    $x^2 \ge 0$ ดังนั้น $-x^2 \le 0$ และ $5 - x^2 \le 5$ → เรนจ์ $(-\infty, 5]$ (พาราโบลาคว่ำ จุดสูงสุด (0, 5))

  6. การหาค่าฟังก์ชันและฟังก์ชันประกอบ
  7. กำหนด $f(x) = 3x + 2$ และ $g(x) = x^2 - 1$ จงหา (ก) $f(-2) + g(3)$ (ข) $(f\circ g)(2)$ (ค) $(g\circ f)(2)$ (ง) $(f\circ g)(x)$

    (ก) $-4 + 8 = 4$ (ข) $g(2)=3,\ f(3)=11$ (ค) $f(2)=8,\ g(8)=63$ (ง) $3(x^2-1)+2 = 3x^2 - 1$

  8. กำหนด $f(x) = 4x - 9$ ถ้า $f(a) = 15$ จงหา $a$ และ $f(2a)$

    $4a - 9 = 15 \Rightarrow a = 6$ แล้ว $f(12) = 48 - 9 = 39$

  9. กำหนด $f(x) = x^2 + 2x$ จงหา $f(x+h)$ และ $f(x+h) - f(x)$ (เตรียมใช้ในบทที่ 4) (แทน x ด้วย x+h ทุกตัว)
    $$\begin{aligned}f(x+h) &= (x+h)^2 + 2(x+h) = x^2 + 2xh + h^2 + 2x + 2h\\ f(x+h)-f(x) &= 2xh + h^2 + 2h\end{aligned}$$
  10. ความชันและสมการเส้นตรง
  11. จงหาความชันของเส้นตรงที่ผ่านจุด $(3,-1)$ และ $(7, 11)$ แล้วเขียนสมการในรูป $y = mx + c$

    $m = \dfrac{11-(-1)}{7-3} = 3$ → $y + 1 = 3(x - 3)$ → $y = 3x - 10$

  12. เส้นตรงมีความชัน $-\tfrac{1}{2}$ และผ่านจุด $(4, 6)$ จงหาสมการและจุดตัดแกน x

    $y - 6 = -\tfrac12(x-4) \Rightarrow y = -\tfrac12 x + 8$ · ตัดแกน x เมื่อ y = 0: $\tfrac12 x = 8 \Rightarrow x = 16$ → จุด (16, 0)

  13. ร้านถ่ายเอกสารคิดค่าเข้าเล่ม 25 บาท บวกหน้าละ 0.5 บาท จงเขียนฟังก์ชันราคา $P(n)$ ของเอกสาร $n$ หน้า บอกความหมายของความชัน และหาราคาเมื่อพิมพ์ 120 หน้า (ความชัน = อัตราต่อหน่วย)

    $P(n) = 0.5n + 25$ · ความชัน 0.5 = ราคาเพิ่มขึ้นหน้าละ 0.5 บาท · $P(120) = 60 + 25 = 85$ บาท

  14. จงบอกว่าพาราโบลา $y = -2x^2 + 8x - 3$ หงายหรือคว่ำ และหาจุดยอด

    $a = -2 \lt 0$ → คว่ำ · $x = -\dfrac{b}{2a} = -\dfrac{8}{-4} = 2$ · $y = -8 + 16 - 3 = 5$ → จุดยอด (2, 5) เป็นจุดสูงสุด
