บทที่ 2 · ลิมิตของฟังก์ชัน

แนวคิดของลิมิต การแทนค่า ทฤษฎีบทลิมิต รูปแบบ 0/0 การแยกตัวประกอบ คอนจูเกต ลิมิตซ้าย–ขวา และลิมิตที่อนันต์

🎯 เมื่อเรียนจบบทนี้ นิสิตจะสามารถ
  1. อธิบายความหมายของ $\displaystyle\lim_{x\to a} f(x)$ ได้ทั้งจากตาราง กราฟ และสมการ
  2. หาลิมิตด้วยการแทนค่า และใช้ทฤษฎีบทของลิมิตได้
  3. จัดการรูปแบบ $\tfrac{0}{0}$ ด้วยการแยกตัวประกอบและการคูณคอนจูเกตได้
  4. หาลิมิตซ้าย ลิมิตขวา และตัดสินว่าลิมิตหาค่าได้หรือไม่
  5. หาลิมิตเมื่อ $x\to\infty$ ของฟังก์ชันตรรกยะได้ (เสริม)

2.1 ลิมิตคืออะไร — “เข้าใกล้” ไม่ใช่ “เท่ากับ”

สัญลักษณ์ $\displaystyle\lim_{x\to a} f(x) = L$ อ่านว่า “ลิมิตของ f(x) เมื่อ x เข้าใกล้ a เท่ากับ L” หมายความว่า เมื่อ x เข้าใกล้ a มาก ๆ ๆ ๆ (แต่ไม่ต้องเท่ากับ a) ค่าของ f(x) จะเข้าใกล้ L

🚶 เปรียบเทียบ: เดินเข้าหาประตู

ลองเดินเข้าหาประตูโดยแต่ละก้าวเดินแค่ครึ่งหนึ่งของระยะที่เหลือ — คุณจะเข้าใกล้ประตูขึ้นเรื่อย ๆ จนห่างแค่ 0.0001 เมตร ลิมิตถามว่า “กำลังมุ่งหน้าไปหาอะไร” ไม่ได้ถามว่า “ถึงหรือยัง” — ต่อให้ประตูถูกถอดออกไป (ฟังก์ชันไม่นิยามที่จุดนั้น) เราก็ยังบอกได้ว่ากำลังเดินไปที่ประตู

ทำไมต้องมีลิมิต? เพราะบางจุด “แทนค่าไม่ได้”

พิจารณา $f(x) = \dfrac{x^2-1}{x-1}$ — ถ้าแทน x = 1 จะได้ $\tfrac{0}{0}$ (หาค่าไม่ได้) แต่ถ้าดูกราฟ จะเห็นว่าเป็นเส้นตรงที่มี “รู” ที่ x = 1 และรอบ ๆ รูนั้นค่า y วิ่งเข้าหา 2

2.2 หาลิมิตโดยการแทนค่าโดยตรง

ถ้าฟังก์ชัน “เรียบร้อย” ที่จุดนั้น (เช่น พหุนาม หรือเศษส่วนที่ตัวส่วนไม่เป็น 0) แทน x = a ลงไปได้เลย ไม่ต้องสร้างตาราง

ตัวอย่าง 2.1แทนค่าได้เลย⭐ ง่าย
  1. $\displaystyle\lim_{x\to0}(x-2)$
  2. $\displaystyle\lim_{x\to5}(5x+3)$
  3. $\displaystyle\lim_{x\to-1}(x^2+2)$
  4. $\displaystyle\lim_{x\to0} 7$
  5. $\displaystyle\lim_{x\to7}\frac{x-7}{x}$
  6. $\displaystyle\lim_{x\to0}\frac{x^2-2x+1}{x-1}$
  7. $\displaystyle\lim_{x\to3}(2x^3 - x^2 + 4)$
✅ เฉลย
  1. $0-2 = -2$
  2. $25+3 = 28$
  3. $1+2 = 3$
  4. ลิมิตของค่าคงที่ = ค่าคงที่นั้น = 7
  5. $\tfrac{0}{7} = 0$
  6. $\tfrac{1}{-1} = -1$
  7. $54 - 9 + 4 = 49$

2.3 ทฤษฎีบทของลิมิต

กำหนด $\displaystyle\lim_{x\to a}f(x) = L$ และ $\displaystyle\lim_{x\to a}g(x) = M$ (มีค่าทั้งคู่) และ $k$ เป็นค่าคงที่

1. ค่าคงที่

$\displaystyle\lim_{x\to a} k = k$

2. ตัวแปรเอง

$\displaystyle\lim_{x\to a} x = a,\ \ \lim_{x\to a} x^n = a^n$

3. ดึงค่าคงที่ออก

$\displaystyle\lim_{x\to a} k f(x) = kL$

4. บวก / ลบ

$\displaystyle\lim_{x\to a}[f(x)\pm g(x)] = L \pm M$

5. คูณ

$\displaystyle\lim_{x\to a}[f(x)\,g(x)] = LM$

6. หาร

$\displaystyle\lim_{x\to a}\frac{f(x)}{g(x)} = \frac{L}{M},\ M\ne0$

7. ยกกำลัง

$\displaystyle\lim_{x\to a}[f(x)]^n = L^n$

8. ราก

$\displaystyle\lim_{x\to a}\sqrt[n]{f(x)} = \sqrt[n]{L}$

สรุปง่าย ๆ: ลิมิต “กระจาย” เข้าไปในการบวก ลบ คูณ หาร ยกกำลังได้ — นี่คือเหตุผลที่การแทนค่าตรง ๆ ใช้ได้กับพหุนาม

ตัวอย่าง 2.2ใช้ทฤษฎีบททีละขั้น⭐ ง่าย

ถ้า $\displaystyle\lim_{x\to 2}f(x) = 4$ และ $\displaystyle\lim_{x\to2}g(x) = -3$ จงหา

  1. $\displaystyle\lim_{x\to2}[3f(x) - 2g(x)]$
  2. $\displaystyle\lim_{x\to2}f(x)\,g(x)$
  3. $\displaystyle\lim_{x\to2}\frac{[f(x)]^2}{g(x)+1}$
  4. $\displaystyle\lim_{x\to2}\sqrt{f(x)} + x^2$
✅ เฉลย
  1. $3(4) - 2(-3) = 12 + 6 = 18$
  2. $4 \times (-3) = -12$
  3. $\dfrac{16}{-3+1} = -8$
  4. $\sqrt4 + 4 = 6$

2.5 เครื่องมือที่ 1: แยกตัวประกอบ

สูตรที่ต้องจำให้ขึ้นใจ

ชื่อสูตรสูตร
ผลต่างกำลังสอง$a^2 - b^2 = (a-b)(a+b)$  ← ใช้ทำคอนจูเกตด้วย
กำลังสองสมบูรณ์$(a\pm b)^2 = a^2 \pm 2ab + b^2$
ผลต่างกำลังสาม$a^3 - b^3 = (a-b)(a^2+ab+b^2)$
ผลบวกกำลังสาม$a^3 + b^3 = (a+b)(a^2-ab+b^2)$

แยกตัวประกอบ $x^2 + bx + c$: “คูณได้ค่าหลัง บวกได้ค่ากลาง”

หาเลขสองตัว $p, q$ ที่ คูณกันได้ c และ บวกกันได้ b แล้วเขียน $(x+p)(x+q)$

$x^2 + 7x + 6$

คู่ที่คูณได้ 6: (1,6) (2,3) (−1,−6) (−2,−3) → คู่ที่บวกได้ 7 คือ 1 กับ 6

→ $(x+1)(x+6)$

$x^2 - x - 20$

คูณได้ −20 → เครื่องหมายต้องต่างกัน: (4,−5) (−4,5) (2,−10) … → บวกได้ −1 คือ 4 กับ −5

→ $(x+4)(x-5)$

ตัวอย่าง 2.3ฝึกแยกตัวประกอบ (อุ่นเครื่อง)⭐ ง่าย
  1. $x^2 - 7x + 10$
  2. $x^2 + 15x - 100$
  3. $x^2 - 15x - 100$
  4. $x^2 + 20x + 100$
  5. $x^2 + 3x - 18$
  6. $x^2 - 14x + 40$
  7. $x^3 - 8$
✅ เฉลย
  1. $(x-2)(x-5)$
  2. $(x+20)(x-5)$
  3. $(x-20)(x+5)$
  4. $(x+10)^2$
  5. $(x+6)(x-3)$
  6. $(x-4)(x-10)$
  7. $(x-2)(x^2+2x+4)$
ตัวอย่าง 2.4ลิมิตที่ต้องแยกตัวประกอบ⭐⭐ ปานกลาง
  1. $\displaystyle\lim_{x\to-1}\frac{x^2+7x+6}{x+1}$
  2. $\displaystyle\lim_{x\to-4}\frac{x^2+x-12}{x+4}$
  3. $\displaystyle\lim_{x\to1}\frac{x^2-8x+7}{x^2+4x-5}$
  4. $\displaystyle\lim_{x\to1}\frac{x^3-1}{x-1}$
  5. $\displaystyle\lim_{x\to3}\frac{x^3-27}{x-3}$
  6. $\displaystyle\lim_{x\to3}\frac{x^4-3x^3}{x-3}$
✅ เฉลย
  1. $\dfrac{(x+1)(x+6)}{x+1} = x + 6 \to -1+6 = $ 5
  2. $\dfrac{(x-3)(x+4)}{x+4} = x - 3 \to $ −7
  3. $\dfrac{(x-7)(x-1)}{(x-1)(x+5)} = \dfrac{x-7}{x+5} \to \dfrac{-6}{6} = $ −1
  4. $\dfrac{(x-1)(x^2+x+1)}{x-1} = x^2+x+1 \to $ 3
  5. $\dfrac{(x-3)(x^2+3x+9)}{x-3} = x^2+3x+9 \to 9+9+9 = $ 27
  6. ดึง $x^3$ ร่วม: $\dfrac{x^3(x-3)}{x-3} = x^3 \to $ 27
ตัวอย่าง 2.5ลิมิตแบบหลายชั้น⭐⭐⭐ ท้าทาย
  1. $\displaystyle\lim_{x\to2}\frac{x^4-16}{x-2}$
  2. $\displaystyle\lim_{x\to3}\frac{x^2-9}{6x-18}$
  3. $\displaystyle\lim_{x\to-2}\frac{x^3+8}{x^2-4}$
✅ เฉลย
  1. $x^4 - 16 = (x^2-4)(x^2+4) = (x-2)(x+2)(x^2+4)$ → เหลือ $(x+2)(x^2+4) \to 4 \times 8 = $ 32
  2. $\dfrac{(x-3)(x+3)}{6(x-3)} = \dfrac{x+3}{6} \to $ 1
  3. $\dfrac{(x+2)(x^2-2x+4)}{(x+2)(x-2)} = \dfrac{x^2-2x+4}{x-2} \to \dfrac{4+4+4}{-4} = $ −3

2.6 เครื่องมือที่ 2: คูณด้วยคอนจูเกต (เมื่อเจอรากที่สอง)

คอนจูเกต ของ $\sqrt{A} - B$ คือ $\sqrt{A} + B$ (สลับเครื่องหมายตรงกลาง) เมื่อคูณกันจะได้ผลต่างกำลังสอง ทำให้ รากหายไป: $$(\sqrt{A} - B)(\sqrt{A} + B) = A - B^2$$

  1. หา $\displaystyle\lim_{x\to1}\frac{\sqrt x - 1}{x-1}$ — แทนค่าได้ $\tfrac00$ จึงคูณทั้งเศษและส่วนด้วย $\sqrt x + 1$
  2. $\displaystyle\frac{\sqrt x - 1}{x-1}\cdot\frac{\sqrt x + 1}{\sqrt x + 1} = \frac{x - 1}{(x-1)(\sqrt x + 1)}$  (เศษใช้ผลต่างกำลังสอง)
  3. ตัด $(x-1)$ ได้ $\dfrac{1}{\sqrt x + 1}$
  4. ตอนนี้แทนค่าได้แล้ว (ส่วนไม่เป็น 0): $\dfrac{1}{1+1} = \dfrac12$
ตัวอย่าง 2.6คอนจูเกต⭐⭐ ปานกลาง
  1. $\displaystyle\lim_{x\to4}\frac{\sqrt x - 2}{x-4}$
  2. $\displaystyle\lim_{x\to0}\frac{\sqrt{4+x} - 2}{x}$
  3. $\displaystyle\lim_{x\to4}\frac{\sqrt{x+5} - 3}{x-4}$
  4. $\displaystyle\lim_{x\to9}\frac{x-9}{\sqrt x - 3}$
✅ เฉลย
  1. $\dfrac{(\sqrt x-2)(\sqrt x+2)}{(x-4)(\sqrt x+2)} = \dfrac{x-4}{(x-4)(\sqrt x+2)} = \dfrac{1}{\sqrt x + 2} \to $ 1/4
  2. $\dfrac{(4+x) - 4}{x(\sqrt{4+x}+2)} = \dfrac{1}{\sqrt{4+x}+2} \to \dfrac{1}{2+2} = $ 1/4
  3. $\dfrac{(x+5) - 9}{(x-4)(\sqrt{x+5}+3)} = \dfrac{1}{\sqrt{x+5}+3} \to $ 1/6
  4. รากอยู่ที่ตัวส่วน คูณ $\sqrt x + 3$: $\dfrac{(x-9)(\sqrt x+3)}{x - 9} = \sqrt x + 3 \to $ 6
    (หรือมอง $x - 9 = (\sqrt x-3)(\sqrt x+3)$ ก็ได้)
⚠️ อย่าคูณคอนจูเกตโดยไม่ดู

เช่น $\displaystyle\lim_{x\to3}\frac{\sqrt x - 9}{x-3}$ แทนค่าได้ $\dfrac{\sqrt3 - 9}{0}$ — เศษ ไม่ใช่ 0 จึงไม่ใช่รูป $\tfrac00$ ลิมิตนี้ หาค่าไม่ได้ ทันที ไม่ต้องจัดรูปอะไรเลย

2.7 ลิมิตซ้าย ลิมิตขวา

ลิมิตซ้าย $\displaystyle\lim_{x\to a^-}f(x)$

x เข้าใกล้ a จาก ค่าที่น้อยกว่า a (เช่น 1.9, 1.99, 1.999 → 2)

ลิมิตขวา $\displaystyle\lim_{x\to a^+}f(x)$

x เข้าใกล้ a จาก ค่าที่มากกว่า a (เช่น 2.1, 2.01, 2.001 → 2)

🔑 กฎสำคัญที่สุดของหัวข้อนี้
$$\lim_{x\to a}f(x) \text{ หาค่าได้} \iff \lim_{x\to a^-}f(x) = \lim_{x\to a^+}f(x)$$

ถ้าซ้ายกับขวาไม่เท่ากัน → ลิมิตหาค่าไม่ได้ (ค่าของ f(a) เองไม่เกี่ยว!)

ตัวอย่าง 2.7อ่านลิมิตจากกราฟ⭐ ง่าย

จากกราฟ จงหา $f(2)$, $\displaystyle\lim_{x\to2^-}f(x)$, $\displaystyle\lim_{x\to2^+}f(x)$ และ $\displaystyle\lim_{x\to2}f(x)$

✅ เฉลย

จุดทึบที่ x = 2 อยู่ที่ y = 0 → $f(2) = 0$ · เดินจากซ้ายเข้าหารู → $\displaystyle\lim_{x\to2^-}f(x) = 2$ · เดินจากขวา → $\displaystyle\lim_{x\to2^+}f(x) = 3$

ซ้าย (2) ≠ ขวา (3) → $\lim_{x\to2}f(x)$ หาค่าไม่ได้ ทั้งที่ $f(2) = 0$ หาค่าได้

ตัวอย่าง 2.8ฟังก์ชันหลายช่วง (piecewise)⭐⭐ ปานกลาง

$$f(x) = \begin{cases} x - 1 & ;\ x \lt 0\\ 0 & ;\ x = 0\\ x + 2 & ;\ x \gt 0\end{cases}$$ จงหา $\displaystyle\lim_{x\to0^-}f(x)$, $\displaystyle\lim_{x\to0^+}f(x)$ และ $\displaystyle\lim_{x\to0}f(x)$

✅ เฉลย

ฝั่งซ้าย (x < 0) ใช้สูตร $x - 1$ → $0 - 1 = -1$ · ฝั่งขวา (x > 0) ใช้ $x+2$ → $2$

$-1 \ne 2$ → ลิมิตหาค่าไม่ได้

ตัวอย่าง 2.9ค่าสัมบูรณ์⭐⭐⭐ ท้าทาย

จงหา $\displaystyle\lim_{x\to0}\frac{|x|}{x}$

✅ เฉลย

เมื่อ $x > 0$: $|x| = x$ จึงได้ $\frac{x}{x} = 1$ · เมื่อ $x \lt 0$: $|x| = -x$ จึงได้ $\frac{-x}{x} = -1$

ลิมิตขวา = 1, ลิมิตซ้าย = −1 → หาค่าไม่ได้ (กราฟเป็นขั้นบันไดกระโดดที่ x = 0)

2.8 ลิมิตที่อนันต์และลิมิตอนันต์ เสริม

บางครั้งเราสนใจว่า เมื่อ x ใหญ่ขึ้นไม่สิ้นสุด ฟังก์ชันจะวิ่งไปหาค่าอะไร เช่น ค่าเฉลี่ยต้นทุนเมื่อผลิตเยอะ ๆ หรือความเร็วของอัลกอริทึมเมื่อข้อมูลใหญ่มาก

หลักสำคัญ: $\displaystyle\lim_{x\to\infty}\frac{1}{x} = 0$ (หาร 1 ด้วยเลขมหาศาล ได้เกือบ 0) และ $\displaystyle\lim_{x\to\infty}\frac{k}{x^n} = 0$ สำหรับ $n > 0$

⚡ ทางลัดฟังก์ชันตรรกยะ $\dfrac{P(x)}{Q(x)}$ เมื่อ $x\to\infty$ — เทียบกำลังสูงสุด
  • กำลังเศษ น้อยกว่า ส่วน → ลิมิต = 0
  • กำลัง เท่ากัน → ลิมิต = อัตราส่วนสัมประสิทธิ์ตัวหน้า
  • กำลังเศษ มากกว่า ส่วน → ±∞ (หาค่าไม่ได้)
ตัวอย่าง 2.10ลิมิตเมื่อ x → ∞⭐⭐ ปานกลาง
  1. $\displaystyle\lim_{x\to\infty}\frac{3x^2+1}{x^2-5}$
  2. $\displaystyle\lim_{x\to\infty}\frac{5x+2}{x^3+1}$
  3. $\displaystyle\lim_{x\to\infty}\frac{2x^3}{x^2+4}$
  4. $\displaystyle\lim_{x\to0}\frac{1}{x^2}$
✅ เฉลย
  1. หารทุกพจน์ด้วย $x^2$: $\dfrac{3 + 1/x^2}{1 - 5/x^2} \to \dfrac{3+0}{1-0} = $ 3
  2. กำลังเศษ (1) < ส่วน (3) → 0
  3. กำลังเศษ (3) > ส่วน (2) → โตไม่หยุด ∞ (หาค่าไม่ได้)
  4. ทั้งซ้ายและขวา $x^2$ เป็นบวกเล็กมาก → $\frac1{x^2}\to+\infty$ ∞ (หาค่าไม่ได้ แต่บอกได้ว่าพุ่งขึ้น)
ตรวจคำตอบด้วย Python (SymPy)
from sympy import symbols, limit, sqrt, oo
x = symbols('x')
print(limit((x**3 - 27)/(x - 3), x, 3))
print(limit((sqrt(4 + x) - 2)/x, x, 0))
print(limit(abs(x)/x, x, 0, '+'), limit(abs(x)/x, x, 0, '-'))
print(limit((3*x**2 + 1)/(x**2 - 5), x, oo))

  2. จงหา (ก) $\displaystyle\lim_{x\to2}(x^3 - 4x + 1)$ (ข) $\displaystyle\lim_{x\to-3}\frac{x+5}{x^2-1}$ (ค) $\displaystyle\lim_{x\to4}\sqrt{2x+1}$

  3. ถ้า $\displaystyle\lim_{x\to1}f(x) = 5$ และ $\displaystyle\lim_{x\to1}g(x) = 2$ จงหา $\displaystyle\lim_{x\to1}\frac{f(x) - 3g(x)}{[g(x)]^3}$

    $\dfrac{5 - 6}{8} = -\dfrac18$

  4. รูปแบบ 0/0
  5. จงหา $\displaystyle\lim_{x\to5}\frac{x^2-25}{x-5}$ (แยกตัวประกอบ)

    $\dfrac{(x-5)(x+5)}{x-5} = x + 5 \to 10$

  6. จงหา $\displaystyle\lim_{x\to2}\frac{x^2-5x+6}{x^2-4}$ (แยกตัวประกอบทั้งเศษและส่วน)

    $\dfrac{(x-2)(x-3)}{(x-2)(x+2)} = \dfrac{x-3}{x+2} \to -\dfrac14$

  7. จงหา $\displaystyle\lim_{x\to2}\frac{x^3-8}{x-2}$ (ผลต่างกำลังสาม)

    $\dfrac{(x-2)(x^2+2x+4)}{x-2} = x^2+2x+4 \to 12$

  8. จงหา $\displaystyle\lim_{x\to0}\frac{x^3 + 5x^2 - 2x}{x}$ (ดึงตัวร่วม)

    $\dfrac{x(x^2+5x-2)}{x} = x^2 + 5x - 2 \to -2$

  9. จงหา $\displaystyle\lim_{x\to9}\frac{\sqrt x - 3}{x - 9}$ (คอนจูเกต)

    $\dfrac{x - 9}{(x-9)(\sqrt x + 3)} = \dfrac{1}{\sqrt x+3} \to \dfrac16$

  10. จงหา $\displaystyle\lim_{x\to0}\frac{\sqrt{x+1} - 1}{x}$ (คอนจูเกต)

    $\dfrac{(x+1)-1}{x(\sqrt{x+1}+1)} = \dfrac{1}{\sqrt{x+1}+1} \to \dfrac12$

  11. นิสิตคนหนึ่งตอบว่า $\displaystyle\lim_{x\to2}\frac{x+3}{x-2}$ “ต้องแยกตัวประกอบก่อน” ถูกหรือไม่ อธิบาย

    ไม่ถูก แทนค่าได้ $\dfrac{5}{0}$ ซึ่ง ไม่ใช่ รูป $\tfrac00$ จึงสรุปได้ทันทีว่าลิมิต หาค่าไม่ได้ (ลิมิตซ้ายพุ่ง −∞ ลิมิตขวาพุ่ง +∞)

  12. ลิมิตซ้าย–ขวา
  13. กำหนด $f(x) = \begin{cases} 2x+1 &;\ x \lt 1\\ x^2 + 2 &;\ x \ge 1\end{cases}$ จงหา $\displaystyle\lim_{x\to1}f(x)$

    ซ้าย: $2(1)+1 = 3$ · ขวา: $1 + 2 = 3$ · เท่ากัน → $\displaystyle\lim_{x\to1}f(x) = 3$

  14. กำหนด $f(x) = \begin{cases} x^2 &;\ x \lt 2\\ 7 &;\ x = 2 \\ 10 - 3x &;\ x \gt 2\end{cases}$ จงหา $f(2)$ และ $\displaystyle\lim_{x\to2}f(x)$

    $f(2) = 7$ · ซ้าย: 4 · ขวา: $10 - 6 = 4$ → $\displaystyle\lim_{x\to2}f(x) = 4$ (ลิมิตมีค่า แม้ไม่เท่ากับ f(2) — เรื่องนี้สำคัญมากในบทที่ 3)

  15. จงหา $\displaystyle\lim_{x\to3}\frac{|x-3|}{x-3}$

    ขวา: $\frac{x-3}{x-3} = 1$ · ซ้าย: $\frac{-(x-3)}{x-3} = -1$ → ไม่เท่ากัน หาค่าไม่ได้

  16. ลิมิตที่อนันต์ (เสริม)
  17. จงหา $\displaystyle\lim_{x\to\infty}\frac{4x^3 - x}{2x^3 + 7x^2}$ และ $\displaystyle\lim_{x\to\infty}\frac{100x}{x^2+1}$

    กำลังเท่ากัน → $\dfrac42 = 2$ · กำลังเศษน้อยกว่า → 0
