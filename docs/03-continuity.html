บทที่ 3 · ความต่อเนื่องของฟังก์ชัน

เงื่อนไข 3 ข้อของความต่อเนื่อง ชนิดของจุดไม่ต่อเนื่อง ฟังก์ชันหลายช่วง และการหาค่า k ให้ฟังก์ชันต่อเนื่อง

🎯 เมื่อเรียนจบบทนี้ นิสิตจะสามารถ
  1. บอกเงื่อนไข 3 ข้อของความต่อเนื่องที่จุด $x = a$ ได้
  2. จำแนกจุดไม่ต่อเนื่องแบบ “รู” “กระโดด” และ “พุ่งไปอนันต์” จากกราฟได้
  3. ตรวจสอบความต่อเนื่องของฟังก์ชันหลายช่วง (piecewise) ได้
  4. หาค่าคงที่ $k$ ที่ทำให้ฟังก์ชันต่อเนื่องได้

3.1 ความต่อเนื่องคืออะไร

พูดแบบภาษาคน: ฟังก์ชันต่อเนื่องที่จุดหนึ่ง ถ้า เราวาดกราฟผ่านจุดนั้นได้โดยไม่ต้องยกปากกา ✏️ — ไม่มีรู ไม่มีรอยขาด ไม่มีการกระโดด

✅ นิยาม: $f$ ต่อเนื่องที่ $x = a$ ก็ต่อเมื่อครบทั้ง 3 ข้อ
  1. $f(a)$ หาค่าได้  (มีจุดอยู่จริง)
  2. $\displaystyle\lim_{x\to a}f(x)$ หาค่าได้  (ลิมิตซ้าย = ลิมิตขวา)
  3. $\displaystyle\lim_{x\to a}f(x) = f(a)$  (ค่าที่ “กำลังมุ่งไป” ตรงกับ “ค่าจริง”)

ข้อใดข้อหนึ่งไม่ผ่าน → ไม่ต่อเนื่อง ที่ $x = a$

3.2 หน้าตาของจุดไม่ต่อเนื่อง

💡 ทำไมต้องสนใจ?

ทฤษฎีหลายอย่างในบทต่อ ๆ ไป (เช่น หาค่าสูงสุด–ต่ำสุดบนช่วงปิด, หาพื้นที่ด้วยอินทิกรัล) ใช้ได้ เฉพาะกับฟังก์ชันที่ต่อเนื่อง และในโลกจริง ความต่อเนื่องหมายถึง “ไม่มีการกระตุก” เช่น ความเร็วรถไม่กระโดดจาก 40 เป็น 90 กม./ชม. ในพริบตา

3.3 ตรวจความต่อเนื่องทีละข้อ

ตัวอย่าง 3.1พหุนาม⭐ ง่าย

กำหนด $f(x) = x^2$ จงตรวจว่า $f$ ต่อเนื่องที่ $x = -1$ หรือไม่

✅ เฉลย
  1. $f(-1) = (-1)^2 = 1$ ✓
  2. $\displaystyle\lim_{x\to-1}x^2 = 1$ ✓
  3. $\displaystyle\lim_{x\to-1}x^2 = f(-1) = 1$ ✓

ครบ 3 ข้อ → ต่อเนื่องที่ x = −1 (อันที่จริง พหุนามต่อเนื่องทุกจุดเสมอ)

ตัวอย่าง 3.2ตัวส่วนเป็นศูนย์⭐ ง่าย

กำหนด $f(x) = \dfrac{x}{x-7}$ จงตรวจว่า $f$ ต่อเนื่องที่ $x = 7$ หรือไม่

✅ เฉลย

ข้อ 1: $f(7) = \dfrac{7}{0}$ หาค่าไม่ได้ ✗ → ไม่ต้องตรวจข้ออื่นต่อ ไม่ต่อเนื่องที่ x = 7

ตัวอย่าง 3.3ฟังก์ชันสองช่วง⭐⭐ ปานกลาง

$$f(x) = \begin{cases} 3x - 2 &;\ x \le 2\\ x^2 &;\ x \gt 2\end{cases}$$ ต่อเนื่องที่ $x = 2$ หรือไม่

✅ เฉลย
  1. $x = 2$ อยู่ในช่วง $x \le 2$ → $f(2) = 3(2) - 2 = 4$
  2. ลิมิตซ้าย $\displaystyle\lim_{x\to2^-}(3x-2) = 4$ · ลิมิตขวา $\displaystyle\lim_{x\to2^+}x^2 = 4$ → $\displaystyle\lim_{x\to2}f(x) = 4$
  3. $\displaystyle\lim_{x\to2}f(x) = 4 = f(2)$ ✓

ต่อเนื่องที่ x = 2 — สองท่อนกราฟมาบรรจบกันพอดีที่ (2, 4)

ตัวอย่าง 3.4ต้องแยกตัวประกอบก่อนหาลิมิต⭐⭐ ปานกลาง

$$f(x) = \begin{cases} x - 2 &;\ x \le 1\\[4pt] \dfrac{x^2 - 3x + 2}{x-1} &;\ x \gt 1\end{cases}$$ ต่อเนื่องที่ $x = 1$ หรือไม่

✅ เฉลย
  1. $f(1) = 1 - 2 = -1$
  2. ซ้าย: $\displaystyle\lim_{x\to1^-}(x-2) = -1$ · ขวา: $\dfrac{(x-1)(x-2)}{x-1} = x - 2 \to -1$ → ลิมิต $= -1$
  3. $-1 = f(1)$ ✓

ต่อเนื่องที่ x = 1

ตัวอย่าง 3.5สูตรเดิมแต่ตรวจที่จุดอื่น⭐⭐ ปานกลาง

$$f(x) = \begin{cases} x - 2 &;\ x \lt 0\\[4pt] \dfrac{x^2 - 3x + 2}{x-1} &;\ x \ge 0\end{cases}$$ ต่อเนื่องที่ $x = 0$ หรือไม่

✅ เฉลย

$f(0) = \dfrac{0 - 0 + 2}{0 - 1} = -2$ · ซ้าย: $0 - 2 = -2$ · ขวา: $\dfrac{2}{-1} = -2$ (แทนค่าได้เลย ตัวส่วนไม่เป็น 0)

ทุกค่าเท่ากับ −2 → ต่อเนื่องที่ x = 0 (แต่ระวัง! ฟังก์ชันนี้ไม่นิยามที่ x = 1 เพราะช่วง x ≥ 0 ครอบคลุม x = 1 ซึ่งทำให้ตัวส่วนเป็น 0)

ตัวอย่าง 3.6สามช่วง⭐⭐⭐ ท้าทาย

$$f(x) = \begin{cases} \dfrac{x^2+4x-12}{x^2+8x-20} &;\ x \lt 2\\[6pt] \dfrac{x}{3} &;\ x = 2 \\[6pt] \dfrac{x^2-4}{x^2+2x-8} &;\ x \gt 2\end{cases}$$ ต่อเนื่องที่ $x = 2$ หรือไม่

✅ เฉลย
  1. $f(2) = \dfrac{2}{3}$
  2. ซ้าย: $\dfrac{(x+6)(x-2)}{(x+10)(x-2)} = \dfrac{x+6}{x+10} \to \dfrac{8}{12} = \dfrac23$ · ขวา: $\dfrac{(x-2)(x+2)}{(x-2)(x+4)} = \dfrac{x+2}{x+4} \to \dfrac46 = \dfrac23$
  3. ทั้งสามค่าเท่ากับ $\tfrac23$ ✓

ต่อเนื่องที่ x = 2

3.4 หาค่า k ที่ทำให้ฟังก์ชันต่อเนื่อง

โจทย์แนวนี้ออกสอบบ่อยมาก! หลักคิด: บังคับให้ ลิมิตซ้าย = ลิมิตขวา = f(a) แล้วแก้สมการหา k

  1. หาลิมิตซ้ายและลิมิตขวา (ถ้ามี k อยู่ในสูตรก็ปล่อยไว้เป็นตัวแปร)
  2. ตั้งสมการให้ทุกค่าเท่ากัน
  3. แก้สมการหา k แล้วตรวจคำตอบ — ถ้าตั้งสมการแล้วขัดแย้งกัน แปลว่า ไม่มี k ที่เป็นไปได้
ตัวอย่าง 3.7k คือค่าของจุด⭐ ง่าย

$$f(x) = \begin{cases} \dfrac{x^2-9}{x-3} &;\ x \lt 3\\[4pt] k &;\ x = 3\\ x + 3 &;\ x \gt 3\end{cases}$$ หาค่า $k$ ที่ทำให้ $f$ ต่อเนื่องที่ $x = 3$

✅ เฉลย

ซ้าย: $\dfrac{(x-3)(x+3)}{x-3} = x + 3 \to 6$ · ขวา: $3 + 3 = 6$ → ลิมิต = 6

ต้องการ $f(3) = k = 6$ → k = 6 (เป็นการ “อุดรู” ที่จุด (3, 6) พอดี)

ตัวอย่าง 3.8ไม่มีคำตอบก็ได้⭐⭐ ปานกลาง

$$f(x) = \begin{cases} \dfrac{x^2-4}{x-2} &;\ x \lt 2\\[4pt] k &;\ x = 2\\ x + 1 &;\ x \gt 2\end{cases}$$ หาค่า $k$ ที่ทำให้ $f$ ต่อเนื่องที่ $x = 2$

✅ เฉลย

ซ้าย: $x + 2 \to 4$ · ขวา: $2 + 1 = 3$

ลิมิตซ้าย ≠ ลิมิตขวา → ลิมิตหาค่าไม่ได้ ไม่ว่า k จะเป็นอะไร เงื่อนไขข้อ 2 ก็ไม่ผ่าน → ไม่มีค่า k ที่ทำให้ต่อเนื่อง

ตัวอย่าง 3.9k อยู่ในสูตร⭐⭐ ปานกลาง

$$f(x) = \begin{cases} kx + 1 &;\ x \lt 2\\ x^2 - 1 &;\ x \ge 2\end{cases}$$ หาค่า $k$ ที่ทำให้ $f$ ต่อเนื่องทุกจุด

✅ เฉลย

แต่ละท่อนเป็นพหุนาม จึงต่อเนื่องอยู่แล้ว ต้องตรวจแค่ที่รอยต่อ x = 2

ซ้าย: $2k + 1$ · ขวา (และ $f(2)$): $4 - 1 = 3$ → $2k + 1 = 3$ → k = 1

ตัวอย่าง 3.10สองตัวแปร⭐⭐⭐ ท้าทาย

$$f(x) = \begin{cases} x + a &;\ x \lt 1\\ 5 &;\ x = 1\\ bx^2 - 3 &;\ x \gt 1\end{cases}$$ หาค่า $a$ และ $b$ ที่ทำให้ $f$ ต่อเนื่องที่ $x = 1$

✅ เฉลย

ต้องได้ ลิมิตซ้าย = ลิมิตขวา = $f(1) = 5$

ซ้าย: $1 + a = 5 \Rightarrow a = 4$ · ขวา: $b - 3 = 5 \Rightarrow b = 8$ → a = 4, b = 8

3.5 ฟังก์ชันไหนต่อเนื่องบ้าง (ภาพรวม)

พหุนาม

ต่อเนื่อง ทุกจุด บน $\mathbb{R}$ เช่น $x^3 - 2x + 7$

ฟังก์ชันตรรกยะ $\frac{P(x)}{Q(x)}$

ต่อเนื่องทุกจุด ยกเว้นที่ $Q(x) = 0$

รากที่สอง $\sqrt{g(x)}$

ต่อเนื่องเมื่อ $g(x) \ge 0$

ฟังก์ชันหลายช่วง

ต้อง ตรวจที่รอยต่อ ทุกจุด

ตัวอย่าง 3.11หาจุดไม่ต่อเนื่อง⭐ ง่าย

ฟังก์ชัน $f(x) = \dfrac{x+1}{x^2 - 5x + 6}$ ไม่ต่อเนื่องที่จุดใดบ้าง

✅ เฉลย

$x^2 - 5x + 6 = (x-2)(x-3) = 0$ เมื่อ x = 2, 3 → ไม่ต่อเนื่องที่ x = 2 และ x = 3 ต่อเนื่องทุกจุดอื่น

ตรวจคำตอบด้วย Python (SymPy)
from sympy import symbols, limit, Piecewise, solve
x, k = symbols('x k')
left  = limit((x**2 - 9)/(x - 3), x, 3, '-')
right = limit(x + 3, x, 3, '+')
print("ลิมิตซ้าย =", left, " ลิมิตขวา =", right)
print("k ที่ทำให้ kx+1 ต่อกับ x^2-1 ที่ x=2:", solve(k*2 + 1 - (2**2 - 1), k))
▸ ผลลัพธ์เมื่อรัน
ลิมิตซ้าย = 6  ลิมิตขวา = 6
k ที่ทำให้ kx+1 ต่อกับ x^2-1 ที่ x=2: [1]

คำถามท้ายบท

ลองทำเองก่อนทุกข้อ แล้วค่อยกด 🔑 ดูเฉลย (ต้องใช้รหัสผ่านจากผู้สอน)

  1. นิยามและกราฟ
  2. จงเขียนเงื่อนไข 3 ข้อของการที่ $f$ ต่อเนื่องที่ $x = a$

    (1) $f(a)$ หาค่าได้ (2) $\displaystyle\lim_{x\to a}f(x)$ หาค่าได้ (ลิมิตซ้าย = ขวา) (3) $\displaystyle\lim_{x\to a}f(x) = f(a)$

  3. ฟังก์ชัน $f$ มี $f(4) = 2$, $\displaystyle\lim_{x\to4^-}f(x) = 5$, $\displaystyle\lim_{x\to4^+}f(x) = 5$ ฟังก์ชันต่อเนื่องที่ $x=4$ หรือไม่ ถ้าไม่ จะแก้ $f(4)$ เป็นเท่าใดจึงจะต่อเนื่อง (ดูว่าข้อไหนไม่ผ่าน)

    ลิมิต = 5 แต่ $f(4) = 2 \ne 5$ → ไม่ต่อเนื่อง (แบบรู) · แก้ให้ $f(4) = 5$ ก็จะต่อเนื่อง

  4. ฟังก์ชัน $f(x) = \dfrac{x-4}{x^2-16}$ ไม่ต่อเนื่องที่จุดใด จุดไหนเป็นแบบ “รู” จุดไหนเป็นแบบ “พุ่งไปอนันต์”

    ไม่ต่อเนื่องที่ $x = 4$ และ $x = -4$ · $\dfrac{x-4}{(x-4)(x+4)} = \dfrac{1}{x+4}$ ดังนั้นที่ x = 4 ลิมิต = $\tfrac18$ เป็น รู · ที่ x = −4 ตัวส่วนเป็น 0 แต่เศษไม่เป็น 0 เป็น อนันต์

  5. ตรวจความต่อเนื่อง
  6. $f(x) = \begin{cases} x^2 + 1 &;\ x \lt 1\\ 3x - 1 &;\ x \ge 1\end{cases}$ ต่อเนื่องที่ $x = 1$ หรือไม่

    $f(1) = 2$ · ซ้าย $1 + 1 = 2$ · ขวา $3 - 1 = 2$ → ต่อเนื่อง

  7. $f(x) = \begin{cases} 2x &;\ x \lt 3\\ 5 &;\ x = 3\\ x + 3 &;\ x \gt 3\end{cases}$ ต่อเนื่องที่ $x = 3$ หรือไม่

    ซ้าย 6, ขวา 6 → ลิมิต = 6 แต่ $f(3) = 5 \ne 6$ → ไม่ต่อเนื่อง (ข้อ 3 ไม่ผ่าน)

  8. $f(x) = \begin{cases} \dfrac{x^2-1}{x+1} &;\ x \ne -1\\ -2 &;\ x = -1\end{cases}$ ต่อเนื่องที่ $x = -1$ หรือไม่

    $\dfrac{(x-1)(x+1)}{x+1} = x - 1 \to -2$ และ $f(-1) = -2$ → ต่อเนื่อง

  9. หาค่าคงที่
  10. $f(x) = \begin{cases} \dfrac{x^2-4}{x-2} &;\ x \lt 2\\ k &;\ x = 2\\ x + 2 &;\ x \gt 2\end{cases}$ หาค่า $k$ ที่ทำให้ต่อเนื่องที่ $x = 2$ (ลิมิตซ้าย = ขวา = k)

    ซ้าย: $x + 2 \to 4$ · ขวา: 4 → $k = 4$

  11. $f(x) = \begin{cases} kx^2 &;\ x \le 3\\ 2x + 12 &;\ x \gt 3\end{cases}$ หาค่า $k$

    $9k = 6 + 12 = 18 \Rightarrow k = 2$

  12. $f(x) = \begin{cases} \dfrac{x^2 + x - 6}{x - 2} &;\ x \ne 2\\ k &;\ x = 2\end{cases}$ หาค่า $k$

    $\dfrac{(x+3)(x-2)}{x-2} = x+3 \to 5$ → $k = 5$

  13. $f(x) = \begin{cases} ax + 1 &;\ x \lt 1\\ 4 &;\ x = 1\\ x^2 + b &;\ x \gt 1\end{cases}$ หาค่า $a$ และ $b$ ที่ทำให้ต่อเนื่องที่ $x = 1$ (2 สมการ 2 ตัวแปร)

    $a + 1 = 4 \Rightarrow a = 3$ · $1 + b = 4 \Rightarrow b = 3$

  14. $f(x) = \begin{cases} \dfrac{\sqrt{x} - 2}{x - 4} &;\ x \ne 4\\ k &;\ x = 4\end{cases}$ หาค่า $k$

    คอนจูเกต: $\dfrac{1}{\sqrt x + 2} \to \dfrac14$ → $k = \dfrac14$
