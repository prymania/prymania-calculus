4.1 อัตราการเปลี่ยนแปลงเฉลี่ย

ขับรถจากมหาสารคามไปขอนแก่น 75 กม. ใช้เวลา 1.5 ชม. → ความเร็วเฉลี่ย $= \dfrac{75}{1.5} = 50$ กม./ชม. นี่แหละคือ “อัตราการเปลี่ยนแปลงเฉลี่ย”: ระยะทางเปลี่ยนไปเท่าไร ต่อเวลาที่เปลี่ยนไป

📐 อัตราการเปลี่ยนแปลงเฉลี่ย เมื่อ x เปลี่ยนจาก $x$ เป็น $x + h$
$$\frac{\Delta y}{\Delta x} = \frac{f(x+h) - f(x)}{(x+h) - x} = \frac{f(x+h) - f(x)}{h} \quad\text{หรือ}\quad \frac{f(x_2) - f(x_1)}{x_2 - x_1}$$

ในทางกราฟ คือ ความชันของเส้นตัด (secant line) ที่ลากผ่านสองจุดบนกราฟ

ตัวอย่าง 4.1อัตราการเปลี่ยนแปลงเฉลี่ย⭐ ง่าย

$f(x) = 2x + 1$ เมื่อ x เปลี่ยนจาก 1 เป็น 3

✅ เฉลย

$f(1) = 3,\ f(3) = 7$ → $\dfrac{7 - 3}{3 - 1} = $ 2 (เส้นตรง อัตราเฉลี่ยเท่ากับความชันเสมอ)

ตัวอย่าง 4.2อัตราการเปลี่ยนแปลงเฉลี่ย (ชุดฝึก)⭐⭐ ปานกลาง
  1. $f(x) = x^2 + 5$ เมื่อ x เปลี่ยนจาก 1 เป็น 8
  2. $f(x) = x^2 - 5x$ เมื่อ x เปลี่ยนจาก −10 เป็น 10
  3. $f(x) = \dfrac{x-2}{x+2}$ เมื่อ x เปลี่ยนจาก −5 เป็น 5
  4. $f(x) = 3x^2 + 2x + 7$ เมื่อ x เปลี่ยนจาก 0 เป็น 10
✅ เฉลย
  1. $\dfrac{(64+5) - (1+5)}{8 - 1} = \dfrac{63}{7} = $ 9
  2. $f(10) = 50,\ f(-10) = 150$ → $\dfrac{50 - 150}{20} = $ −5
  3. $f(5) = \tfrac37,\ f(-5) = \tfrac{-7}{-3} = \tfrac73$ → $\dfrac{\frac37 - \frac73}{10} = \dfrac{-\frac{40}{21}}{10} = $ −4/21 ≈ −0.19
  4. $f(10) = 327,\ f(0) = 7$ → $\dfrac{320}{10} = $ 32

4.2 อัตราการเปลี่ยนแปลงขณะใด ๆ = อนุพันธ์

มาตรวัดความเร็วในรถไม่ได้บอกความเร็วเฉลี่ย แต่บอกความเร็ว ณ วินาทีนั้น — ทำได้โดยให้ช่วงเวลา $h$ เล็กลงจนเข้าใกล้ 0 นั่นคือใช้ลิมิตจากบทที่ 2!

⭐ นิยามอนุพันธ์ (Derivative)
$$f'(x) = \lim_{h\to0}\frac{f(x+h) - f(x)}{h}$$

เขียนแทนได้หลายแบบ: $f'(x),\ y',\ \dfrac{dy}{dx},\ \dfrac{d}{dx}f(x)$ — เรียกการหาอนุพันธ์ว่า “การดิฟ” (differentiate)

ในทางกราฟ $f'(a)$ = ความชันของเส้นสัมผัส (tangent line) ที่จุด $x = a$

ลองเลื่อน h ให้เล็กลง: จุด Q ไหลเข้าหา P และเส้นตัดสีชมพูค่อย ๆ ทับเส้นสัมผัสสีเขียว — ความชันของเส้นตัดวิ่งเข้าหาความชันของเส้นสัมผัส นี่คือความหมายของอนุพันธ์

ตัวอย่าง 4.3ดิฟจากนิยาม⭐⭐ ปานกลาง

หาอัตราการเปลี่ยนแปลงขณะใด ๆ ของ $f(x) = x^2 + 5$ แล้วหาค่าเมื่อ $x = 1$

✅ เฉลย
$$\begin{aligned}f'(x) &= \lim_{h\to0}\frac{[(x+h)^2+5] - [x^2+5]}{h} = \lim_{h\to0}\frac{x^2+2xh+h^2+5-x^2-5}{h}\\ &= \lim_{h\to0}\frac{2xh+h^2}{h} = \lim_{h\to0}\frac{h(2x+h)}{h} = \lim_{h\to0}(2x+h) = 2x\end{aligned}$$

เมื่อ $x = 1$: $f'(1) = $ 2

ตัวอย่าง 4.4ดิฟจากนิยาม (ฝึกต่อ)⭐⭐⭐ ท้าทาย
  1. $f(x) = 3x^2 - 5$ ขณะ $x = 10$
  2. $f(x) = x^3 - x^2$ ขณะ $x = 5$
✅ เฉลย

a) $f(x+h) - f(x) = 3(x^2+2xh+h^2) - 5 - 3x^2 + 5 = 6xh + 3h^2$

$$f'(x) = \lim_{h\to0}\frac{6xh+3h^2}{h} = \lim_{h\to0}(6x+3h) = 6x \quad\Rightarrow\quad f'(10) = 60$$

b) ใช้ $(x+h)^3 = x^3 + 3x^2h + 3xh^2 + h^3$

$$\begin{aligned}f(x+h)-f(x) &= (3x^2h + 3xh^2 + h^3) - (2xh + h^2)\\ f'(x) &= \lim_{h\to0}(3x^2 + 3xh + h^2 - 2x - h) = 3x^2 - 2x\end{aligned}$$

$f'(5) = 75 - 10 = $ 65

😮‍💨 นิยามยาวไปไหม?

ใช่! เลยมีคนสรุปเป็น สูตร ไว้ให้ใช้ (หัวข้อถัดไป) แต่ต้องเข้าใจที่มาก่อนว่าสูตรทั้งหมดมาจากลิมิตตัวนี้

4.3 สูตรการดิฟพื้นฐาน

1. ดิฟค่าคงที่

$$\frac{d}{dx}C = 0$$

เส้นนอน ความชัน = 0

2. ดิฟเลขยกกำลัง (Power rule)

$$\frac{d}{dx}ax^n = (n\cdot a)\,x^{n-1}$$

“เอากำลังลงมาคูณ แล้วลดกำลังลง 1”

3. ดิฟผลบวก/ผลต่าง

$$\frac{d}{dx}[f \pm g] = f' \pm g'$$

ดิฟทีละพจน์ได้เลย

4. ใช้กับกำลังลบ/เศษส่วนได้

$$\frac{d}{dx}\frac{1}{x} = -\frac{1}{x^2},\ \ \frac{d}{dx}\sqrt x = \frac{1}{2\sqrt x}$$

เขียน $\frac1x = x^{-1}$, $\sqrt x = x^{1/2}$ ก่อน

ตัวอย่าง 4.5สูตรยกกำลัง⭐ ง่าย
  1. $\dfrac{d}{dx}100$
  2. $\dfrac{d}{dx}x^2$
  3. $\dfrac{d}{dx}3x^5$
  4. $\dfrac{d}{dx}(3x^5 + 20x + 2)$
  5. $\dfrac{d}{dx}(3x^{10} - 20x^2 + 2x - 7)$
  6. $\dfrac{d}{dx}(-5x^8 - 4x^3 - 10x - 3)$
  7. $\dfrac{d}{dx}\left(\tfrac14x^4 - \tfrac13x^3 - \tfrac14x^2 - 3\right)$
  8. $\dfrac{d}{dx}\left(\tfrac15x^5 - \tfrac23x^3 + \tfrac12x^2 + 3\right)$
✅ เฉลย
  1. $0$
  2. $2x$
  3. $15x^4$
  4. $15x^4 + 20$
  5. $30x^9 - 40x + 2$
  6. $-40x^7 - 12x^2 - 10$
  7. $x^3 - x^2 - \tfrac12x$
  8. $x^4 - 2x^2 + x$
ตัวอย่าง 4.6กำลังลบและราก⭐⭐ ปานกลาง
  1. $y = \dfrac{4}{x^3}$
  2. $y = 6\sqrt x$
  3. $y = x^2 + \dfrac{1}{x} - \dfrac{2}{x^2}$
  4. $y = \sqrt[3]{x^2}$
✅ เฉลย
  1. $4x^{-3} \to -12x^{-4} = -\dfrac{12}{x^4}$
  2. $6x^{1/2} \to 3x^{-1/2} = \dfrac{3}{\sqrt x}$
  3. $2x - x^{-2} + 4x^{-3} = 2x - \dfrac1{x^2} + \dfrac4{x^3}$
  4. $x^{2/3} \to \tfrac23x^{-1/3} = \dfrac{2}{3\sqrt[3]{x}}$

4.4 ดิฟผลคูณและผลหาร

❌ ข้อผิดพลาดยอดฮิต

$\dfrac{d}{dx}[f\cdot g] \ne f'\cdot g'$ — ดิฟผลคูณ ไม่ใช่ เอาดิฟมาคูณกัน! เช่น $x\cdot x = x^2$ ดิฟได้ $2x$ แต่ $1 \cdot 1 = 1$

ดิฟผลคูณ

$$\frac{d}{dx}(\text{หน้า}\cdot\text{หลัง}) = \text{หน้า}\cdot\text{หลัง}' + \text{หลัง}\cdot\text{หน้า}'$$

ดิฟผลหาร

$$\frac{d}{dx}\left(\frac{\text{บน}}{\text{ล่าง}}\right) = \frac{\text{ล่าง}\cdot\text{บน}' - \text{บน}\cdot\text{ล่าง}'}{(\text{ล่าง})^2}$$

ท่องว่า “ล่างดิฟบน ลบ บนดิฟล่าง ส่วนล่างกำลังสอง”

ตัวอย่าง 4.7ดิฟผลคูณ⭐⭐ ปานกลาง
  1. $\dfrac{d}{dx}(x+2)(3x^5+x)$
  2. $\dfrac{d}{dx}(3x^5+2x)(-x^3+2x^2)$
  3. $\dfrac{d}{dx}(-4x^3)(-2x^3-x-5)$
✅ เฉลย

a) $(x+2)(15x^4+1) + (3x^5+x)(1) = 15x^5 + 30x^4 + x + 2 + 3x^5 + x$ = $18x^5 + 30x^4 + 2x + 2$

b) $(3x^5+2x)(-3x^2+4x) + (-x^3+2x^2)(15x^4+2)$

$$= (-9x^7 + 12x^6 - 6x^3 + 8x^2) + (-15x^7 + 30x^6 - 2x^3 + 4x^2)$$

= $-24x^7 + 42x^6 - 8x^3 + 12x^2$

c) $(-4x^3)(-6x^2-1) + (-2x^3-x-5)(-12x^2) = (24x^5 + 4x^3) + (24x^5 + 12x^3 + 60x^2)$ = $48x^5 + 16x^3 + 60x^2$

💡 ตรวจแบบที่ 2: กระจายก่อนแล้วดิฟ เช่น (a) $(x+2)(3x^5+x) = 3x^6 + 6x^5 + x^2 + 2x$ ดิฟได้ $18x^5 + 30x^4 + 2x + 2$ ✓ เหมือนกัน

ตัวอย่าง 4.8ดิฟผลหาร⭐⭐ ปานกลาง
  1. $\dfrac{d}{dx}\left(\dfrac{x^2-2x+5}{x^2-3x}\right)$
  2. $\dfrac{d}{dx}\left(\dfrac{x^3-4x^2}{2x^2}\right)$
  3. $\dfrac{d}{dx}\left(\dfrac{3x^4-5x^3+1}{x^2}\right)$
  4. $\dfrac{d}{dx}\left(\dfrac{2x+1}{x-3}\right)$
✅ เฉลย

a) $$\frac{(x^2-3x)(2x-2) - (x^2-2x+5)(2x-3)}{(x^2-3x)^2} = \frac{(2x^3-8x^2+6x) - (2x^3-7x^2+16x-15)}{(x^2-3x)^2} = \frac{-x^2-10x+15}{(x^2-3x)^2}$$

b) ลดรูปก่อนง่ายกว่า: $\dfrac{x^3-4x^2}{2x^2} = \dfrac{x}{2} - 2$ → ดิฟได้ 1/2 (ใช้สูตรผลหารก็ได้ $\frac{2x^4}{4x^4} = \frac12$ เท่ากัน)

c) แยกพจน์: $3x^2 - 5x + x^{-2}$ → $6x - 5 - \dfrac{2}{x^3}$

d) $\dfrac{(x-3)(2) - (2x+1)(1)}{(x-3)^2} = $ $\dfrac{-7}{(x-3)^2}$

🧠 ทริค: ถ้าตัวส่วนเป็นพจน์เดียว แยกเศษส่วนก่อน

$\dfrac{3x^4 - 5x^3 + 1}{x^2} = 3x^2 - 5x + x^{-2}$ แล้วใช้สูตรยกกำลังทีละตัว เร็วกว่าและพลาดน้อยกว่าสูตรผลหารมาก

4.5 กฎลูกโซ่ (Chain Rule)

ใช้เมื่อเจอ “ฟังก์ชันซ้อนฟังก์ชัน” เช่น $(x^2+2x)^4$ — ถ้าจะกระจายยกกำลังสี่คงเหนื่อยมาก

⛓️ กฎลูกโซ่

ถ้า $y = f(u)$ และ $u = g(x)$ แล้ว $$\frac{dy}{dx} = \frac{dy}{du}\cdot\frac{du}{dx}$$

ทางลัด: ดิฟก้อนนอก (ไส้ในอยู่เหมือนเดิม) × ดิฟไส้ใน

$$\frac{d}{dx}[\,\text{ก้อน}\,]^n = n[\,\text{ก้อน}\,]^{n-1}\cdot\frac{d}{dx}[\,\text{ก้อน}\,]$$
$(x^2+2x)^4$
➜
$4(x^2+2x)^3$ดิฟก้อนนอก
×
$(2x+2)$ดิฟไส้ใน
ตัวอย่าง 4.9กฎลูกโซ่แบบเต็ม⭐ ง่าย

หาอนุพันธ์ของ $y = (x+5)^3$ โดยใช้กฎลูกโซ่

✅ เฉลย

ให้ $u = x + 5$ จะได้ $y = u^3$ · $\dfrac{dy}{du} = 3u^2$ · $\dfrac{du}{dx} = 1$

$\dfrac{dy}{dx} = 3u^2\cdot 1 = $ $3(x+5)^2$

ตัวอย่าง 4.10ทางลัดกฎลูกโซ่⭐⭐ ปานกลาง
  1. $\dfrac{d}{dx}(x^2+2x)^4$
  2. $\dfrac{d}{dx}(x^3-3x^2)^3$
  3. $\dfrac{d}{dx}(x^4-4x^3+2x)^3$
  4. $\dfrac{d}{dx}(5-2x)^7$
  5. $\dfrac{d}{dx}\sqrt{x^2+1}$
  6. $\dfrac{d}{dx}\dfrac{1}{(3x-1)^2}$
✅ เฉลย
  1. $4(x^2+2x)^3(2x+2) = 8(x+1)(x^2+2x)^3$
  2. $3(x^3-3x^2)^2(3x^2-6x)$
  3. $3(x^4-4x^3+2x)^2(4x^3-12x^2+2)$
  4. $7(5-2x)^6\cdot(-2) = -14(5-2x)^6$  (อย่าลืมดิฟไส้ใน −2!)
  5. $(x^2+1)^{1/2} \to \tfrac12(x^2+1)^{-1/2}\cdot 2x = \dfrac{x}{\sqrt{x^2+1}}$
  6. $(3x-1)^{-2} \to -2(3x-1)^{-3}\cdot 3 = \dfrac{-6}{(3x-1)^3}$

4.6 ดิฟฟังก์ชันประกอบ $(f\circ g)'$

🔗 สูตร (คือกฎลูกโซ่ในอีกรูปแบบ)
$$(f\circ g)'(x) = f'(g(x))\cdot g'(x)$$

ขั้นตอน: หา $f'$ และ $g'$ ก่อน → เอา $g(x)$ ไปแทนใน $f'$ → คูณด้วย $g'(x)$

ตัวอย่าง 4.11ฟังก์ชันประกอบ⭐⭐ ปานกลาง

กำหนด $f(x) = 2x^2 + 3$ และ $g(x) = 3x + 5$ จงหา $(f\circ g)'(x)$ และ $(g\circ f)'(x)$

✅ เฉลย

$f'(x) = 4x$, $g'(x) = 3$

$(f\circ g)'(x) = f'(g(x))\cdot g'(x) = 4(3x+5)\cdot 3 = $ $12(3x+5)$

$(g\circ f)'(x) = g'(f(x))\cdot f'(x) = 3\cdot 4x = $ $12x$  (เพราะ $g'$ เป็นค่าคงที่ 3 แทนอะไรก็ได้ 3)

ตัวอย่าง 4.12ฟังก์ชันประกอบ (ฝึกต่อ)⭐⭐ ปานกลาง
  1. $f(x) = x^2 - 3,\ g(x) = 2x^2 + 3x + 5$
  2. $f(x) = 2x - 3,\ g(x) = 5x^3$
  3. $f(x) = 3x^2 - 3,\ g(x) = x^2 + 3x$

จงหา $(f\circ g)'(x)$ และ $(g\circ f)'(x)$ ของแต่ละข้อ

✅ เฉลย

a) $f' = 2x,\ g' = 4x+3$ → $(f\circ g)' = 2(2x^2+3x+5)(4x+3)$ · $(g\circ f)' = [4(x^2-3)+3](2x) = (4x^2-9)(2x)$

b) $f' = 2,\ g' = 15x^2$ → $(f\circ g)' = 2\cdot15x^2 = 30x^2$ · $(g\circ f)' = 15(2x-3)^2\cdot 2 = 30(2x-3)^2$

c) $f' = 6x,\ g' = 2x+3$ → $(f\circ g)' = 6(x^2+3x)(2x+3)$ · $(g\circ f)' = [2(3x^2-3)+3](6x) = (6x^2-3)(6x) = 36x^3 - 18x$

4.7 อนุพันธ์อันดับสูง

ดิฟซ้ำไปเรื่อย ๆ ได้: $f'(x) = \dfrac{dy}{dx}$ (อันดับ 1), $f''(x) = \dfrac{d^2y}{dx^2}$ (อันดับ 2), $f'''(x) = \dfrac{d^3y}{dx^3}$ (อันดับ 3)

📍 ตำแหน่ง $s(t)$

รถอยู่ตรงไหน

🚗 ความเร็ว $v(t) = s'(t)$

ตำแหน่งเปลี่ยนเร็วแค่ไหน

🚀 ความเร่ง $a(t) = s''(t)$

ความเร็วเปลี่ยนเร็วแค่ไหน

ตัวอย่าง 4.13อนุพันธ์อันดับ 1, 2, 3⭐ ง่าย
  1. $f(x) = 5x^3 - 10x^2 + 3x$
  2. $f(x) = 5x^4 - 10x^3 + 3x - 7$
  3. $f(x) = 10x^5 - 7x^3 - 3x^2 - x$
✅ เฉลย

a) $f' = 15x^2 - 20x + 3$ · $f'' = 30x - 20$ · $f''' = 30$

b) $f' = 20x^3 - 30x^2 + 3$ · $f'' = 60x^2 - 60x$ · $f''' = 120x - 60$

c) $f' = 50x^4 - 21x^2 - 6x - 1$ · $f'' = 200x^3 - 42x - 6$ · $f''' = 600x^2 - 42$

ตัวอย่าง 4.14การเคลื่อนที่⭐⭐ ปานกลาง

วัตถุเคลื่อนที่โดยมีตำแหน่ง $s(t) = t^3 - 6t^2 + 9t$ เมตร ($t$ วินาที) จงหาความเร็วและความเร่งที่ $t = 2$ และหาว่าวัตถุหยุดนิ่งเมื่อใด

✅ เฉลย

$v(t) = 3t^2 - 12t + 9$ → $v(2) = 12 - 24 + 9 = -3$ ม./วินาที (เคลื่อนที่ถอยหลัง)

$a(t) = 6t - 12$ → $a(2) = 0$ ม./วินาที²

หยุดนิ่งเมื่อ $v = 0$: $3(t^2 - 4t + 3) = 3(t-1)(t-3) = 0$ → t = 1 และ t = 3 วินาที

ลองทำเองก่อนทุกข้อ แล้วค่อยกด 🔑 ดูเฉลย (ต้องใช้รหัสผ่านจากผู้สอน)

  1. อัตราการเปลี่ยนแปลงและนิยาม
  2. จงหาอัตราการเปลี่ยนแปลงเฉลี่ยของ $f(x) = x^3 - 2x$ เมื่อ x เปลี่ยนจาก 1 เป็น 3

    $f(3) = 21,\ f(1) = -1$ → $\dfrac{21 - (-1)}{2} = 11$

  3. จงใช้นิยามหาอนุพันธ์ของ $f(x) = 4x^2 + x$ (ใช้นิยามลิมิต)
    $$f'(x) = \lim_{h\to0}\frac{4(x+h)^2 + (x+h) - 4x^2 - x}{h} = \lim_{h\to0}\frac{8xh + 4h^2 + h}{h} = \lim_{h\to0}(8x + 4h + 1) = 8x + 1$$
  4. สูตรพื้นฐาน
  5. จงหา $y'$ เมื่อ (ก) $y = 7x^6 - 3x^4 + x - 12$ (ข) $y = \tfrac13x^6 + \tfrac12x^4 - 5$ (ค) $y = \pi^2$

    (ก) $42x^5 - 12x^3 + 1$ (ข) $2x^5 + 2x^3$ (ค) 0 ($\pi^2$ เป็นค่าคงที่)

  6. จงหา $y'$ เมื่อ $y = \dfrac{3}{x^2} + 4\sqrt x - \dfrac{1}{x}$

    $3x^{-2} + 4x^{1/2} - x^{-1}$ → $-6x^{-3} + 2x^{-1/2} + x^{-2} = -\dfrac{6}{x^3} + \dfrac{2}{\sqrt x} + \dfrac{1}{x^2}$

  7. ผลคูณ ผลหาร
  8. จงหา $\dfrac{d}{dx}(2x^2 - 1)(x^3 + 4x)$ (ผลคูณ)

    $(2x^2-1)(3x^2+4) + (x^3+4x)(4x) = 6x^4 + 5x^2 - 4 + 4x^4 + 16x^2 = 10x^4 + 21x^2 - 4$

  9. จงหา $\dfrac{d}{dx}\left(\dfrac{x^2}{x+1}\right)$ (ผลหาร)

    $\dfrac{(x+1)(2x) - x^2(1)}{(x+1)^2} = \dfrac{x^2 + 2x}{(x+1)^2}$

  10. จงหา $\dfrac{d}{dx}\left(\dfrac{x^5 + 2x^3 - x}{x}\right)$ (ลดรูปก่อน)

    $= x^4 + 2x^2 - 1$ (เมื่อ $x \ne 0$) → $4x^3 + 4x$

  11. กฎลูกโซ่และฟังก์ชันประกอบ
  12. จงหา $\dfrac{d}{dx}(3x^2 - 5x + 1)^5$

    $5(3x^2 - 5x + 1)^4(6x - 5)$

  13. จงหา $\dfrac{d}{dx}\sqrt{4x^3 + 1}$

    $\tfrac12(4x^3+1)^{-1/2}\cdot 12x^2 = \dfrac{6x^2}{\sqrt{4x^3+1}}$

  14. จงหา $\dfrac{d}{dx}\,x^2(x+1)^3$ (ผลคูณ + ลูกโซ่)

    $x^2\cdot 3(x+1)^2 + (x+1)^3\cdot 2x = x(x+1)^2(3x + 2x + 2) = x(x+1)^2(5x+2)$

  15. กำหนด $f(x) = x^3$ และ $g(x) = 2x - 1$ จงหา $(f\circ g)'(x)$, $(g\circ f)'(x)$ และ $(f\circ g)'(1)$

    $(f\circ g)' = 3(2x-1)^2\cdot 2 = 6(2x-1)^2$ · $(g\circ f)' = 2\cdot 3x^2 = 6x^2$ · $(f\circ g)'(1) = 6$

  16. อนุพันธ์อันดับสูง
  17. จงหา $f'''(x)$ ของ $f(x) = 2x^5 - x^4 + 3x^2 - 9$

    $f' = 10x^4 - 4x^3 + 6x$ · $f'' = 40x^3 - 12x^2 + 6$ · $f''' = 120x^2 - 24x$

  18. ลูกบอลถูกโยนขึ้นด้วยความสูง $h(t) = -5t^2 + 30t + 2$ เมตร จงหาความเร็วเมื่อ $t = 1$ และความเร่ง

    $v = h' = -10t + 30$ → $v(1) = 20$ ม./วินาที · $a = h'' = -10$ ม./วินาที² (คือแรงโน้มถ่วงโดยประมาณ)
