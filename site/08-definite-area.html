8.1 อินทิกรัลจำกัดเขต

อินทิกรัลจำกัดเขตมี “ขอบเขต” $a$ (ล่าง) และ $b$ (บน) กำกับไว้ ผลลัพธ์เป็น ตัวเลข ไม่ใช่ฟังก์ชัน

⭐ ทฤษฎีบทหลักมูลของแคลคูลัส (Fundamental Theorem of Calculus)
$$\int_a^b f(x)\,dx = \Big[F(x)\Big]_a^b = F(b) - F(a) \qquad\text{โดยที่ } F'(x) = f(x)$$

สรุปวิธีทำ: อินทิเกรตธรรมดา → แทนค่าบน → ลบด้วยแทนค่าล่าง (ไม่ต้องเขียน $+C$ เพราะลบกันหายเสมอ)

ตัวอย่าง 8.1อินทิกรัลจำกัดเขตข้อแรก⭐ ง่าย

จงหา $\displaystyle\int_2^5 (x^2 - 1)\,dx$

✅ เฉลย
$$\Big[\tfrac13x^3 - x\Big]_2^5 = \left(\tfrac{125}{3} - 5\right) - \left(\tfrac83 - 2\right) = \tfrac{117}{3} - 3 = 39 - 3 = 36$$

36

ตัวอย่าง 8.2ฝึกอินทิกรัลจำกัดเขต⭐⭐ ปานกลาง
  1. $\displaystyle\int_0^3 (x^2 - 1)\,dx$
  2. $\displaystyle\int_{-1}^2 (3x^2 - 6x - 9)\,dx$
  3. $\displaystyle\int_0^2 (3x^2 - 6x - 9)\,dx$
  4. $\displaystyle\int_1^4 \frac{2}{\sqrt x}\,dx$
  5. $\displaystyle\int_1^4 \frac{1}{\sqrt x}\,dx$
  6. $\displaystyle\int_1^6 (-x^2 + 6x + 10)\,dx$
✅ เฉลย
  1. $\big[\tfrac{x^3}{3} - x\big]_0^3 = 9 - 3 = $ 6
  2. $\big[x^3 - 3x^2 - 9x\big]_{-1}^2 = (8 - 12 - 18) - (-1 - 3 + 9) = -22 - 5 = $ −27
  3. $(-22) - 0 = $ −22
  4. $\big[4\sqrt x\big]_1^4 = 8 - 4 = $ 4
  5. $\big[2\sqrt x\big]_1^4 = 4 - 2 = $ 2
  6. $\big[-\tfrac{x^3}{3} + 3x^2 + 10x\big]_1^6 = (-72 + 108 + 60) - (-\tfrac13 + 13) = 96 - \tfrac{38}{3} = $ $\tfrac{250}{3} \approx 83.33$

💡 ข้อ 2–3 ได้ค่าติดลบ — หมายความว่าอะไร? ดูหัวข้อถัดไป!

สมบัติ 1

$$\int_a^a f(x)\,dx = 0$$

สมบัติ 2 สลับขอบเขต

$$\int_b^a f\,dx = -\int_a^b f\,dx$$

สมบัติ 3 แบ่งช่วง

$$\int_a^b f\,dx = \int_a^c f\,dx + \int_c^b f\,dx$$

สมบัติ 4 ดึงค่าคงที่

$$\int_a^b k f\,dx = k\int_a^b f\,dx$$

8.2 อินทิกรัล = พื้นที่ใต้เส้นโค้ง

ทำไมการ “ดิฟย้อนกลับ” ถึงได้พื้นที่? ลองหั่นพื้นที่ใต้กราฟเป็นสี่เหลี่ยมผืนผ้าแคบ ๆ หลายชิ้น แต่ละชิ้นกว้าง $\Delta x$ สูง $f(x)$ พื้นที่รวม $\approx \sum f(x)\Delta x$ — ยิ่งหั่นบาง ยิ่งแม่น และเมื่อ $\Delta x \to 0$ จะได้พื้นที่จริงพอดี เครื่องหมาย $\int$ ก็คือตัว S ยืด ๆ มาจาก Sum นั่นเอง

$$\int_a^b f(x)\,dx = \lim_{n\to\infty}\sum_{i=1}^{n} f(x_i)\,\Delta x$$
ตัวอย่าง 8.3พื้นที่ใต้พาราโบลา⭐ ง่าย

หาพื้นที่ใต้กราฟของ $y = -x^2 + 6x + 10$ บนช่วง $[1, 6]$

✅ เฉลย

กราฟอยู่เหนือแกน x ตลอดช่วง → $A = \displaystyle\int_1^6(-x^2+6x+10)\,dx = \tfrac{250}{3} \approx$ 83.33 ตารางหน่วย (จากตัวอย่างก่อนหน้า)

ตัวอย่าง 8.4โบนัส: พื้นที่สี่เหลี่ยมด้วยอินทิกรัล⭐⭐ ปานกลาง

เรารู้ว่าพื้นที่สี่เหลี่ยม = กว้าง × ยาว จงอธิบายว่าพื้นที่สีฟ้า (ใต้ $y = 5$ จาก $x = 2$ ถึง $10$) คำนวณด้วยอินทิกรัลได้อย่างไร และได้เท่ากับสูตรกว้าง × ยาวหรือไม่

✅ เฉลย

สูตรเดิม: กว้าง $10 - 2 = 8$ × สูง $5$ = 40

อินทิกรัล: $\displaystyle\int_2^{10}5\,dx = \big[5x\big]_2^{10} = 50 - 10 = 40$ ✓ เท่ากัน

หลักการ: อินทิกรัลคือการรวมแถบสี่เหลี่ยมบาง ๆ สูง $f(x) = 5$ กว้าง $dx$ ตั้งแต่ $x = 2$ ถึง $10$ — เมื่อความสูงคงที่ ผลรวมก็คือ ความสูง × ความกว้างรวม นั่นเอง สูตรสี่เหลี่ยมจึงเป็นกรณีพิเศษของอินทิกรัล

ตัวอย่าง 8.5พื้นที่ใต้กราฟ (ชุดฝึก)⭐⭐ ปานกลาง
  1. $y = 3x^2 + 4$ บนช่วง $[0, 10]$
  2. $y = 3x^2 + 4$ บนช่วง $[-10, 10]$
  3. $y = x^4 - \tfrac12x^3 + 2$ บนช่วง $[2, 5]$
  4. $y = \sqrt x$ บนช่วง $[0, 10]$
  5. $y = x$ บนช่วง $[0, 10]$
✅ เฉลย
  1. $\big[x^3 + 4x\big]_0^{10} = $ 1040
  2. $1040 - (-1040) = $ 2080 (กราฟสมมาตร ได้สองเท่าของข้อ 1)
  3. $\big[\tfrac{x^5}{5} - \tfrac{x^4}{8} + 2x\big]_2^5 = 556.875 - 8.4 = $ 548.475
  4. $\big[\tfrac23x^{3/2}\big]_0^{10} = \tfrac23\cdot10\sqrt{10} \approx $ 21.08
  5. $\big[\tfrac{x^2}{2}\big]_0^{10} = $ 50 (= พื้นที่สามเหลี่ยม ½ × 10 × 10 ✓)

8.3 พื้นที่ใต้แกน x

ถ้ากราฟอยู่ ใต้แกน x ค่า $f(x)$ ติดลบ อินทิกรัลจึงได้ ค่าลบ แต่ พื้นที่ต้องเป็นบวกเสมอ จึงต้องใส่เครื่องหมายลบ (หรือใช้ค่าสัมบูรณ์)

📐 สามกรณีของพื้นที่

อยู่เหนือแกน x ($f \ge 0$): $\quad A = \displaystyle\int_a^b f(x)\,dx$

อยู่ใต้แกน x ($f \lt 0$): $\quad A = -\displaystyle\int_a^b f(x)\,dx = \left|\int_a^b f(x)\,dx\right|$

คาบเกี่ยวแกน x (ตัดแกนที่ $x = z$): $\quad A = \left|\displaystyle\int_a^z f\,dx\right| + \left|\displaystyle\int_z^b f\,dx\right|$

ตัวอย่าง 8.6กราฟอยู่ใต้แกน⭐ ง่าย

หาพื้นที่ที่ปิดล้อมด้วยกราฟ $y = -x^2 - 6x - 10$ กับแกน x บนช่วง $[1, 6]$

✅ เฉลย
$$\int_1^6(-x^2-6x-10)\,dx = \Big[-\tfrac{x^3}{3} - 3x^2 - 10x\Big]_1^6 = (-240) - \left(-\tfrac{40}{3}\right) = -\tfrac{680}{3}$$

ได้ค่าลบเพราะอยู่ใต้แกน → พื้นที่ = 680/3 ≈ 226.67 ตารางหน่วย

ตัวอย่าง 8.7ใต้แกน (ชุดฝึก)⭐⭐ ปานกลาง
  1. $y = x^2 - 2x - 10$ บน $[0, 4]$
  2. $y = -3x^2 - 20$ บน $[0, 6]$
  3. $y = -3x^2 - 20$ บน $[-6, 6]$
  4. $y = x$ บน $[-10, 0]$
✅ เฉลย

ก่อนอื่นต้องเช็คว่ากราฟตัดแกนในช่วงหรือไม่ — ข้อ 1 รากคือ $1 \pm\sqrt{11} \approx -2.32,\ 4.32$ อยู่นอก [0, 4] จึงอยู่ใต้แกนทั้งช่วง ข้อ 2–4 อยู่ใต้แกนตลอด

  1. $\big[\tfrac{x^3}{3} - x^2 - 10x\big]_0^4 = -\tfrac{104}{3}$ → พื้นที่ $\tfrac{104}{3} \approx 34.67$
  2. $\big[-x^3 - 20x\big]_0^6 = -336$ → 336
  3. $-336 - 336 = -672$ → 672
  4. $\big[\tfrac{x^2}{2}\big]_{-10}^0 = -50$ → 50

8.4 เมื่อกราฟตัดแกน x — ต้องแบ่งช่วง!

⚠️ กับดักใหญ่ที่สุดของบทนี้

ถ้าอินทิเกรตรวดเดียวทั้งช่วง ส่วนที่อยู่เหนือแกน (บวก) กับใต้แกน (ลบ) จะ หักล้างกัน ได้คำตอบผิด! ต้อง หาจุดตัดแกน x ก่อน (แก้ $f(x) = 0$) ถ้าจุดตัดอยู่ในช่วง ให้แบ่งอินทิเกรตทีละช่วงแล้วรวมค่าสัมบูรณ์

ตัวอย่าง 8.8พาราโบลาตัดแกน⭐⭐ ปานกลาง

หาพื้นที่ที่ปิดล้อมด้วย $y = x^2 - 4x$ กับแกน x บนช่วง $[0, 6]$

✅ เฉลย

1. จุดตัดแกน: $x^2 - 4x = x(x-4) = 0 \Rightarrow x = 0, 4$ → x = 4 อยู่ในช่วง ต้องแบ่ง [0, 4] และ [4, 6]

2. $\displaystyle\int_0^4(x^2 - 4x)dx = \Big[\tfrac{x^3}{3} - 2x^2\Big]_0^4 = \tfrac{64}{3} - 32 = -\tfrac{32}{3}$ → พื้นที่ $\tfrac{32}{3}$

3. $\displaystyle\int_4^6(x^2 - 4x)dx = (72 - 72) - \left(-\tfrac{32}{3}\right) = \tfrac{32}{3}$

4. พื้นที่รวม $= \tfrac{32}{3} + \tfrac{32}{3} = $ 64/3 ≈ 21.33

😱 ถ้าอินทิเกรตรวด $\int_0^6 = 0$ — ได้พื้นที่ศูนย์ ทั้งที่เห็นพื้นที่ชัด ๆ!

ตัวอย่าง 8.9กำลังสามตัดแกน⭐⭐⭐ ท้าทาย

หาพื้นที่ที่ปิดล้อมด้วย $y = x^3 - 4x^2 - 7x + 10$ กับแกน x บนช่วง $[0, 4]$

✅ เฉลย

จุดตัด: ลอง x = 1: $1 - 4 - 7 + 10 = 0$ ✓ จึงหารด้วย $(x - 1)$ ได้ $(x-1)(x^2 - 3x - 10) = (x-1)(x-5)(x+2)$ → ตัดแกนที่ −2, 1, 5 · ในช่วง [0, 4] มี x = 1

ให้ $F(x) = \tfrac{x^4}{4} - \tfrac{4x^3}{3} - \tfrac{7x^2}{2} + 10x$ → $F(0) = 0,\ F(1) = \tfrac{65}{12},\ F(4) = -\tfrac{112}{3}$

$\int_0^1 = \tfrac{65}{12}$ (เหนือแกน) · $\int_1^4 = -\tfrac{112}{3} - \tfrac{65}{12} = -\tfrac{513}{12}$ (ใต้แกน)

พื้นที่ $= \tfrac{65}{12} + \tfrac{513}{12} = \tfrac{578}{12} = $ 289/6 ≈ 48.17

ตัวอย่าง 8.10ลองทำเอง: ตัดแกนหลายจุด⭐⭐⭐ ท้าทาย
  1. $y = x^3 - 4x^2 - 7x + 10$ บนช่วง $[-2, 5]$
  2. $y = x^3 - 4x^2$ บนช่วง $[-2, 5]$
  3. $y = 3x^2 - 10$ บนช่วง $[-3, 3]$
✅ เฉลย

a) แบ่งที่ x = 1 (−2 และ 5 เป็นปลายช่วงพอดี) · $F(-2) = -\tfrac{58}{3},\ F(1) = \tfrac{65}{12},\ F(5) = -\tfrac{575}{12}$ · $\int_{-2}^{1} = \tfrac{99}{4}$ · $\int_1^5 = -\tfrac{160}{3}$ → พื้นที่ $\tfrac{99}{4} + \tfrac{160}{3} = $ $\tfrac{937}{12} \approx 78.08$

b) $x^2(x - 4) = 0$ → x = 0 (แตะแกน ไม่เปลี่ยนเครื่องหมาย), 4 · ช่วง [−2, 4] อยู่ใต้แกน, [4, 5] เหนือแกน · $F = \tfrac{x^4}{4} - \tfrac{4x^3}{3}$ · $\int_{-2}^4 = -\tfrac{64}{3} - \tfrac{44}{3} = -36$ · $\int_4^5 = \tfrac{131}{12}$ → พื้นที่ $36 + \tfrac{131}{12} = $ $\tfrac{563}{12} \approx 46.92$

c) $3x^2 = 10 \Rightarrow x = \pm\sqrt{10/3} \approx \pm1.826$ · แบ่ง 3 ช่วง (ใช้สมมาตร: คิดฝั่งขวาแล้วคูณ 2) · $F = x^3 - 10x$, $r = \sqrt{10/3}$, $F(r) = -\tfrac{20r}{3}$ · $\int_0^r = -\tfrac{20r}{3}$ · $\int_r^3 = -3 + \tfrac{20r}{3}$ → พื้นที่ $= 2\left(\tfrac{40r}{3} - 3\right) = \tfrac{80\sqrt{30}}{9} - 6 \approx$ 42.69

8.5 พื้นที่ระหว่างเส้นโค้ง

ถ้า $f(x) \ge g(x)$ ตลอดช่วง $[a, b]$ พื้นที่ระหว่างสองเส้นคือ “เส้นบน ลบ เส้นล่าง”

📐 สูตรเดียวใช้ได้ทุกกรณี
$$A = \int_a^b \big[f(x) - g(x)\big]\,dx = \int_a^b(\text{บน} - \text{ล่าง})\,dx$$

ไม่ว่าทั้งสองเส้นจะอยู่เหนือแกน ใต้แกน หรือคร่อมแกน x ก็ ใช้สูตรนี้ได้เหมือนเดิม เพราะ “บน − ล่าง” เป็นบวกเสมอ (ความสูงของแถบสี่เหลี่ยม)

ทั้ง 3 แบบ → $A = \displaystyle\int_a^b [f(x) - g(x)]\,dx$ เหมือนกันหมด

ตัวอย่าง 8.11เส้นตรงกับพาราโบลา⭐⭐ ปานกลาง

หาพื้นที่ระหว่าง $f(x) = 4x$ และ $g(x) = \tfrac13x^2$ บนช่วง $[2, 8]$

✅ เฉลย

บนช่วง [2, 8]: เช่น x = 5 → $f = 20,\ g \approx 8.3$ → $f$ อยู่บน (สองเส้นตัดกันที่ x = 0 และ 12 อยู่นอกช่วง)

$$A = \int_2^8\left(4x - \tfrac13x^2\right)dx = \Big[2x^2 - \tfrac{x^3}{9}\Big]_2^8 = (128 - 8) - \left(\tfrac{512}{9} - \tfrac89\right) = 120 - 56 = 64$$

64 ตารางหน่วย

ตัวอย่าง 8.12คร่อมแกน x⭐⭐ ปานกลาง

หาพื้นที่ระหว่าง $f(x) = x^2$ และ $g(x) = -3x$ บนช่วง $[0, 8]$

✅ เฉลย
$$A = \int_0^8\big[x^2 - (-3x)\big]dx = \int_0^8(x^2 + 3x)\,dx = \Big[\tfrac{x^3}{3} + \tfrac{3x^2}{2}\Big]_0^8 = \tfrac{512}{3} + 96 = \tfrac{800}{3}$$

800/3 ≈ 266.67 — สังเกตว่าไม่ต้องแยกส่วนเหนือ/ใต้แกนเลย

เมื่อเส้นโค้งสลับกันอยู่บน

ถ้า $f$ กับ $g$ ตัดกัน ในช่วง ตัวที่อยู่บนจะสลับกัน → ต้องหาจุดตัด ($f(x) = g(x)$) แล้วแบ่งช่วง (คล้ายกรณีตัดแกน x)

ตัวอย่าง 8.13สลับบน–ล่าง⭐⭐⭐ ท้าทาย

หาพื้นที่ระหว่าง $f(x) = x^3$ และ $g(x) = 4x$ บนช่วง $[-2, 2]$

✅ เฉลย

จุดตัด: $x^3 = 4x \Rightarrow x(x-2)(x+2) = 0 \Rightarrow x = -2, 0, 2$

ช่วง [−2, 0]: ทดสอบ x = −1 → $x^3 = -1 > 4x = -4$ → $x^3$ อยู่บน: $\int_{-2}^0(x^3 - 4x)dx = \big[\tfrac{x^4}{4} - 2x^2\big]_{-2}^0 = 0 - (4 - 8) = 4$

ช่วง [0, 2]: $4x$ อยู่บน: $\int_0^2(4x - x^3)dx = \big[2x^2 - \tfrac{x^4}{4}\big]_0^2 = 8 - 4 = 4$

รวม 8 ตารางหน่วย

ตัวอย่าง 8.14พื้นที่ที่ปิดล้อม (ไม่บอกช่วง)⭐⭐⭐ ท้าทาย

หาพื้นที่ที่ปิดล้อมด้วย $y = x^2$ และ $y = x + 2$

✅ เฉลย

เมื่อโจทย์ไม่บอกช่วง ขอบเขตก็คือจุดตัด: $x^2 = x + 2 \Rightarrow (x-2)(x+1) = 0 \Rightarrow x = -1, 2$ · ระหว่างนั้นเส้นตรงอยู่บน (ทดสอบ x = 0: 2 > 0)

$$A = \int_{-1}^2(x + 2 - x^2)\,dx = \Big[\tfrac{x^2}{2} + 2x - \tfrac{x^3}{3}\Big]_{-1}^2 = \tfrac{10}{3} - \left(-\tfrac76\right) = \tfrac92$$

4.5 ตารางหน่วย

ตัวอย่าง 8.15ตัดกันในช่วง (ตัวอย่างจากชั้นเรียน)⭐⭐⭐ ท้าทาย

หาพื้นที่ระหว่าง $f(x) = x^3 - 2x$ และ $g(x) = -2x + 8$ บนช่วง $[1, 10]$

✅ เฉลย

จุดตัด: $x^3 - 2x = -2x + 8 \Rightarrow x^3 = 8 \Rightarrow x = 2$ → แบ่ง [1, 2] และ [2, 10]

[1, 2] ($g$ บน): $\int_1^2(8 - x^3)dx = \big[8x - \tfrac{x^4}{4}\big]_1^2 = 12 - \tfrac{31}{4} = \tfrac{17}{4}$

[2, 10] ($f$ บน): $\int_2^{10}(x^3 - 8)dx = \big[\tfrac{x^4}{4} - 8x\big]_2^{10} = 2420 - (-12) = 2432$

รวม $\tfrac{17}{4} + 2432 = $ 2436.25 ตารางหน่วย

ตรวจคำตอบด้วย Python (SymPy)
from sympy import symbols, integrate, solve, Abs
x = symbols('x')
f, g = x**3, 4*x
print("จุดตัด:", solve(f - g, x))
print("พื้นที่ =", integrate(Abs(f - g), (x, -2, 2)))
print("ถ้าลืมแบ่งช่วง:", integrate(f - g, (x, -2, 2)), " ← ผิด!")

พื้นที่ = 8
ถ้าลืมแบ่งช่วง: 0  ← ผิด!

ลองทำเองก่อนทุกข้อ แล้วค่อยกด 🔑 ดูเฉลย (ต้องใช้รหัสผ่านจากผู้สอน)

  1. อินทิกรัลจำกัดเขต
  2. จงหา (ก) $\displaystyle\int_0^2(3x^2 + 2x)\,dx$ (ข) $\displaystyle\int_{-1}^1(x^3 + 1)\,dx$ (ค) $\displaystyle\int_1^9\sqrt x\,dx$

    (ก) $[x^3 + x^2]_0^2 = 12$ (ข) $[\tfrac{x^4}{4} + x]_{-1}^1 = \tfrac54 - (-\tfrac34) = 2$ (ค) $[\tfrac23x^{3/2}]_1^9 = 18 - \tfrac23 = \tfrac{52}{3}$

  3. ถ้า $\displaystyle\int_1^4 f(x)\,dx = 10$ และ $\displaystyle\int_4^6 f(x)\,dx = -3$ จงหา $\displaystyle\int_1^6 f(x)\,dx$, $\displaystyle\int_4^1 f(x)\,dx$ และ $\displaystyle\int_1^4 3f(x)\,dx$ (สมบัติสลับขอบเขต)

    $10 + (-3) = 7$ · $-10$ · $30$

  4. จงหา $\displaystyle\int_1^2 \frac{x^2 + 1}{x^2}\,dx$

    $\int_1^2(1 + x^{-2})dx = [x - \tfrac1x]_1^2 = (2 - \tfrac12) - (1 - 1) = \tfrac32$

  5. พื้นที่ใต้เส้นโค้ง
  6. จงหาพื้นที่ใต้กราฟ $y = x^2 + 1$ บนช่วง $[0, 3]$

    $[\tfrac{x^3}{3} + x]_0^3 = 9 + 3 = 12$ ตารางหน่วย

  7. จงหาพื้นที่ที่ปิดล้อมด้วย $y = x^2 - 9$ กับแกน x บนช่วง $[0, 3]$

    $\int_0^3(x^2 - 9)dx = 9 - 27 = -18$ → พื้นที่ 18 ตารางหน่วย

  8. จงหาพื้นที่ที่ปิดล้อมด้วย $y = x^2 - 2x$ กับแกน x บนช่วง $[0, 3]$ (หาจุดตัดแกนก่อน)

    ตัดแกนที่ x = 0, 2 · $\int_0^2 = [\tfrac{x^3}{3} - x^2]_0^2 = -\tfrac43$ · $\int_2^3 = 0 - (-\tfrac43) = \tfrac43$ → พื้นที่ $\tfrac43 + \tfrac43 = \tfrac83$

  9. จงหาพื้นที่ที่ปิดล้อมด้วยพาราโบลา $y = 4 - x^2$ กับแกน x

    ตัดแกนที่ ±2 · $\int_{-2}^2(4 - x^2)dx = [4x - \tfrac{x^3}{3}]_{-2}^2 = \tfrac{16}{3} - (-\tfrac{16}{3}) = \tfrac{32}{3}$

  10. เพราะเหตุใด $\displaystyle\int_{-2}^2 x^3\,dx = 0$ แต่พื้นที่ที่ปิดล้อมด้วย $y = x^3$ กับแกน x บนช่วงเดียวกันไม่เท่ากับ 0 พื้นที่จริงเท่าใด

    ส่วนใต้แกน (−2 ถึง 0) ให้ค่า −4 หักล้างกับส่วนเหนือแกน (0 ถึง 2) ค่า +4 · พื้นที่จริง = 4 + 4 = 8

  11. พื้นที่ระหว่างเส้นโค้ง
  12. จงหาพื้นที่ระหว่าง $y = x + 4$ และ $y = x^2 - 2$ บนช่วง $[0, 2]$

    เส้นตรงอยู่บน · $\int_0^2(x + 6 - x^2)dx = [\tfrac{x^2}{2} + 6x - \tfrac{x^3}{3}]_0^2 = 2 + 12 - \tfrac83 = \tfrac{34}{3}$

  13. จงหาพื้นที่ที่ปิดล้อมด้วย $y = x^2$ และ $y = 4$ (ขอบเขต = จุดตัด)

    จุดตัด x = ±2 · $\int_{-2}^2(4 - x^2)dx = \tfrac{32}{3}$

  14. จงหาพื้นที่ที่ปิดล้อมด้วย $y = x^2$ และ $y = 2x$

    จุดตัด $x^2 = 2x \Rightarrow x = 0, 2$ · $2x$ อยู่บน · $\int_0^2(2x - x^2)dx = 4 - \tfrac83 = \tfrac43$

  15. จงหาพื้นที่ระหว่าง $f(x) = x^3 - 1$ และ $g(x) = x$ บนช่วง $[-1, 1]$

    ในช่วงนี้ $g$ อยู่บนตลอด (สองเส้นตัดกันที่ x ≈ 1.32 นอกช่วง) · $\int_{-1}^1(x - x^3 + 1)dx = 0 - 0 + 2 = 2$
