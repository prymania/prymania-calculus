บทที่ 7 · อินทิกรัลไม่จำกัดเขต

ปฏิยานุพันธ์ สูตรอินทิกรัล การจัดรูปก่อนอินทิเกรต การหาค่าคงที่ C และการแทนค่า (เสริม)

🎯 เมื่อเรียนจบบทนี้ นิสิตจะสามารถ
  1. อธิบายว่าอินทิกรัลคือ “การดิฟย้อนกลับ” และทำไมต้องมี $+C$
  2. ใช้สูตรอินทิกรัลยกกำลัง และ $\int \frac1x\,dx = \ln|x| + C$ ได้
  3. จัดรูปฟังก์ชัน (กระจาย แยกเศษส่วน ตัดตัวร่วม) ก่อนอินทิเกรตได้
  4. หาค่าคงที่ $C$ จากเงื่อนไขที่โจทย์กำหนดได้

7.1 อินทิกรัล = ดิฟย้อนกลับ

$\int f(x)\,dx$อินทิกรัล
⇄
$f(x)$ฟังก์ชัน
⇄
$f'(x)$อนุพันธ์

➡️ ดิฟ (derivative) ไปทางขวา  ·  ⬅️ อินทิเกรต (integration) ย้อนกลับไปทางซ้าย

ถ้าถามว่า “ฟังก์ชันอะไรเมื่อดิฟแล้วได้ $2x$?” คำตอบคือ $x^2$ — แต่ $x^2 + 5$, $x^2 - 100$ ดิฟก็ได้ $2x$ เหมือนกัน เพราะค่าคงที่ดิฟได้ 0 ดังนั้น

∫ ปฏิยานุพันธ์ (Antiderivative)
$$\int 2x\,dx = x^2 + C \qquad (C \text{ คือค่าคงที่ใด ๆ})$$

$\int$ อ่านว่า “อินทิกรัล” · $f(x)$ คือ integrand · $dx$ บอกว่าอินทิเกรตเทียบกับ x · เรียกว่า อินทิกรัลไม่จำกัดเขต เพราะยังไม่ได้กำหนดช่วง

7.2 สูตรอินทิกรัล

ยกกำลัง (สำคัญที่สุด)

$$\int ax^n\,dx = \frac{a\,x^{n+1}}{n+1} + C,\ \ n \ne -1$$

“บวกกำลังเพิ่ม 1 แล้วหารด้วยกำลังใหม่” — ตรงข้ามกับการดิฟ

ค่าคงที่

$$\int k\,dx = kx + C$$

ผลบวก/ผลต่าง

$$\int [f \pm g]\,dx = \int f\,dx \pm \int g\,dx$$

อินทิเกรตทีละพจน์

กรณีพิเศษ n = −1

$$\int \frac1x\,dx = \ln|x| + C,\ x\ne0$$

เพราะสูตรยกกำลังจะได้ $\frac{x^0}{0}$ ใช้ไม่ได้

⚠️ ไม่มีสูตรผลคูณ / ผลหารแบบง่าย ๆ

$\int f\cdot g\,dx \ne \int f\,dx\cdot\int g\,dx$ — ถ้าเจอผลคูณหรือผลหาร ให้ กระจาย / แยกพจน์ / ตัดตัวร่วม จนเป็นผลบวกของ $x^n$ ก่อนเสมอ

✅ ตรวจคำตอบได้ทุกข้อ

ดิฟคำตอบที่ได้ ต้องกลับมาเป็นฟังก์ชันในอินทิกรัล — เช่น $\int 5x^4dx = x^5 + C$ ดิฟ $x^5$ ได้ $5x^4$ ✓

ตัวอย่าง 7.1สูตรยกกำลัง⭐ ง่าย
  1. $\int x\,dx$
  2. $\int x^3\,dx$
  3. $\int 5x^4\,dx$
  4. $\int 2\,dx$
  5. $\int (2x^3 + 2x^2 - x)\,dx$
  6. $\int (4x^5 - 2x^4 - x + 2)\,dx$
  7. $\int (x^2 - 2x - 3)\,dx$
  8. $\int (10x^4 + 10x^3 - 10x + 10)\,dx$
✅ เฉลย
  1. $\dfrac{x^2}{2} + C$
  2. $\dfrac{x^4}{4} + C$
  3. $x^5 + C$
  4. $2x + C$
  5. $\dfrac{x^4}{2} + \dfrac{2x^3}{3} - \dfrac{x^2}{2} + C$
  6. $\dfrac{2x^6}{3} - \dfrac{2x^5}{5} - \dfrac{x^2}{2} + 2x + C$
  7. $\dfrac{x^3}{3} - x^2 - 3x + C$
  8. $2x^5 + \dfrac{5x^4}{2} - 5x^2 + 10x + C$
ตัวอย่าง 7.2กำลังลบ ราก และ 1/x⭐⭐ ปานกลาง
  1. $\int \sqrt x\,dx$
  2. $\int \dfrac{1}{\sqrt x}\,dx$
  3. $\int \dfrac{3}{x^2}\,dx$
  4. $\int \dfrac{5}{x}\,dx$
  5. $\int \left(x^2 + \dfrac{1}{x}\right)dx$
✅ เฉลย
  1. $\int x^{1/2}dx = \dfrac{x^{3/2}}{3/2} = \dfrac23x^{3/2} + C$
  2. $\int x^{-1/2}dx = \dfrac{x^{1/2}}{1/2} = 2\sqrt x + C$
  3. $\int 3x^{-2}dx = \dfrac{3x^{-1}}{-1} = -\dfrac{3}{x} + C$
  4. $5\ln|x| + C$
  5. $\dfrac{x^3}{3} + \ln|x| + C$

7.3 จัดรูปก่อนอินทิเกรต

ผลคูณ?กระจายออก
เศษส่วนที่ตัวส่วนพจน์เดียว?แยกเป็นพจน์ ๆ
มีตัวร่วมเศษ–ส่วน?แยกตัวประกอบแล้วตัด
➜
เหลือผลบวกของ $x^n$ใช้สูตรได้
ตัวอย่าง 7.3กระจายก่อน⭐⭐ ปานกลาง
  1. $\int (x^2 - 2)(x + 5)\,dx$
  2. $\int \dfrac{(x-5)^2}{5}\,dx$
  3. $\int (2x+1)^2\,dx$
✅ เฉลย

a) $x^3 + 5x^2 - 2x - 10$ → $\dfrac{x^4}{4} + \dfrac{5x^3}{3} - x^2 - 10x + C$

b) $\dfrac{x^2 - 10x + 25}{5} = \tfrac15x^2 - 2x + 5$ → $\dfrac{x^3}{15} - x^2 + 5x + C$

c) $4x^2 + 4x + 1$ → $\dfrac{4x^3}{3} + 2x^2 + x + C$

ตัวอย่าง 7.4ตัดตัวร่วม⭐⭐ ปานกลาง
  1. $\int \dfrac{x(x-5)^2}{x-5}\,dx$
  2. $\int \dfrac{x(x^2+2x-3)}{x-1}\,dx$
  3. $\int \dfrac{x^2-1}{(x+1)(x-1)}\,dx$
✅ เฉลย

a) $x(x-5) = x^2 - 5x$ → $\dfrac{x^3}{3} - \dfrac{5x^2}{2} + C$

b) $\dfrac{x(x-1)(x+3)}{x-1} = x^2 + 3x$ → $\dfrac{x^3}{3} + \dfrac{3x^2}{2} + C$

c) เศษกับส่วนเท่ากัน $= 1$ → $x + C$

ตัวอย่าง 7.5แยกเศษส่วน⭐⭐⭐ ท้าทาย
  1. $\int \dfrac{x^4 + 3x^2 + 5}{x^4}\,dx$
  2. $\int \dfrac{x^2 + 4x + 1}{x}\,dx$
  3. $\int \dfrac{(\sqrt x + 1)^2}{\sqrt x}\,dx$
✅ เฉลย

a) $1 + 3x^{-2} + 5x^{-4}$ → $x + \dfrac{3x^{-1}}{-1} + \dfrac{5x^{-3}}{-3}$ = $x - \dfrac3x - \dfrac{5}{3x^3} + C$

b) $x + 4 + \dfrac1x$ → $\dfrac{x^2}{2} + 4x + \ln|x| + C$

c) $\dfrac{x + 2\sqrt x + 1}{\sqrt x} = x^{1/2} + 2 + x^{-1/2}$ → $\tfrac23x^{3/2} + 2x + 2\sqrt x + C$

7.4 หาค่าคงที่ C — หาฟังก์ชันจริงจากอนุพันธ์

ถ้ารู้ $f'(x)$ และรู้ จุดหนึ่งจุด ที่กราฟผ่าน เราจะหา $C$ ได้ค่าเดียว → ได้ฟังก์ชันจริง (เลือกเส้นเดียวจากครอบครัวกราฟ)

🎯 ขั้นตอน
  1. $f(x) = \int f'(x)\,dx$ (ยังมี $+C$)
  2. แทนเงื่อนไขที่โจทย์ให้ เช่น $f(10) = 800$
  3. แก้สมการหา $C$ แล้วเขียน $f(x)$ ใหม่ (ตรวจคำตอบด้วยการแทนค่า)
ตัวอย่าง 7.6หาฟังก์ชันจากอนุพันธ์⭐ ง่าย

กำหนด $f'(x) = 3x^2 - 4x + 6$ และ $f(10) = 800$ จงหา $f(x)$

✅ เฉลย

$f(x) = x^3 - 2x^2 + 6x + C$ · แทน x = 10: $1000 - 200 + 60 + C = 800 \Rightarrow C = -60$

$f(x) = x^3 - 2x^2 + 6x - 60$ · ตรวจ: $f(10) = 860 - 60 = 800$ ✓

ตัวอย่าง 7.7หาฟังก์ชันจากอนุพันธ์ (ฝึกต่อ)⭐⭐ ปานกลาง
  1. $f'(x) = 4x^3 - 6x^2 - 2x,\ f(1) = 0$
  2. $f'(x) = 3x^2 - 2x,\ f(10) = 900$
  3. $f'(x) = 6x^2 - 8x + 5,\ f(2) = 0$
  4. $f'(x) = 3x^2,\ f(2) = 7$
✅ เฉลย

a) $x^4 - 2x^3 - x^2 + C$ · $1 - 2 - 1 + C = 0 \Rightarrow C = 2$ → $f(x) = x^4 - 2x^3 - x^2 + 2$

b) $x^3 - x^2 + C$ · $1000 - 100 + C = 900 \Rightarrow C = 0$ → $f(x) = x^3 - x^2$

c) $2x^3 - 4x^2 + 5x + C$ · $16 - 16 + 10 + C = 0 \Rightarrow C = -10$ → $f(x) = 2x^3 - 4x^2 + 5x - 10$

d) $x^3 + C$ · $8 + C = 7 \Rightarrow C = -1$ → $f(x) = x^3 - 1$

ตัวอย่าง 7.8สมการเส้นโค้งจากความชัน⭐⭐ ปานกลาง

เส้นโค้งหนึ่งมีความชัน ณ จุดใด ๆ เท่ากับ $2x + 1$ และผ่านจุด $(1, 5)$ จงหาสมการเส้นโค้ง

✅ เฉลย

$y = \int(2x+1)dx = x^2 + x + C$ · $5 = 1 + 1 + C \Rightarrow C = 3$ → $y = x^2 + x + 3$

ตัวอย่าง 7.9จากความเร็วหาตำแหน่ง⭐⭐ ปานกลาง

รถเคลื่อนที่ด้วยความเร็ว $v(t) = 3t^2 + 2$ เมตร/วินาที และที่ $t = 0$ อยู่ที่ตำแหน่ง $s = 5$ เมตร จงหา $s(t)$ และตำแหน่งที่ $t = 3$

✅ เฉลย

ความเร็วคืออนุพันธ์ของตำแหน่ง → $s(t) = \int(3t^2 + 2)dt = t^3 + 2t + C$ · $s(0) = C = 5$

$s(t) = t^3 + 2t + 5$ · $s(3) = 27 + 6 + 5 = 38$ เมตร

7.5 การอินทิเกรตโดยการแทนค่า เสริม

เป็น “กฎลูกโซ่ย้อนกลับ” ใช้เมื่อเห็น ก้อนหนึ่ง กับ อนุพันธ์ของก้อนนั้น คูณกันอยู่

🔁 แนวคิด

ให้ $u = $ ก้อนข้างใน → $du = u'\,dx$ → เปลี่ยนทั้งโจทย์ให้เป็นตัวแปร $u$ → อินทิเกรต → แทน $u$ กลับ

ตัวอย่าง 7.10แทนค่า u⭐⭐⭐ ท้าทาย
  1. $\int 2x(x^2+1)^3\,dx$
  2. $\int (3x+1)^5\,dx$
  3. $\int x^2\sqrt{x^3 + 4}\,dx$
✅ เฉลย

a) $u = x^2 + 1,\ du = 2x\,dx$ → $\int u^3du = \dfrac{u^4}{4}$ = $\dfrac{(x^2+1)^4}{4} + C$

b) $u = 3x + 1,\ du = 3dx \Rightarrow dx = \tfrac13du$ → $\tfrac13\int u^5du = \dfrac{u^6}{18}$ = $\dfrac{(3x+1)^6}{18} + C$

c) $u = x^3 + 4,\ du = 3x^2dx$ → $\tfrac13\int u^{1/2}du = \tfrac13\cdot\tfrac23u^{3/2}$ = $\tfrac29(x^3+4)^{3/2} + C$

ตรวจคำตอบด้วย Python (SymPy)
from sympy import symbols, integrate, solve, Eq
x, C = symbols('x C')
print(integrate((x**2 - 2)*(x + 5), x))
print(integrate((x**4 + 3*x**2 + 5)/x**4, x))
F = integrate(3*x**2 - 4*x + 6, x) + C
print("C =", solve(Eq(F.subs(x, 10), 800), C))
print(integrate(2*x*(x**2 + 1)**3, x).factor())

x**4/4 + 5*x**3/3 - x**2 - 10*x
x + (-9*x**2 - 5)/(3*x**3)
C = [-60]
x**2*(x**2 + 2)*(x**4 + 2*x**2 + 2)/4

คำถามท้ายบท

ลองทำเองก่อนทุกข้อ แล้วค่อยกด 🔑 ดูเฉลย (ต้องใช้รหัสผ่านจากผู้สอน)

  1. สูตรพื้นฐาน
  2. จงหา (ก) $\int (6x^2 - 4x + 7)\,dx$ (ข) $\int (x^5 - x^{-3})\,dx$ (ค) $\int 0\,dx$

    (ก) $2x^3 - 2x^2 + 7x + C$ (ข) $\dfrac{x^6}{6} + \dfrac{1}{2x^2} + C$ (ค) $C$

  3. จงหา $\int \left(\dfrac{4}{x^3} - 3\sqrt x\right)dx$

    $\int (4x^{-3} - 3x^{1/2})dx = -2x^{-2} - 2x^{3/2} + C = -\dfrac{2}{x^2} - 2x^{3/2} + C$

  4. นิสิตตอบว่า $\int 3x^2\,dx = 6x + C$ ผิดตรงไหน (ดิฟคำตอบดู)

    สับสนกับการดิฟ · ที่ถูกคือ $\dfrac{3x^3}{3} = x^3 + C$ · ตรวจ: ดิฟ $x^3$ ได้ $3x^2$ ✓ (ส่วนดิฟ $6x$ ได้ 6 ✗)

  5. จงหา $\int \dfrac{2}{x}\,dx$ และ $\int \dfrac{x+1}{x}\,dx$

    $2\ln|x| + C$ · $\int(1 + \tfrac1x)dx = x + \ln|x| + C$

  6. จัดรูปก่อน
  7. จงหา $\int (x+3)(x-3)\,dx$

    $\int(x^2 - 9)dx = \dfrac{x^3}{3} - 9x + C$

  8. จงหา $\int \dfrac{x^3 - 2x^2 + x}{x}\,dx$

    $\int(x^2 - 2x + 1)dx = \dfrac{x^3}{3} - x^2 + x + C$

  9. จงหา $\int \dfrac{x^2 - 4}{x - 2}\,dx$ (แยกตัวประกอบ)

    $\int(x + 2)dx = \dfrac{x^2}{2} + 2x + C$

  10. จงหา $\int x^2(x^3 - 2)\,dx$ (โดยกระจาย)

    $\int(x^5 - 2x^2)dx = \dfrac{x^6}{6} - \dfrac{2x^3}{3} + C$

  11. หาค่า C
  12. กำหนด $f'(x) = 4x - 3$ และ $f(2) = 5$ จงหา $f(x)$

    $f = 2x^2 - 3x + C$ · $8 - 6 + C = 5 \Rightarrow C = 3$ → $f(x) = 2x^2 - 3x + 3$

  13. กำหนด $f'(x) = x^2 + 2x$ และ $f(0) = -4$ จงหา $f(3)$

    $f = \dfrac{x^3}{3} + x^2 + C$ · $C = -4$ → $f(3) = 9 + 9 - 4 = 14$

  14. กำหนด $f''(x) = 6x$, $f'(1) = 5$ และ $f(0) = 2$ จงหา $f(x)$ (อินทิเกรต 2 ครั้ง)

    $f' = 3x^2 + C_1$ · $3 + C_1 = 5 \Rightarrow C_1 = 2$ · $f = x^3 + 2x + C_2$ · $C_2 = 2$ → $f(x) = x^3 + 2x + 2$

  15. เส้นโค้งมีความชัน $3x^2 - 6x$ และผ่านจุด $(2, 1)$ จงหาสมการเส้นโค้ง

    $y = x^3 - 3x^2 + C$ · $8 - 12 + C = 1 \Rightarrow C = 5$ → $y = x^3 - 3x^2 + 5$
