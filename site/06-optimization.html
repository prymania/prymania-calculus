6.1 สูตรสำเร็จ 5 ขั้น

1. อ่าน + วาดรูปอะไรคือสิ่งที่อยากให้ max/min
➜
2. ตั้งตัวแปรให้ x คืออะไร
➜
3. เขียนฟังก์ชันให้เหลือตัวแปรเดียว
➜
4. ดิฟ = 0หาจุดวิกฤต
➜
5. ตรวจ + ตอบf″ / ปลายช่วง / หน่วย
⚠️ ข้อผิดพลาดที่เจอบ่อย
  • ฟังก์ชันยังมี 2 ตัวแปร → ต้องใช้ “เงื่อนไข” ในโจทย์ แทนตัวแปรหนึ่งด้วยอีกตัวก่อนดิฟ
  • ตอบแค่ค่า x แต่โจทย์ถามขนาด หรือ พื้นที่ หรือ เงิน — อ่านคำถามซ้ำก่อนตอบ
  • ลืมเช็คว่าค่า x อยู่ในช่วงที่เป็นไปได้จริง (เช่น ความยาวต้องเป็นบวก)

6.2 ปัญหาพื้นที่และปริมาตร

ตัวอย่าง 6.1กั้นรั้วริมแม่น้ำ⭐⭐ ปานกลาง

มีรั้วยาว 1,000 เมตร ต้องการกั้นที่ดินรูปสี่เหลี่ยมมุมฉากริมแม่น้ำ โดยด้านที่ติดแม่น้ำไม่ต้องกั้นรั้ว จงหาขนาดที่ทำให้ได้พื้นที่มากที่สุด และพื้นที่นั้นเป็นเท่าใด

✅ เฉลย

รั้ว: $2x + y = 1000 \Rightarrow y = 1000 - 2x$ · พื้นที่ $A = xy = x(1000 - 2x) = 1000x - 2x^2$

$A'(x) = 1000 - 4x = 0 \Rightarrow x = 250$ · $A''(x) = -4 \lt 0$ → สูงสุด ✓

ด้านกว้าง (ตั้งฉากแม่น้ำ) 250 ม. ด้านยาว $y = 500$ ม. → พื้นที่มากที่สุด 125,000 ตร.ม.

ตัวอย่าง 6.2ความยาวรอบรูปคงที่⭐ ง่าย

สี่เหลี่ยมผืนผ้ามีความยาวรอบรูป 40 ซม. จะมีพื้นที่มากที่สุดเท่าใด

✅ เฉลย

ให้กว้าง x ยาว y: $2x + 2y = 40 \Rightarrow y = 20 - x$ · $A = x(20 - x) = 20x - x^2$

$A' = 20 - 2x = 0 \Rightarrow x = 10,\ y = 10$ · $A'' = -2 \lt 0$ → สี่เหลี่ยมจัตุรัส 10×10 พื้นที่ 100 ตร.ซม.

ตัวอย่าง 6.3พับกล่องไม่มีฝา⭐⭐⭐ ท้าทาย

นำกระดาษแข็งรูปสี่เหลี่ยมจัตุรัสขนาด 12×12 ซม. มาตัดมุมทั้งสี่ออกเป็นสี่เหลี่ยมจัตุรัสด้านละ x ซม. แล้วพับขึ้นเป็นกล่องไม่มีฝา จงหา x ที่ทำให้กล่องมีปริมาตรมากที่สุด

✅ เฉลย

ฐานกว้าง $12 - 2x$ สูง $x$ → $V(x) = x(12 - 2x)^2$ โดย $0 \lt x \lt 6$

ใช้ผลคูณ+ลูกโซ่: $V'(x) = (12-2x)^2 + x\cdot 2(12-2x)(-2) = (12-2x)(12 - 2x - 4x) = (12-2x)(12-6x)$

$V' = 0 \Rightarrow x = 6$ (ตัดทิ้ง กล่องแบน ปริมาตร 0) หรือ $x = 2$

$V(2) = 2\cdot 8^2 = 128$ → ตัดมุมด้านละ 2 ซม. ได้ปริมาตรมากสุด 128 ลบ.ซม.

6.3 ปัญหาตัวเลข

ตัวอย่าง 6.4ผลคูณมากที่สุด⭐⭐ ปานกลาง

จงหาจำนวนเต็มบวกสองจำนวนที่บวกกันได้ 120 และทำให้ ผลคูณของจำนวนหนึ่งกับกำลังสองของอีกจำนวนหนึ่ง มีค่ามากที่สุด

✅ เฉลย

ให้จำนวนแรก $x$ จำนวนที่สอง $120 - x$ · $f(x) = (120 - x)x^2 = 120x^2 - x^3$

$f'(x) = 240x - 3x^2 = 3x(80 - x) = 0 \Rightarrow x = 0$ หรือ $x = 80$ · $f''(x) = 240 - 6x$

$f''(0) = 240 > 0$ (ต่ำสุด) · $f''(80) = -240 \lt 0$ (สูงสุด ✓)

สองจำนวนคือ 80 และ 40 ได้ผลคูณ $40 \times 80^2 = 256{,}000$

ตัวอย่าง 6.5ผลบวกน้อยที่สุด⭐⭐ ปานกลาง

จำนวนบวกสองจำนวนคูณกันได้ 64 ผลบวกของสองจำนวนนี้น้อยที่สุดเป็นเท่าใด

✅ เฉลย

ให้ $x$ และ $\dfrac{64}{x}$ → $S(x) = x + 64x^{-1}$ · $S'(x) = 1 - \dfrac{64}{x^2} = 0 \Rightarrow x = 8$ (บวก)

$S''(x) = \dfrac{128}{x^3} > 0$ → ต่ำสุด ✓ → 8 กับ 8 ผลบวกน้อยสุด 16

6.4 ปัญหาธุรกิจ: รายได้และกำไร

💰 ศัพท์ที่ต้องรู้

รายได้ $R$ = ราคา × จำนวนที่ขาย · ต้นทุน $C$ · กำไร $P = R - C$ · ลดราคาลง → ขายได้มากขึ้น แต่ได้เงินต่อชิ้นน้อยลง จึงต้องหา “จุดพอดี”

ตัวอย่าง 6.6PryFlix สู้ NetFlix⭐⭐ ปานกลาง

เราทำ PryFlix เก็บค่าสมาชิกเดือนละ 200 บาท มีสมาชิก 1,000 คน สังเกตว่าทุก ๆ การลดราคา 10 บาท จะมีสมาชิกเพิ่ม 100 คน ควรตั้งราคาเท่าใดจึงได้รายได้มากที่สุด และได้รายได้เท่าใด

✅ เฉลย

ให้ $x$ = จำนวนครั้งที่ลดราคาครั้งละ 10 บาท → ราคา $200 - 10x$ · สมาชิก $1000 + 100x$

$$R(x) = (1000 + 100x)(200 - 10x) = 200{,}000 + 10{,}000x - 1{,}000x^2$$

$R'(x) = 10{,}000 - 2{,}000x = 0 \Rightarrow x = 5$ · $R'' = -2{,}000 \lt 0$ สูงสุด ✓

ราคา $200 - 50 = $ 150 บาท · สมาชิก 1,500 คน → รายได้สูงสุด 225,000 บาท/เดือน

ตัวอย่าง 6.7ร้านเค้ก⭐⭐ ปานกลาง

ร้านเค้กตั้งราคาชิ้นละ 50 บาท ขายได้เดือนละ 100 ชิ้น ถ้าลดราคาลงทุก 1 บาท จะขายได้เพิ่ม 5 ชิ้น ควรตั้งราคาเท่าใด และได้ยอดขายกี่บาท

✅ เฉลย

คราวนี้ให้ $x$ = ราคาเค้กโดยตรง → ลดไป $50 - x$ บาท ขายได้ $100 + 5(50 - x) = 350 - 5x$ ชิ้น

$R(x) = x(350 - 5x) = 350x - 5x^2$ · $R'(x) = 350 - 10x = 0 \Rightarrow x = 35$ · $R'' = -10 \lt 0$ ✓

ตั้งราคา 35 บาท ขาย 175 ชิ้น ได้ 6,125 บาท/เดือน

💡 สังเกต: ตั้งตัวแปรต่างกัน (PryFlix ให้ x = จำนวนครั้งที่ลด / เค้กให้ x = ราคา) ได้ทั้งคู่ ขอแค่ใช้ให้สม่ำเสมอ

ตัวอย่าง 6.8กำไรสูงสุด⭐⭐ ปานกลาง

บริษัทผลิตสินค้า $x$ ชิ้น มีต้นทุน $C(x) = x^2 - 4x + 5$ บาท และรายได้ $R(x) = 20x - x^2$ บาท จงหาจำนวนที่ควรผลิตเพื่อให้กำไรสูงสุด และกำไรสูงสุดเท่าใด

✅ เฉลย

$P(x) = R - C = (20x - x^2) - (x^2 - 4x + 5) = -2x^2 + 24x - 5$

$P'(x) = -4x + 24 = 0 \Rightarrow x = 6$ · $P''(x) = -4 \lt 0$ ✓

$P(6) = -72 + 144 - 5 = 67$ → ผลิต 6 ชิ้น กำไรสูงสุด 67 บาท

6.5 ปัญหาการเคลื่อนที่

ตัวอย่าง 6.9โยนลูกบอล⭐ ง่าย

ลูกบอลถูกโยนขึ้นจากความสูง 1 เมตร ความสูงหลังผ่านไป $t$ วินาทีคือ $h(t) = -5t^2 + 20t + 1$ เมตร ลูกบอลขึ้นไปได้สูงสุดเท่าใด เมื่อใด

✅ เฉลย

จุดสูงสุดคือจุดที่ความเร็วเป็นศูนย์: $h'(t) = -10t + 20 = 0 \Rightarrow t = 2$ วินาที

$h(2) = -20 + 40 + 1 = 21$ → สูงสุด 21 เมตร ที่ t = 2 วินาที

ตัวอย่าง 6.10ต้นทุนเฉลี่ยต่อชิ้น⭐⭐⭐ ท้าทาย

ต้นทุนรวมของการผลิต $x$ ชิ้นคือ $C(x) = 2x^2 + 50x + 800$ บาท ควรผลิตกี่ชิ้นเพื่อให้ ต้นทุนเฉลี่ยต่อชิ้น ต่ำที่สุด

✅ เฉลย

ต้นทุนเฉลี่ย $\bar C(x) = \dfrac{C(x)}{x} = 2x + 50 + \dfrac{800}{x}$

$\bar C'(x) = 2 - \dfrac{800}{x^2} = 0 \Rightarrow x^2 = 400 \Rightarrow x = 20$ · $\bar C''(x) = \dfrac{1600}{x^3} > 0$ ต่ำสุด ✓

$\bar C(20) = 40 + 50 + 40 = 130$ → ผลิต 20 ชิ้น ต้นทุนเฉลี่ยต่ำสุด 130 บาท/ชิ้น

ตรวจโจทย์กล่องไม่มีฝาด้วย SymPy
from sympy import symbols, diff, solve
x = symbols('x', positive=True)
V = x*(12 - 2*x)**2
for c in solve(diff(V, x), x):
    print("x =", c, " V =", V.subs(x, c), " V'' =", diff(V, x, 2).subs(x, c))
▸ ผลลัพธ์เมื่อรัน
x = 2  V = 128  V'' = -48
x = 6  V = 0  V'' = 48

คำถามท้ายบท

ลองทำเองก่อนทุกข้อ แล้วค่อยกด 🔑 ดูเฉลย (ต้องใช้รหัสผ่านจากผู้สอน)

  1. เรขาคณิต
  2. สี่เหลี่ยมผืนผ้ามีพื้นที่ 100 ตร.ม. จงหาขนาดที่ทำให้ความยาวรอบรูปน้อยที่สุด

    $y = \dfrac{100}{x}$ · $L = 2x + \dfrac{200}{x}$ · $L' = 2 - \dfrac{200}{x^2} = 0 \Rightarrow x = 10$ · $L'' > 0$ → 10×10 ม. รอบรูป 40 ม.

  3. ชาวนามีรั้ว 240 ม. ต้องการล้อมคอกสี่เหลี่ยมติดกำแพงยุ้งฉาง (ไม่ต้องกั้นด้านกำแพง) ให้ได้พื้นที่มากที่สุด (ด้านหนึ่งเป็นกำแพง)

    $2x + y = 240$ · $A = x(240 - 2x)$ · $A' = 240 - 4x = 0 \Rightarrow x = 60,\ y = 120$ → พื้นที่ 7,200 ตร.ม.

  4. ต้องการกั้นที่ดินสี่เหลี่ยมผืนผ้าแล้วแบ่งเป็น 2 แปลงด้วยรั้วกลาง 1 เส้นขนานกับด้านกว้าง ใช้รั้วทั้งหมด 600 ม. พื้นที่มากที่สุดเท่าใด

    ด้านกว้าง x มี 3 เส้น ด้านยาว y มี 2 เส้น: $3x + 2y = 600 \Rightarrow y = 300 - 1.5x$ · $A = 300x - 1.5x^2$ · $A' = 300 - 3x = 0 \Rightarrow x = 100,\ y = 150$ → 15,000 ตร.ม.

  5. กระดาษ 30×30 ซม. ตัดมุมด้านละ x แล้วพับเป็นกล่องไม่มีฝา x เท่าใดได้ปริมาตรมากสุด (V = x(a − 2x)²)

    $V = x(30 - 2x)^2$ · $V' = (30-2x)(30-6x) = 0 \Rightarrow x = 5$ (x = 15 ตัดทิ้ง) · $V(5) = 5\cdot 400 = 2{,}000$ ลบ.ซม.

  6. ตัวเลข
  7. จำนวนสองจำนวนบวกกันได้ 50 ผลคูณมากที่สุดเท่าใด

    $P = x(50 - x)$ · $P' = 50 - 2x = 0 \Rightarrow x = 25$ → 25 กับ 25 ผลคูณ 625

  8. จงหาจำนวนบวกที่ทำให้ผลบวกของจำนวนนั้นกับส่วนกลับของมันมีค่าน้อยที่สุด

    $S = x + \dfrac1x$ · $S' = 1 - \dfrac1{x^2} = 0 \Rightarrow x = 1$ · $S'' = \dfrac2{x^3} > 0$ → x = 1 ได้ค่าน้อยสุด 2

  9. ธุรกิจ
  10. คอนเสิร์ตขายบัตรใบละ 500 บาท ได้ 2,000 ใบ ทุกการลดราคา 20 บาทขายเพิ่มได้ 100 ใบ ควรตั้งราคาเท่าใดให้รายได้สูงสุด

    ลด x ครั้ง: $R = (500 - 20x)(2000 + 100x) = 1{,}000{,}000 + 10{,}000x - 2{,}000x^2$ · $R' = 10{,}000 - 4{,}000x = 0 \Rightarrow x = 2.5$ → ราคา 450 บาท ขาย 2,250 ใบ รายได้ 1,012,500 บาท

  11. ฟังก์ชันกำไร $P(x) = -x^3 + 6x^2 + 15x - 40$ (พันบาท) เมื่อผลิต $x$ พันชิ้น ($x \ge 0$) ควรผลิตเท่าใด

    $P' = -3x^2 + 12x + 15 = -3(x-5)(x+1) = 0 \Rightarrow x = 5$ · $P''(5) = -6(5) + 12 = -18 \lt 0$ · $P(5) = -125 + 150 + 75 - 40 = 60$ → ผลิต 5 พันชิ้น กำไร 60 พันบาท

  12. รายได้ $R(x) = 100x - 0.5x^2$ ต้นทุน $C(x) = 20x + 1{,}000$ จงหาจำนวนที่ผลิตเพื่อกำไรสูงสุด

    $P = 80x - 0.5x^2 - 1000$ · $P' = 80 - x = 0 \Rightarrow x = 80$ · $P(80) = 6400 - 3200 - 1000 = 2{,}200$ บาท

  13. การเคลื่อนที่
  14. จรวดจำลองมีความสูง $h(t) = -4.9t^2 + 49t$ เมตร จงหาความสูงสูงสุด

    $h' = -9.8t + 49 = 0 \Rightarrow t = 5$ วินาที · $h(5) = -122.5 + 245 = 122.5$ เมตร
